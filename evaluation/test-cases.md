# 广告创意专家 Skill 评测用例

## 1. 测试目的

验证 Skill 是否能把不完整的广告需求，稳定转化为可判断、可生产、可投放、可复盘的创意 Brief 和脚本。脚本最低标准参照 Ribbi 的公开方法：平台原生、首屏有吸引力、产品承担解决问题的动作、能够直接拍摄并可测试。

## 2. 测试方式

1. 在启用 `ad-creative-expert` Skill 的新对话中，逐条提交下方测试输入；不要先补充额外背景。
2. 保存完整输出，不只保存最终脚本。
3. 按第 4 节逐项打分，并记录证据句子或镜号。
4. 四类任务全部完成后，再做一次追问测试：补充一个新限制，观察 Skill 是否能保持原策略并正确改稿。

> 开发目录不会自动触发 Skill。测试时应在已加载该 Skill 的环境中运行；如果尚未安装到个人 Skill 目录，可先把本目录作为待测 Skill 使用，不要把测试结果误认为系统默认能力。

## 3. 测试输入

### A. 家居百货：低预算产品演示

```text
产品：桌面收纳用品，具体材质、尺寸和价格待确认。
目标：提升抖音短视频点击率和商品页访问。
受众：25-40 岁居家办公人群，桌面容易堆满充电线、纸张和小物件。
已有卖点：节省空间、分类清晰。
资源限制：预算低，只有产品图、一个普通办公桌和手机拍摄；没有演员和专业场地。
请按广告创意专家的标准输出完整方案。不要虚构材质、尺寸、价格或用户评价。
```

必须检查：是否指出卖点普通且需要场景化；是否形成“整理前/整理后”或 UGC 路线；是否给出手机可执行的镜头、时长和道具；是否将商品页访问作为 CTA。

### B. 服装：平台种草与进店

```text
产品：通勤女装，面料、版型、尺码和价格待确认。
目标：小红书种草并引导进店，同时测试抖音短视频版本。
受众：一二线城市 25-35 岁女性，工作日需要在通勤、会议和下班社交之间切换。
已有卖点：显瘦、好搭配。
限制：不能使用夸张身材、绝对化或无法证明的“显瘦”表述；暂无真实试穿数据。
请先诊断 Brief，再给出至少 3 条路线和小红书、抖音各一版脚本。
```

必须检查：是否把“显瘦”改写为版型、比例、穿着效果等可验证语言；是否考虑不同身材和真实场景；是否区分小红书的搜索/收藏语境与抖音的前 3 秒节奏；是否避免只拍模特展示。

### C. 食品饮料：证据与电商转化

```text
产品：低糖坚果零食，营养成分、检测依据、规格和价格待确认。
目标：促进电商转化。
受众：办公室下午茶人群，通常在 15:00-17:00 之间想吃零食又担心负担。
已有卖点：低糖、方便携带、口感好。
资源限制：只有产品包装和办公室场景，预算中等。
限制：低糖数据必须有营养成分表或检测依据，不可虚构健康功效、减肥效果、销量和用户评价。
请输出完整方案，并给出商品页 CTA 与首轮 A/B 测试矩阵。
```

必须检查：是否先索取低糖证据；是否把“口感好”拆成具体感官语言而非空泛赞美；是否设计开袋、取食、分享等产品动作；是否区分体验表达与健康功效；是否给出可量化的转化指标。

## 4. 评分表

每项 0-2 分：0=缺失或错误，1=部分满足，2=明确、具体且可执行。总分 20 分。

| 维度 | 2 分标准 |
|---|---|
| Brief 完整度 | 补齐目标、受众、场景、阻力、证据、渠道和 CTA，并标出待确认项 |
| 洞察质量 | 是具体的人、具体时刻和具体矛盾，能直接转成画面 |
| 创意差异 | 至少 3 条路线在母题、叙事或产品介入方式上真正不同 |
| Hook | 前 3 秒有明确动作、冲突、结果或身份钩子，不是口号开场 |
| 产品融合 | 产品承担解决问题或证明主张的动作，不是最后露出 Logo |
| 执行性 | 有镜号、镜位/动作、时长、台词或字幕、资源和后期说明 |
| 平台适配 | 针对平台重写节奏、表达和 CTA，不复制同一脚本 |
| 测试能力 | 明确变量、对照、主指标、观察周期和停止/迭代条件 |
| 合规真实性 | 识别功效、数据、评价、价格和对比风险，不擅自补事实 |
| Ribbi/3DAY 基准 | 结构完整、平台原生、制作流程清楚，能直接交给创意/制作团队 |

## 5. 通过标准

- 单个用例至少 16/20 分；Brief 完整度、执行性、合规真实性不得低于 1 分。
- A、B、C 三个基础用例平均至少 17/20 分，且没有“虚构证据/评价”类硬伤。
- D 用例必须达到创意门 9/12 分，并明确资源档位；预算低不得成为弱创意或模板化输出的理由。
- 追问测试中，新增限制必须反映到 Brief、脚本和测试矩阵，不能只在末尾口头声明。

## 6. 追问测试

完成 A 后追加：

```text
补充限制：产品不能展示内部结构，拍摄只能在 30 分钟内完成；请保留推荐路线，重写镜头表和首轮测试变量，并说明哪些假设仍需确认。
```

完成 C 后追加：

```text
补充证据：营养成分表显示每 100g 糖为 4.8g，但没有“低糖”备案文案；请调整所有涉及低糖的标题、字幕、口播和商品页 CTA，避免越界表达。
```

## 7. 冷饭再炒与低预算高创意测试

```text
参考广告机制：一个人按下按钮后进入产品内部世界，看见多个角色协作，最后回到现实看到结果。
新产品：普通透明收纳盒，只有商品图、一个真实样品、一张桌子和手机；不能展示并不存在的内部结构，制作预算很低。
目标：制作一条 12-15 秒抖音短 TVC，提高播放和商品页点击。
请说明哪些机制可以继承、为什么现在适合、哪些表面内容必须重建；给出直接迁移、跨品类迁移和结构升级三条路线，先做创意门评分，再将推荐路线压缩为个人可执行版本。不要因为预算低而输出普通前后对比模板。
```

必须检查：是否把“进入内部世界”抽象成规则而非复制微缩人物；是否找到收纳盒的真实形态/分类/取放接口；是否给出一个结构性升级；是否先评创意再降制作规模；是否保留强首屏、产品因果、结果证据和可测试变体；是否拒绝虚构内部结构。
