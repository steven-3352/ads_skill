## 归并规则

- 通用方法只保留一份 canonical 来源；案例文件引用它，不复制整段规则。
- 样本分析必须标事实、推断、假设，不能把审美判断写成投放结论。
- 新的 AI 生产案例先放 `cases/`；验证为通用规律后，再更新对应 SOP。
