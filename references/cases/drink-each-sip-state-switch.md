## 一、样本事实

### 可见结构

1. 开头人物穿中性灰色服装，在白色背景前打开饮料并饮用。
2. 画面转入高识别度绿色系统，人物始终位于巨大的白色瓶身轮廓中。
3. 每次饮用后，人物服装、姿态、道具和状态词同时变化。
4. 第一组以耳机、节奏设备、相机等道具建立音乐/节奏状态。
5. 第二组以帽子、墨镜、相机、运动鞋等道具建立夏日出行状态。
6. 第三组以烤串、扇子等道具建立户外烧烤与辛辣状态。
7. 第四组以泳圈、毛巾、冰饮等道具建立泳池与清凉状态。
8. 大饮料瓶多次横向经过画面，既是产品展示，也是不同状态之间的擦除转场。
9. 最后回到完整瓶装产品、品牌色和广告语，结束人物幻想。

### 画面语言

- 绿色、白色和少量黄色形成强品牌色块。
- 人物是抠像式全身构图，不依赖真实地点连续摄影。
- 白色瓶形既是人物舞台，也是持续存在的产品符号。
- 每种状态由“服装 + 姿态 + 5-8 个浮动道具 + 大字状态词”共同编码。
- 构图规则稳定，内容在瓶形内部和周围重复升级。
- 平面设计承担主要叙事，产品瓶承担切换动作。

### 声音证据边界

文件包含连续音乐/声音轨，结尾约 0.38 秒进入低声或静音。当前分析未进行对白转写，因此不把具体歌词、拟音和口播作为已确认事实。复刻时应重新设计合法音乐、开盖、气泡、吞咽、切换和场景提示音。

## 二、核心创意机制

这条片子不是“喝一口换一件衣服”，而是：

```text
饮品的味觉与身体感受不可见
→ 把每一口变成一个状态切换开关
→ 用身份、服装、动作、道具和场景符号外化感受
→ 重复饮用，连续解锁不同的生活模式
→ 最后回到产品，说明这些状态都由同一瓶饮料触发
```

可以命名为：

```text
一口一状态 / Sip-to-State
```

### 产品承担四种角色

1. **触发器**：喝一口，状态改变。
2. **容器**：瓶形轮廓持续包住人物和体验。
3. **转场器**：大瓶划过画面，切换下一状态。
4. **回扣物**：结尾产品定格重新解释前面所有状态。

产品不是中途插入的广告，而是整条片子的操作系统。

### 为什么成立

- “喝”是饮品真实动作，因果无需解释。
- 味道和口感看不见，但姿态、颜色、动作速度和生活场景看得见。
- 相同规则重复三至四次，观众会等待下一口带来什么。
- 每次变化同时改变多个层级，比单纯换装的信息奖励更大。
- 固定瓶形降低理解成本，让快速切换仍然保持统一。

## 三、饮品感受外化模型

拿到新饮品时，按以下链路设计：

```text
可验证产品事实
→ 入口瞬间的感官线索
→ 身体动作或节奏
→ 主观情绪
→ 身份/场景/物理规则
→ 真实产品或饮用场景回扣
```

### 1. 产品事实

先记录：温度、气泡、酸甜苦辣、浓稠度、香气、颜色、原料、饮用方式、包装动作和适合场景。配方、咖啡因、电解质、糖分、功效和适用人群只能使用可核实资料。

### 2. 感官线索

| 感官线索 | 可用视觉语法 | 不是功效承诺的情绪联想 |
|---|---|---|
| 强气泡 | 反重力、弹跳、快速上升、密集圆点 | 活跃、释放、玩心 |
| 冰凉 | 空间打开、冷雾边缘、蓝白闪切、速度重置 | 清爽、喘息、重启 |
| 酸 | 锐利折线、快速聚焦、表情收紧后展开 | 醒神感、俏皮刺激 |
| 甜 | 柔软形状、明亮色块、轻盈摆动 | 愉悦、安慰、分享 |
| 苦/烘焙 | 深色层次、机械启动、节拍逐层加入 | 成熟、专注仪式 |
| 浓郁/绵密 | 硬边变软、空间包裹、速度减慢 | 放松、满足、温和 |
| 辛辣 | 点火、热浪、红色节拍、动作升级 | 热烈、挑战、聚会 |
| 茶香/花香 | 空间延展、季节变化、记忆物件出现 | 从容、回忆、松弛 |

这些是创意联想，不是客观健康或功能结论。文案使用“像、仿佛、这一刻的感觉”，不要写成未经证实的生理功效。

### 3. 状态卡

每一口只设计一个主状态：

```text
状态名称：
产品依据：
入口动作：
身体反应：
情绪：
临时身份：
场景或物理规则：
服装：
3-5 个必要道具：
主色与运动方向：
触发音：
回到产品的证据：
```

同一状态不要堆十几个不相关道具。每个道具都要帮助观众在一秒内读懂身份或场景。

## 四、跨饮品举一反三

| 品类 | 一口后的核心变化 | 可重复状态 | 结果回扣 |
|---|---|---|---|
| 碳酸饮料 | 重力和节奏被气泡打乱 | 宅家音乐、街头、聚餐、泳池 | 开盖气泡、冰杯和产品特写 |
| 气泡水 | 每口减少一层环境噪声，空间变透明 | 通勤、会议后、运动后 | 气泡与真实饮用场景，不暗示治疗压力 |
| 咖啡 | 日常界面逐步启动 | 清晨开机、创作、会议、夜间阅读 | 研磨、萃取、香气和真实咖啡信息 |
| 茶 | 每口切换一种时间与节奏 | 清晨、午后、雨天、夜读 | 茶汤颜色、叶底、冲泡方式和香气描述 |
| 果汁 | 颜色带人物进入原料世界 | 柑橘阳光、莓果舞台、热带雨林 | 使用真实水果/含量信息，避免虚构天然或健康 |
| 牛奶/乳饮 | 周围硬边逐渐柔软，动作变慢 | 早餐、烘焙、夜间小憩 | 质地、奶泡、搭配和真实成分 |
| 酸奶/奶昔 | 浓稠度把道具吸入同一节奏 | 早餐碗、通勤杯、运动后加餐 | 倒出、挂壁、配料和真实营养信息 |
| 运动饮料 | 每口切换一种训练场景或节拍 | 跑步、球场、骑行、恢复阶段 | 电解质等文案必须有配方依据，不承诺提升成绩 |
| 热巧克力/热饮 | 环境从冷硬变为温暖包裹 | 冬夜、雨天、沙发、分享 | 蒸汽、温度、搅拌和口感 |
| 草本/功能饮品 | 每口点亮一个经过证实的成分模块 | 工作、通勤、夜间等真实场景 | 只展示合规成分与用途，不使用治疗隐喻 |
| 鸡尾酒/酒饮 | 每口切换一种社交类型或音乐类型 | 屋顶、晚餐、舞池、独处聆听 | 成年人、适量饮用；不与驾驶、勇气或能力提升绑定 |
| 汤饮/代餐饮品 | 温度或饱满质地重建一个生活时刻 | 早餐、办公室、旅行、深夜 | 真实份量、原料和食用方式，不夸大饱腹或健康功效 |

## 五、不只换装的七种扩展

### 1. 一口一套物理规律

第一口失重，第二口时间加速，第三口空间变宽，第四口所有气泡定格。适合强调气泡、冰凉或层次口感。

### 2. 一口一段音乐编制

第一口加入鼓点，第二口加入贝斯，第三口加入人声，第四口组成完整乐队。适合咖啡、碳酸、调饮；真实开盖、倒入和冰块声可成为节奏采样。

### 3. 一口一层味觉角色

酸、甜、香、气泡分别拟人成调音师、灯光师、鼓手和舞者，最后共同完成一场演出。适合多层风味饮品，但不得虚构配方中不存在的味型。

### 4. 一口一个目的地

瓶身像登机门，每口进入一个与真实口味或消费场景相关的地点。适合茶、咖啡、果汁和地域风味饮品。

### 5. 一口一次情绪卸载

每喝一口，人物身上的一层可见负担变成轻物件离开：通知、噪声、拥挤、待办。适合水、茶和轻饮；表达主观放松，不承诺治疗焦虑或压力。

### 6. 一口让同一空间换季

人物位置不动，光线、衣着、窗外天气和桌面物件依次变化。适合茶、咖啡和季节限定饮品，AI 制作稳定且不需要复杂实景。

### 7. 一口传给下一个人

同一瓶/杯通过动作匹配传递给不同人物，每个人获得不同状态，最后汇成同一聚会。适合分享装和社交饮品；必须保持包装、容量和递接方向一致。

## 六、创意筛选规则

每个方案通过以下检查：

1. 不看文案，能否看懂“喝一口导致变化”？
2. 每种变化是否来自饮品真实口感、原料、温度或场景？
3. 第二、第三次是否增加新奖励，而非只换颜色？
4. 产品是否持续承担触发、容器、转场或回扣中的至少两个角色？
5. 去掉品牌和样本人物后，机制是否仍能服务新饮品？
6. 幻想结束后，是否回到真实包装、饮用动作或成分/口感证据？
7. 是否把主观感受误写成健康、提神、解压或运动功效？

## 七、AI 制作策略

这类片子适合“图片生成 + 平面动画 + 少量短视频”，不需要让视频模型连续生成四次喝水和四次变装。

### 推荐拆法

1. 使用真实产品图锁定瓶形、瓶盖、标签和液体颜色。
2. 生成一张人物身份母图，派生 3-4 张状态全身图。
3. 每张状态图锁定人物身份、瓶子所在手、身体方向和人物占比。
4. 为每个状态单独生成 3-5 个透明背景道具，后期环绕人物排布。
5. 在后期制作瓶形蒙版、品牌色背景、状态词和大瓶擦除转场。
6. 只在开盖、举瓶、入口或状态间动作确有需要时生成 4-5 秒短视频。
7. 从短视频中只截取最稳定的 0.5-1.2 秒，不把生成时长当成成片时长。
8. 结尾使用真实包装与后期文字，禁止 AI 重绘商标、标签和合规信息。

### 关键帧

- **状态母帧**：人物、产品、瓶形蒙版位置和品牌色构图。
- **入口帧**：瓶口准确接近嘴部，但避免复杂吞咽特写。
- **状态结果帧**：人物完成身份变化，产品仍在同一只手。
- **转场帧**：完整产品瓶覆盖画面，提供干净遮挡边界。
- **Packshot**：真实商品图、合法广告语和必要合规信息。

### 提高成功率

- 每个生成任务只做一个状态，不生成整条多世界连续视频。
- 把人物抠图、瓶形、道具、文字和产品拆成独立图层。
- 用构图规则而非真实场景连续性维持统一。
- 商品标签、容量、成分和品牌文字始终使用真实素材或后期。
- 先完成无文字画面，再由后期添加可控排版。
- 音效使用“开盖→气泡/倒入→吞咽→状态切换→场景提示音→产品落点”的因果链。


## 八、使用边界

- 本案例只迁移“一口一状态”的机制，不复制样本人物、服装、品牌色、瓶形、道具组合、广告语、音乐和具体转场资产。
- 食品饮料的成分、营养、提神、解压、补水、减脂和运动表现必须有证据。
- AI 人物和幻想场景只能表达主观感受，不能冒充实验结果或真实用户证言。
- 酒饮必须遵守平台、地区、年龄和责任饮酒要求。
