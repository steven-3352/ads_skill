## 核心创意机制

### 1. 把“持续时间”转译成“后台夜班”

夜间产品的传播困难是作用过程看不见、等待时间长。该片没有用钟表或进度条解释时间，而是让多个分身在用户闭眼后继续工作。

```text
用户停止主动操作
-> 产品世界开始运转
-> 后台角色执行多个维护动作
-> 用户在现实中获得一个完成后的状态
```

这是一种“时间代理”机制：后台角色替观众度过等待过程。它适合确实存在静置、循环、充电、发酵或自动运行的商品，但画面不能替代功效证据。

### 2. 用“语义接力”代替随机蒙太奇

相邻镜头至少共享一个可辨认锚点：动作、形状、材质、尺度或含义。

|上一镜|共享锚点|下一镜|
|---|---|---|
|触摸真实头发|头发|巨型发丝滑梯|
|黑色发丝地形|材质/方向|白底人物的发型|
|产品瓶身|产品/香味联想|围绕瓶身的植物|
|植物漂浮|气味/梦境|花草包围的头发|
|微缩维护|护理任务|真实按压与抹开|
|闭眼白底人物|睡眠状态|真实卧室安睡|

这种接力让世界不断变化，却不需要旁白解释。评审时应要求每个切换能回答“上一镜的哪个线索把我带到这里”。

### 3. 用尺度变化把普通材质变成可游览空间

头发既是待护理对象，也是滑梯、地形、巨大设施和维护现场。一个产品对象在不同尺度下承担不同叙事职责，单位素材的信息密度因此提高。

### 4. 让商品同时承担入口、能量源和现实锚点

瓶身并非只做片尾 packshot：它在幻想入口出现，在维护世界中与巨大头发同框，在真实使用段触发涂抹，最后回到床头。反复出现解决了奇观可能盖过品牌的问题。

### 5. 用多个“自己”代替陌生专家

维护人员全部由主角分身构成。这样既保留统一的视觉身份，也隐喻“睡着的我”和“替我工作的产品”之间的关系，避免突然引入不相干角色。

## 为什么可能有效（待投放验证）

- **认知落差**：日常摸头发后突然缩小并滑行，2-5 秒形成第一次强奖励。
- **规则好奇**：观众会继续确认黑色表面是什么，以及滑行最终到哪里。
- **抽象卖点可视化**：把夜间、香气、涂抹和护理组织成同一个梦境系统。
- **品牌记忆**：琥珀瓶身在白底与床头多次出现，颜色和轮廓稳定。
- **低文案依赖**：除片尾外几乎不靠字幕，便于跨语言观看。

这些只是从成片结构推导的假设。是否提高 3 秒停留、完播、品牌回忆或转化，需要与普通睡前演示版本做对照测试。

## 局限与可优化处

1. **首秒偏常规**：前 1.77 秒是摸头发的生活画面，异常事件来得稍晚。可测试 0 秒先放“微缩人物滑过发丝”，0.8 秒后再回到卧室解释来源。
2. **真实使用动作出现较晚**：完整按压约在 15 秒后。转化版可在 2-4 秒插入一次按压，让商品动作更早成为梦境的触发器。
3. **功效证明较弱**：光泽发型、植物和维护场景属于视觉表达，不能证明修护、柔顺、留香时长或任何“8H”效果。若投放目标是转化，应补充经证实的使用方法、前后对比或合规测试结论。
4. **微缩工具容易稀释商品因果**：滚筒、吹风机等道具产生观看乐趣，但可能让观众误以为任何护发产品都能替换。应让瓶身按压先触发夜班，或让分身使用与真实涂抹路径一致的动作。
5. **CTA 偏品牌氛围**：片尾短句完整，但没有显式购买或了解路径。内容种草可保留；电商版本需要商品卡、搜索词或明确下一步。

## 可迁移公式

```text
一个日常的完成前状态
+ 一个真实的启动动作
+ 一条进入产品内部世界的语义路径
+ 一个替用户度过等待过程的后台系统
+ 两个以上真实结果证据
= “人离场后，产品仍在完成任务”的可视化故事
```

迁移时保留的是“时间代理 + 语义接力 + 尺度世界 + 现实回环”，不是复制黑发滑梯、白衣分身、花草、卧室或同款音乐。

|证明|纯梦境与片尾短句|结尾增加真实用量/发丝前后或经证实卖点|点击率、加购率、评论异议|
|片长|22 秒品牌叙事版|12-15 秒转化压缩版|完播率、转化率|

停止条件不能预设统一数值，应根据账号基线、样本量和投放成本确定。没有显著差异时先更换 Hook，不要同时重做世界观、证明和 CTA。

## 知识库候选规律

以下内容可加入机制库，但在获得投放数据前不应写入“已验证的创意规律”：

- 对“夜间、自动、静置、循环、缓慢形成”的商品，后台夜班可以压缩不可见时间。
- 跨越多个幻想场景时，用动作、形状、材质、尺度或含义做语义接力，可能比随机特效更易理解。
- 当奇观世界与商品距离较远时，产品需要在入口、中段触发、结果和片尾至少承担两个不同职责。
- 视觉化功效不能代替功效证明；幻想段负责记忆，真实操作与证据段负责购买理由。
