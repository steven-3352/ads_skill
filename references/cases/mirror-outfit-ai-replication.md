## 核心机制

```text
早晨不知道穿什么
→ 手机像角色皮肤选择器
→ 点击触发服装瞬时替换
→ 户外照片证明穿上后的场景效果
→ 选中最终造型并出门
```

真正可迁移的不是服装，而是：

```text
可选择的多个状态
→ 清晰操作
→ 立即反馈
→ 快速结果预览
→ 最终选择进入真实使用
```

适用品类包括颜色/模式/口味/组合明确的商品，如眼镜、箱包、家具配色、灯光模式、饮品口味、耳机音效和软件模板。

本案例的进一步跨品类思维蒸馏见 `references/creative-transfer-thinking.md`。迁移时使用其中的心理外化、平行结果、因果开关、角色权力、结果蒙太奇和重复升级，不复制本案的手机界面、卧室、服装或白闪。

## 已验证的制作方法

### 1. 先锁定背景母图，再生成分段视频

仅在提示词中重复写“同一个卧室”不能稳定空间。先生成一张无人物背景母图，再让每个人物片段共同引用；同时统一机位、光向、人物站位和景别。

本案固定条件：同一卧室、正面机位、左侧晨光、人物中央站位。镜面方案因反射关系和人物越框导致变形，最终改为普通卧室正面构图。

### 2. 把多套换装放在一条视频中，优先保连续性

分别生成三套造型会产生人物比例、五官和背景漂移。本案把黑、白、深蓝三套服装放进同一条 15 秒生成任务，使人物、手机、房间和光线基本连续，再从中截取稳定动作。

生成时长不是成片时长。15 秒素材最终只保留每套最明确的 1-1.7 秒动作。

### 3. 用生成视频的稳定帧派生照片

户外效果图不再凭文字重建服装，也不使用早期造型图。直接从已通过的视频截取黑、白、深蓝稳定帧，将该截图作为人物和整套服装的唯一真值来源，只允许模型改变背景、姿势和去掉手机。

这一规则减少了多参考图互相拉扯、衣服重新设计和人物身份漂移：

```text
先获得稳定视频状态
→ 截取状态帧
→ 用状态帧派生同状态照片
→ 照片回到剪辑中增加信息密度
```

### 4. 照片不是补画面，而是节奏工具

每套服装配置一张全身动态图和一张中景细节图。每张只使用约 0.3-0.6 秒，并用轻微推近/拉远制造运动。照片承担两个作用：快速证明户外使用效果；在不增加 AI 人物连续运动风险的情况下提升画面变化频率。

### 5. 按信息变化剪辑，不按素材长度剪辑

原始 AI 中段每套衣服停留 3-7 秒，虽然动作自然，但单位时间新信息太少。快剪版将手机、人物和户外照片交替排列，平均每 0.3-1.6 秒产生一次变化，总时长压缩到 13.8 秒。

有效节奏单元：

```text
手机选择 0.6-1.4 秒
→ 3 帧白闪
→ 穿搭动作 1-1.7 秒
→ 两张效果照片共 0.6-0.9 秒
→ 下一次选择
```

### 6. 声音负责确认因果

点击声、白闪电子切换声与画面变化必须发生在同一切点；衣料和脚步声只强化真实感。内部样片暂用源片音轨验证节奏，但正式发布必须替换为已授权或可商用音乐与拟音。

## 失败路径与修正

| 失败 | 原因 | 修正 |
|---|---|---|
| 镜中人物变形、人物越出框 | 视频模型难以同时维护真人、反射和框内空间关系 | 删除镜面机制，改成普通固定卧室 |
| 人物太靠近镜头 | 提示词使用腰部以上、中景等近景指令 | 明确距离、焦段、全身构图和人物占比 |
| 分段视频背景不一致 | 只靠文字描述“同一房间” | 创建无人物背景母图并让所有镜头引用 |
| 真人公网图片被隐私规则拦截 | 写实真人参考图不是 Active Asset | 使用同 Asset Group 中认证并激活的素材 URI |
| R2V 请求返回 400 | Seedance 2.0 mini 多参考图模式不支持 `camera_fixed` 参数 | 删除接口字段，将固定镜头写入提示词 |
| 合并视频看起来慢 | 每套造型停留太久、人物大部分时间静止 | 剪掉等待帧，插入手机和短照片蒙太奇 |
| 户外图可能重建设计服装 | 文字描述与旧造型参考不足以锁定新视频状态 | 从成功视频截帧，作为人物和服装的唯一参考 |
| 结尾手机凭空消失 | 未检查中段末帧状态 | 截取末帧检查，要求结尾从右手持手机开始 |

## 可复用生产顺序

1. 抽象“选择 → 触发 → 变化 → 结果”的单一规则。
2. 生成并确认无人物背景母图。
3. 确定一个人物身份锚点；真人素材遵守平台认证与 Asset Group 规则。
4. 优先把多个状态放进同一条生成视频，减少跨任务漂移。
5. 从成功视频截取每个状态的稳定帧。
6. 以稳定帧为唯一参考，派生场景效果照片和细节照片。
7. 先做信息节奏表，再裁剪视频；不要把 AI 输出时长当作必须使用的时长。
8. 用手机/操作近景分隔各状态，用 2-4 帧闪白或硬切确认触发。
9. 在音乐重拍上对齐点击、变化和照片切换。
10. 检查人物身份、服装、手、手机、背景和动作状态连续性。
