# 口播驱动情感短剧：分镜设计操作系统

> 本文是一份**可执行的分镜设计手册**，回答"做这类 AI 情感短剧，逐镜要考虑哪些维度、碰到什么该怎么设计"。
> 证据来自两条"棉花糖"样本；方法部分标注 `事实 / 推断 / 待验证假设`，迁移时只继承机制，不复制人物、台词、场景或音乐。

- 投放验证：无账号后台数据，任何"留存/催泪/转化"判断均为**待投放验证假设**，不得写成已验证规律

## 一句话结论

这类片的"丝滑"不来自转场技巧，而来自一套**文案逐句拆镜**的流水线：

```text
先写一段连续的第一人称独白/对话（唯一真正手写的东西，自带情绪曲线）
→ 按语气切成一句一句（每句 3~4 秒可读完）
→ 每句配 1 个镜头，情绪重的句子配 2 个（全景+特写）
→ 镜头只在同一场景里换景别，不跳地点/不跳光/不跳人
→ 全程一条连续音频（独白/对白/BGM），画面切、声音不切
→ 一个情绪道具（物证）反复插入做接力
→ 结尾一张金句标题卡当 CTA
```

你觉得"像规则跑出来的分镜"——它就是。不是导演在设计每个转场，是"文案切句"在决定镜头数量与落点。

### 口播骨架样本（读自 V1 烧录字幕/气泡，非全量）

- 妈妈微信气泡："晚晚，粥到了，记得趁热喝。"
- 女儿："妈"→ 拨号画面"您拨打的用户已关机"（妈妈已逝的异常信号）
- 闪回当年女儿嫌唠叨："妈我都多大了""外面的饭吃多了不行"
- 护士转述："她不想拖累你""她走之前一直在手机上改备注""她说女儿不爱听她唠叨"
- 崩点台词："妈我错了" → 金句卡："莫要让遗憾成为常态，多回家看看"

**结论（推断）**：台词/聊天文字是全片真正的骨架，画面是逐句配上去的插图。

## 核心机制：丝滑的 4 个技术开关

1. **音频永不断**（第一功臣）：一条连续口播/对白 + BGM，从头到尾不切。画面在切、声音不切，耳朵听到的是完整一段话，眼睛就接受了画面跳动。
2. **一句台词 = 1~2 个镜头**：分镜由"文案切句"生成，故显得规则化、匀速。
3. **切景别，不切场景**：同场景、同人物服装、同灯光，只在 全景→中景→特写→道具空镜 之间切；位置/光/人都不跳，再多切点也不"硌"。
4. **匀速镜长 + 道具接力**：锁 3~4s/镜踩 BGM；一个情绪道具反复插入，在镜间"传手"形成视觉线索。

> 判断丝滑的根本标准（呼应 `video-production-sop.md` §9 [C]/[R] 门）：**决定留不留人的是"每秒有没有新推进"，不是"几秒一切"。长镜只要镜内持续推进，一样留得住人；短切只要句意有停顿，切了也不硌。**

## 辨析：感觉丝滑 ≠ 切得少（实测校验基准）

拆解这类片最常见的误判是"看着舒服所以一定是长镜慢剪"。用 V2 的 ffmpeg 镜头切点检测(scene≥0.3)证伪：

| 指标 | 数值 |
|---|---|
| 镜头段数 | 96 |
| 平均镜长 | 3.52s |
| **中位数镜长** | **2.63s**（一半镜头短于 2.6s） |
| 镜长 ≥5s 占比 | 16% |
| 镜长 ≥8s 占比 | 4% |
| 最长镜 | 18.57s（个别） |
| 前 12 秒切点 | 5.6 / 8.6 / 10.5 / 11.9（4 刀） |

**事实**：这条片是 **2~3 秒快切主导**，不是长镜慢剪。少数 5~18s 的长镜只在情绪节点出现。

**结论（推断）**：它"看着像连续长镜、很舒服"，是因为 **连续音频 + 同一场景 + 统一暖色 + 同一时刻的多景别切换** 把快切抹平了——观众的注意力被连续的声音和不变的空间/色调接住，感觉不到切点。

**方法论校验规则**：拆解任何"看着舒服"的片子，先用镜头切点检测拿到中位镜长再下结论；不要凭观感判断"切得多还是少"。**"感觉丝滑"和"切得少"是两件事**——前者是音频/空间/色调抹平的结果，后者是可测量的剪辑事实，二者常常相反。若照"感觉"去复刻，容易把"快切+连续音频"误抄成"慢剪长镜"，成因错了效果就散。

# 分镜设计操作系统（做新片时从上往下走一遍）

## ① 全片级：拆镜之前先定这 8 件事

| 要素 | 怎么定 |
|---|---|
| 1 母题 + 结尾金句 | **先写结尾金句**，全片倒推，所有镜头为它服务 |
| 2 情绪曲线 | 套模板：`日常铺垫→异常信号→愧疚/矛盾闪回→物证/第三方证词→崩点→金句升华` |
| 3 人物一致性锚点 | 定死长相/发型/服装/年龄，写成"角色卡"每镜复用（AI 一致性命根） |
| 4 场景清单 | 定死每个场景的布景+灯光+色温，同一场景不跳光 |
| 5 情绪道具（物证） | 选 1 个反复出现的锚点物，承担"证据"职能 |
| 6 音频骨架 | 一条连续口播/对白 + 一条 BGM，从头不断 |
| 7 节奏呼吸 | 匀速 3~4s 打底 + 崩点/金句处 2~3 个 6~7s 长镜（快铺垫—慢崩点） |
| 8 时长/镜头数预算 | 时长=音频长度；镜头数 ≈ 时长 ÷ 3.6 |

## ② 镜头级：每个镜头都要填的 12 个维度（=镜头表列头）

1. **对白/口播句**（一切起点，先有句再有镜）
2. **景别**：远/全/中/近/特/大特——情绪越重，景别越近
3. **机位角度**：平视(默认)/俯(压抑)/仰(压迫)/过肩(关系)/主观 POV(代入)
4. **运镜**：固定/缓推/拉/摇/横移/跟——长镜必须有运镜，短镜多用固定
5. **镜头类型**：见③
6. **光/色温**：暖=温情/回忆，冷白=医院/疏离，一束光=锁情绪，明暗对比=内心
7. **景深**：崩点/物证用浅景深虚化背景锁主体
8. **表演/动作**：表情 + 至少一个微动作（手抖、别过头、指尖触碰）——没动作会拖
9. **本镜新信息**：比上一镜多给了什么？答不出→是水，删
10. **声音层**：对白/拟音/环境/留白，四选几（别全拉满）
11. **剪辑点/转场**：硬切/匹配切/遮挡切/叠化/闪白——切在语意停顿处
12. **时长**：由"对白长度+动作完成"决定，不是拍脑袋

## ③ 8 种镜头类型（"除了人物镜/物品镜还有什么"）

| 类型 | 职能 | 设计要点 |
|---|---|---|
| 1 人物镜 | 给**情绪** | 近景/特写，表情+微动作 |
| 2 物品镜 | 给**物证** | 见下方"物品镜 6 规则" |
| 3 空镜/环境镜 | 交代时空 + 情绪喘息 + **盖转场** | 无人画面，≤3s（窗外雨、空椅、走廊、餐桌） |
| 4 主观镜 POV | **代入感** | 拍"她看到的东西"（看手机屏=她视角） |
| 5 闪回镜 | 过去时 | **换装=时间标记**（现实线与回忆线人物穿不同衣服，观众自动识别时空，无需字幕说"一年前"）+ 调色区分（偏暖/偏旧）+ 叠化/闪白进出。V2 现实线粉开衫、回忆线恐龙睡衣/格纹衫即此法 |
| 6 界面镜 | 叙事驱动（**本类片独门主力**） | 聊天气泡/通话/短信，文字后期贴 |
| 7 关系镜/双人镜 | 表现**两人距离** | 过肩正反打、同框（近=亲密，远=疏离） |
| 8 细节镜 | **放大情绪** | 眼、嘴角、手的大特写 |

**组合规律**：情绪段=人物镜+细节镜；叙事段=界面镜+物品镜；转折处=空镜换气；对峙=关系镜正反打；回忆=闪回镜调色。

### 物品镜 6 规则（物品承担"物证/接力/崩点触发器"）

1. **景别**：特写/大特写，物品占画面主体，不当背景
2. **必须带手**：手在拿/翻/放/触碰——手=动作=每秒推进，且人物在场
3. **插入接力**：夹在"人物说→物品证→人物反应"中间，做正反打的物品版
4. **首次全貌，之后局部**：第一次给建立镜，之后只给局部且每次读出一个新信息
5. **浅景深+一束光**锁视线
6. **信息可读**：气泡/备注/数字/纸条必须清楚；崩点常由"看清物品某细节"触发，字糊崩点就废——**文字后期贴，别靠模型写**

## ④ 声音层：不止对白（6 层）

| 层 | 作用 | 注意 |
|---|---|---|
| 连续口播/独白 | 骨架、盖所有切点 | 绝不断——丝滑第一功臣 |
| 对白 | 推剧情 | |
| BGM | 情绪 + 节拍（定镜长踩点） | 崩点前可降弱 |
| 拟音 | 物品镜真实感 | 粥咕嘟、消息叮、翻纸声 |
| 环境声 | 空间真实 | 雨、钟、走廊回声 |
| 留白(静默) | 崩点前半秒静音 | 最催泪的武器，别舍不得用 |

## ⑤ 转场/衔接：7 个技术开关

1. 音频连续（盖切点，占一半功劳）
2. 匹配剪辑（动作/形状/视线匹配）
3. 遮挡切（手、门、身体扫过瞬间切）
4. 空镜过渡（两段间插 3s 空镜换气）
5. 闪白（闪回进/出）
6. 叠化（梦境/回忆）
7. 同场景多景别（不跳地点/光，再多切不硌）

## ⑥ 文字/字幕层

- 台词字幕：统一底部安全区、统一样式，静音可懂
- 界面文字（气泡/备注/数字）：**后期贴**，别靠 AI 生成（必糊）
- 金句标题卡：结尾黑底白字 = CTA

## ⑦ AI 生成专属约束（本类片是 AI 做的，必须单列）

| 碰到 | 怎么办 |
|---|---|
| 人物要一致 | 固定角色卡/参考图，每镜提示词写"保持长相服装不变" |
| 场景要一致 | 固定场景参考图 |
| 画面里要有字 | 后期贴，不让模型生成 |
| 多手指精细/多人连续互动 | 拆多个短片段，或改静帧+局部动 |
| 崩点要稳定运镜 | 先测试，糊就降级为"静帧+缓推+背景微动" |
| 需要精确动作终点 | 用首尾帧（FL2VA）控制起止 |

## ⑧ "碰到 X 怎么设计"决策树（执行时直接查）

```text
一句长台词(6s+)   → 能稳定运镜? 是→6~7s运镜长镜  否→拆2个3s短切
情绪崩点          → 大特写 + 浅景深 + 6~7s长镜 + 崩前留白半秒 + 细节镜(颤抖的手)
要甩出物证        → 物品镜:怼近+带手+可读+夹在"人物说—人物崩"中间
闪回/回忆         → 调色区分(偏暖旧) + 闪白或叠化进出
两人对峙          → 过肩正反打 + 一个同框关系镜(用距离表态度)
转场怕"硌"        → 插空镜换气 + 保证音频连续 + 同场景切景别
某镜"说不出新信息" → 删掉,或并进相邻镜
AI生成不稳定       → 降级:静态人物层 + AI背景微动 + 后期字幕,创意不变、证明降级
```

## 逐句拆镜工作流

1. 填①（全片 8 件事），先把结尾金句和情绪曲线定死
2. 写完整连续口播/对白，按语气切成一句一句
3. 每句用⑧决策树选镜头类型与拍法（长镜 or 短切）
4. 用②的 12 维把每镜写进上面的镜头表
5. 用③④⑤⑥补齐镜型/声音/转场/文字
6. 最后过⑦的 AI 约束逐条检查，标注需降级或后期贴字的镜头
7. 生成 → 剪辑时保证音频一条到底、镜长匀速踩 BGM、崩点留白

## 边界与合规

- 情感短剧靠共情，不靠虚构：**不得编造真实事件、伪造用户经历、假冒真人**；AI 生成的人物/场景需按平台要求标注（本类样本已带"AI生成"水印）。
- 不用"卖惨/制造虚假焦虑"替代内容推进；情绪转折要有可见行为与原因（呼应 SKILL.md：写"从X到Y"必须补出可见行为与变化原因）。
- 若挂接商品，商品只能承担功能/感官/关系媒介角色，不得把商品写成人格价值来源；功效/价格/对比需证据与合规边界。
- 金句卡是价值观表达，不是疗效承诺。

## 可迁移公式

```text
一句自带情绪的连续独白/对话
+ 逐句拆镜(一句 1~2 镜)
+ 同场景多景别(不跳地点/光/人)
+ 一条永不断的音频盖住所有切点
+ 一个反复接力的情绪道具(物证)
+ 崩点处的长镜运镜 + 半秒留白
+ 结尾金句标题卡
= "画面一直在切,却像一段完整的话"的丝滑情感短剧
```

迁移时保留的是"口播骨架 + 逐句拆镜 + 连续音频 + 同场景多景别 + 道具接力 + 崩点留白"这套机制，不是复制粥、存折、护士、夫妻或同款 BGM。

## 知识库候选规律（待投放验证，勿写成已验证）

- 连续音频 + 同场景多景别，可能比精心设计的转场更能制造"丝滑"感。
- 匀速 3~4s/镜 + 崩点处 2~3 个 6~7s 长镜的"呼吸"结构，可能优于全程等速快切。
- 界面镜（聊天/通话/短信）在情感短剧里信息密度高、生成成本低，可能是本类片的性价比主力。
- 物品镜"带手 + 可读 + 每次新信息"三条，可能是避免长镜拖沓的关键。
