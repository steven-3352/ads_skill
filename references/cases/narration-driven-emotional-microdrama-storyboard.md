## 案例状态

- 品类：口播/独白驱动的情感短剧（AI 3D 动画质感，皮克斯风）。
- 样本：V1《妈妈走了粥还热着》、V2《我爱的是你不是车房》，均 AI 生成、带“AI生成”水印。

## 一、事实档案（案例实证，方法论不承载）

### 结构与节奏（两片一致）

| | V1 妈妈走了粥还热着 | V2 我爱的是你不是车房 |
|---|---|---|
| 时长 / 切点数 | 289s / ≈78 | 347s / ≈97 |
| **平均镜长** | **3.7s** | **3.6s** |
| 风格 | 3D 动画（皮克斯质感），AI 生成 | 同 |
| 题材 | 子欲养而亲不待 | 物质 vs 真心 |
| 情绪曲线 | 收粥→拨号"已关机"→嫌唠叨闪回→护士转述妈临终改备注→"妈我错了"→金句卡 | 争吵→"要车要房"→付出闪回→翻存折/日记物证→和解→金句卡 |

平均 3.6~3.7 秒/镜、恒定匀速，踩在 BGM 上（事实）。

### 口播骨架样本（读自 V1 烧录字幕/气泡，非全量）

- 妈妈微信气泡："晚晚，粥到了，记得趁热喝。"
- 女儿："妈"→ 拨号画面"您拨打的用户已关机"（妈妈已逝的异常信号）
- 闪回当年女儿嫌唠叨："妈我都多大了""外面的饭吃多了不行"
- 护士转述："她不想拖累你""她走之前一直在手机上改备注""她说女儿不爱听她唠叨"
- 崩点台词："妈我错了" → 金句卡："莫要让遗憾成为常态，多回家看看"

**结论（推断）**：台词/聊天文字是全片真正的骨架，画面是逐句配上去的插图。

### ffmpeg 镜长实测（"感觉丝滑 ≠ 切得少"的证据）

用 V2 的镜头切点检测(scene≥0.3)：

| 指标 | 数值 |
|---|---|
| 镜头段数 | 96 |
| 平均镜长 | 3.52s |
| **中位数镜长** | **2.63s**（一半镜头短于 2.6s） |
| 镜长 ≥5s 占比 | 16% |
| 镜长 ≥8s 占比 | 4% |
| 最长镜 | 18.57s（个别） |
| 前 12 秒切点 | 5.6 / 8.6 / 10.5 / 11.9（4 刀） |

**事实**：这条片是 **2~3 秒快切主导**，不是长镜慢剪；少数 5~18s 长镜只在情绪节点出现。它"看着像连续长镜"是被 **连续音频 + 同一场景 + 统一暖色 + 多景别切换** 抹平的。

> 这条实测是方法论 §6「节奏诊断：先测中位镜长再下结论」的原始证据。诊断方法与结论以 `storyboard-methodology.md` §6 为准，本文只留数据。

## 二、明细清单（本类片可直接填，方法论指向这里取细节）

### ① 镜头级 12 维（=镜头表列头）

1. **对白/口播句**（一切起点，先有句再有镜）
2. **景别**：远/全/中/近/特/大特——情绪越重，景别越近
3. **机位角度**：平视(默认)/俯(压抑)/仰(压迫)/过肩(关系)/主观 POV(代入)
4. **运镜**：固定/缓推/拉/摇/横移/跟——长镜必须有运镜，短镜多用固定
5. **镜头类型**：镜型学与 8 类定义见 `storyboard-methodology.md` §4
6. **光/色温**：暖=温情/回忆，冷白=医院/疏离，一束光=锁情绪，明暗对比=内心
7. **景深**：崩点/物证用浅景深虚化背景锁主体
8. **表演/动作**：表情 + 至少一个微动作（手抖、别过头、指尖触碰）——没动作会拖
9. **本镜新信息**：比上一镜多给了什么？答不出→是水，删（对应 SOP §9 [C] 逐拍不可删）
10. **声音层**：对白/拟音/环境/留白，四选几（别全拉满）——6 层见下
11. **剪辑点/转场**：硬切/匹配切/遮挡切/叠化/闪白——切在语意停顿处
12. **时长**：由"对白长度+动作完成"决定，不是拍脑袋

### ② 物品镜 6 规则（物品承担"物证/接力/崩点触发器"）

1. **景别**：特写/大特写，物品占画面主体，不当背景
2. **必须带手**：手在拿/翻/放/触碰——手=动作=每秒推进，且人物在场
3. **插入接力**：夹在"人物说→物品证→人物反应"中间，做正反打的物品版
4. **首次全貌，之后局部**：第一次给建立镜，之后只给局部且每次读出一个新信息
5. **浅景深+一束光**锁视线
6. **信息可读**：气泡/备注/数字/纸条必须清楚；崩点常由"看清物品某细节"触发，字糊崩点就废——**文字后期贴，别靠模型写**（对应 SOP §13）

> 镜型组合规律：情绪段=人物镜+细节镜；叙事段=界面镜+物品镜；转折处=空镜换气；对峙=关系镜正反打；回忆=闪回镜调色。（8 镜型定义见 §4 镜型学）

### ③ 声音层 6 层

| 层 | 作用 | 注意 |
|---|---|---|
| 连续口播/独白 | 骨架、盖所有切点 | 绝不断——丝滑第一功臣 |
| 对白 | 推剧情 | |
| BGM | 情绪 + 节拍（定镜长踩点） | 崩点前可降弱 |
| 拟音 | 物品镜真实感 | 粥咕嘟、消息叮、翻纸声 |
| 环境声 | 空间真实 | 雨、钟、走廊回声 |
| 留白(静默) | 崩点前半秒静音 | 最催泪的武器，别舍不得用（>2s 静默铺 room tone，见 SOP §9 R3） |

### ④ 转场/衔接 7 个技术开关

1. 音频连续（盖切点，占一半功劳）
2. 匹配剪辑（动作/形状/视线匹配；剪辑点运动连续性=动接动/静接静，机制见 SOP §8.4）
3. 遮挡切（手、门、身体扫过瞬间切）
4. 空镜过渡（两段间插 3s 空镜换气）
5. 闪白（闪回进/出）
6. 叠化（梦境/回忆）
7. 同场景多景别（不跳地点/光，再多切不硌）

### ⑤ AI 生成专属约束

| 碰到 | 怎么办 |
|---|---|
| 人物要一致 | 固定角色卡/参考图，每镜提示词写"保持长相服装不变"（对应关键帧母板锚定，SOP §8.2/§12） |
| 场景要一致 | 固定场景参考图 |
| 画面里要有字 | 后期贴，不让模型生成 |
| 多手指精细/多人连续互动 | 拆多个短片段，或改静帧+局部动 |
| 崩点要稳定运镜 | 先测试，糊就降级为"静帧+缓推+背景微动" |
| 需要精确动作终点 | 用首尾帧（FL2VA）控制起止 |

### ⑥ 决策树（"碰到 X 怎么设计"，执行时直接查）

```text
一句长台词(6s+)   → 能稳定运镜? 是→6~7s运镜长镜  否→拆2个3s短切
情绪崩点          → 大特写 + 浅景深 + 6~7s长镜 + 崩前留白半秒 + 细节镜(颤抖的手)
要甩出物证        → 物品镜:怼近+带手+可读+夹在"人物说—人物崩"中间
闪回/回忆         → 调色区分(偏暖旧) + 闪白或叠化进出；换装=时间标记(不打字幕)
两人对峙          → 过肩正反打 + 一个同框关系镜(用距离表态度)
转场怕"硌"        → 插空镜换气 + 保证音频连续 + 同场景切景别
某镜"说不出新信息" → 删掉,或并进相邻镜
AI生成不稳定       → 降级:静态人物层 + AI背景微动 + 后期字幕,创意不变、证明降级
```

## 三、边界与合规

- 情感短剧靠共情，不靠虚构：**不得编造真实事件、伪造用户经历、假冒真人**；AI 生成的人物/场景需按平台要求标注。
- 不用"卖惨/制造虚假焦虑"替代内容推进；情绪转折要有可见行为与原因（呼应 SKILL.md：写"从X到Y"必须补出可见行为与变化原因）。
- 若挂接商品，商品只能承担功能/感官/关系媒介角色，不得把商品写成人格价值来源；功效/价格/对比需证据与合规边界。
- 金句卡是价值观表达，不是疗效承诺。
- 情感专属手法（缺失只显影、克制=稀缺、结尾不点题、负空间）只用于情感/剧情片；广告/带货片守 `emotional-drama-storycraft.md` 边界，以显性购买理由/转化钩子为准。

## 四、知识库候选规律（待投放验证，勿写成已验证）

- 连续音频 + 同场景多景别，可能比精心设计的转场更能制造"丝滑"感。
- 匀速 3~4s/镜 + 崩点处 2~3 个 6~7s 长镜的"呼吸"结构，可能优于全程等速快切。
- 界面镜（聊天/通话/短信）在情感短剧里信息密度高、生成成本低，可能是本类片的性价比主力。
- 物品镜"带手 + 可读 + 每次新信息"三条，可能是避免长镜拖沓的关键。
