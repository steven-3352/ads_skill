# 从观看动机到创意路线

用于创意发散、路线选择与改稿。先选观众愿意经历的体验，再选视觉机制。以下是决策工具，不要求把全部栏目展示给用户。

## 1. 分清观看承诺与购买理由

- 观看承诺：这个人此刻为什么停下，继续看能得到什么？写成一个具体期待和对应的兑现画面，不能只填“共情”“高级”“强 Hook”。
- 购买理由：这个商品在什么处境下值得考虑，有什么事实支持？它可能与观看承诺不同，但影片必须建立两者的连接。
- 首屏应让人抓到一个可理解的行动、关系或感官焦点，不必在一秒内解释整个故事。可以暂留答案，不能让观众连在看什么都不知道。

观看承诺从两条并列母路线中寻找。A 线“创意/品牌观赏”依靠炫酷、好玩、视觉规则、幽默、奇观或感官过程，重点是观赏奖励和品牌印象。B 线“日常/问题解决”依靠用户情绪、关系中的真实摩擦和具体生活问题，商品参与解决、选择、缓和、连接或完成。两线没有固定先后顺序，按商品属性、受众、平台目标、事实证据和制作条件选择。关系冲突不等于大吵大哭，小误会、习惯差异、欲言又止和一次选择通常更适合短视频；没有事实支持时不得强造家庭矛盾或健康焦虑。

例如：妈妈包的观看承诺可以是“她忙完所有人的事，会怎样为自己准备？”；购买理由是“这只包的已知外观与喜宴礼服的搭配”。亲情不是包的功效，精确容量也不能从情绪片推导。

## 2. 选择主吸引力

| 入口 | 观众正在期待什么 | 推进与兑现 | 失效征兆 |
|---|---|---|---|
| 好奇 | 这个异常为什么发生，接下来会怎样？ | 提供可解释的线索，揭晓改变前面画面的含义 | 故意拍不清；答案与商品无关；拖到片尾才给信息 |
| 共情 | 这个熟悉处境里的人，会作出什么选择？ | 用具体习惯暴露矛盾，用选择与后果完成变化 | 只靠配乐和旁白喊感动；把人物拍成需要被拯救的人 |
| 幽默 | 我认出的这点生活荒谬会走到哪里？ | 建立预期，偏离预期，再回扣商品或使用情境 | 演员夸张反应代替笑点；嘲讽受众身体、年龄或处境 |
| 感官 | 下一次接触、释放、完成会是什么感觉？ | 用尺度、材质、动作与声音形成期待和释放 | 只有慢镜头、粒子和流体；所有商品同一种质感 |
| 证明 | 我关心的问题真的能这样解决吗？ | 提出具体可验证问题，让操作和结果在可判断条件下出现 | 隐藏关键步骤；摆拍制造结果；用 AI 奇观证明性能 |
| 身份表达 | 这种选择是否像我，或像我想过的生活？ | 展示具体搭配、习惯与处事方式，让商品成为选择的一部分 | 把购买等同于尊严、阶层或被爱；只有空泛“气场” |

通常保留一个主入口，必要时一个辅助入口。感官片可以没有谜底，证明片可以没有人物，情绪片可以没有超现实变化。不是每个观众都需要被制造焦虑。

## 3. 让三条路线真正不同

固定商品事实、目标受众、任务目标和预算，再比较路线。每条用以下短卡表达：

```text
具体处境 / 当前观看者：
所属母路线：A 创意/品牌观赏；B 日常/问题解决；或有明确主次的混合
项目案例机制：参考文件 / 只继承的机制 / 新商品接口 / 明确不复制的表面元素
主观看承诺：我想继续看，因为……
首屏可见或可听的入口：
中段如何推进，在哪个动作兑现：
商品承担的角色与事实依据：
看后应记住的商品/品牌线索：
最大的失效风险与可验证问题：
```

路线比较时分别检查：A 线的观赏奖励是否足够、是否形成品牌记忆、奇观是否来自商品；B 线的情绪与关系是否真实、问题是否具体、解决是否可信。再按当前商品和受众判断哪条预期效果更好，不能默认日常关系线或视觉品牌线优先。混合时必须明确主线，避免既讲关系又堆奇观造成十五秒内容拥挤。

去掉路线名称、风格词、人物年龄、场景和配色后，比较：观众的期待、推进方式、产品角色。若三者都相同，只是执行变体；不能用“共情版/高级版/年轻版”冒充不同创意。

同一类观看动机也可以产生不同路线，例如“等人物作出选择”和“逐渐看懂人物的秘密”都能产生共情；判断依据是观看过程，不是标签不同。

探索不足时回到真实使用观察、消费者的替代行为、商品声音/形态或评论中的具体疑问。没有材料就标记假设，不伪造用户洞察；不为了凑十个隐喻浪费篇幅。用户已经选定路线时只解决其问题，不重新强制三路提案。

项目已有案例应在发散前被扫描，但不能因为存在案例就强行套用。A 线重点提取成熟语法、规则、观众角色、升级和视觉兑现；B 线重点提取人物处境、关系张力、选择、问题解决和商品进入方式。每次引用都写明“继承机制”和“新商品接口”，不得只写案例名称或复刻其表面资产。

## 4. 产品融合的三层检查

1. **品类角色**：拿掉这类商品，核心操作、感官体验、人物选择或场景表达损失什么？若只损失末尾广告位，先重写商品参与方式。
2. **具体商品适配**：哪些已知形态、使用方式、外观或证据支持这条表达？同类商品能替换不自动判失败；不要为满足独占性而虚构性能。生活方式广告允许搭配与关系角色，不强迫商品成为剧情的机械开关。
3. **商品/品牌记忆**：高潮与哪个真实识别线索绑定，例如包型与丝巾、包装、真实使用动作、已有品牌语言？只有 Logo 露出不等于品牌记忆。品牌资料缺失就围绕可确认商品外观建立识别，明确品牌归因待验证。

去掉商品后故事仍能成立，不一定是错误；但需要说清购买情境与商品记忆如何成立。用这一步诊断松散连接，不把它变成“所有人情都必须由商品造成”。

## 5. 统一创意门

用于所有路线；参考再创作另加迁移检查。每项 0-2 分：0 为缺失/矛盾，1 为已有方向但缺具体兑现，2 为脚本动作或可观察画面支持。每项引用证据，不能仅凭填有字段给满分。

| 维度 | 2 分需要什么 |
|---|---|
| 观看动机 | 针对具体观看者，有明确期待或持续体验；能指认入口 |
| 产品角色 | 商品以事实支持功能、感官、搭配或关系角色，连接购买情境 |
| 推进清晰 | 行为、线索、感官变化或证明条件可读；核心信息不用事后解释补救 |
| 奖励兑现 | 开场承诺在具体一拍得到回应；持续感官体验则有可辨认的变化与完成 |
| 表达辨识度 | 至少一个具体观察、选择、呈现角度或视听安排，使它区别于可批量换品的通稿 |
| 记忆与行动 | 商品/品牌线索与主要体验相连；下一步符合目标，品牌片不硬塞促销 |

总分至少 9/12 且无 0 分，才可进入脚本细化；这只是内部修稿门槛，不是效果预测。产品事实不成立、诱导性伪证、核心承诺无法兑现时直接退回，不允许靠别项加分通过。脚本细化后重新检查，提案通过不等于成片通过。

不设“奇观必有”“每片反转”“一定压过参考”的通用加分项。冷饭任务额外说明继承与升级，但朴素且有观察力的真实演示不因此失分。

## 6. 推荐与混合

推荐要说明它为何适合当前任务，以及放弃了什么。情绪路线可能牺牲直接信息量，证明路线可能缺少情节惊喜；根据目标取舍，不把各路线优点拼成一条拥挤的短片。

混合路线时保留一个主观看承诺，重写中段与结尾，检查新加入的桥段是否改变商品事实、制作预算或已获确认的方向。后续 A/B 优先验证最不确定的一环，不把内部评分最高当作投放胜出。
