# 从案例中蒸馏创意思维，而不是复刻内容

用于有参考的机制发散。本文的跨领域世界与单一规则是专项工具；没有参考的任务先读 `creative-attention.md`，允许以真实观察、证明或感官体验直接形成路线。

## 1. 先删除表面内容

分析一个参考视频时，依次删除人物、品类、道具、场景、服装、音乐和具体转场。如果删除后仍能说清“观众为什么继续看”，留下来的才是创意思维。

手机换装案例删除表面元素后是：

```text
一个日常但有摩擦的决定
→ 被改造成可见、可操作的系统
→ 每次操作立即打开一个不同结果
→ 多个结果快速对照
→ 最后选择一个结果进入现实
```

它不是“手机换装模板”，而是“把看不见的选择过程外化成连续可见的结果”。

## 2. 六个底层创意思维

结合完整样本集后，在六个思维之前增加一个总原则：**借用成熟语法，而不是借用表面风格**。监狱、教程、超市、电视、工程图、电量、街机、沙漏、交通灯和相机界面的价值，都来自观众已经理解的行为规则。完整样本证据和逐条映射见 `references/sample-set-creative-distillation.md`。

### 2.1 把心理活动变成物理事件

普通表达是“我不知道选哪个”。创意表达是让犹豫、比较、期待、后悔或确认在画面中真的发生。

```text
犹豫 → 多个选项轮流占据现实
比较 → 两个结果并排、交替或互相争夺
确认 → 一个操作让其他可能性消失
后悔 → 结果倒放、撤销或重新选择
```

先问：消费者购买或使用这个商品时，哪一个看不见的心理过程最值得被看见？

### 2.2 把选项变成平行世界

颜色、模式、口味和规格不是库存列表，而是不同的未来。每个选项都要带来一个可感知的生活结果，而不只是产品换色。

```text
产品选项
→ 使用状态
→ 用户角色/情绪
→ 一个具体场景结果
```

例如灯具的三档色温不是三张灯泡图，而是清晨起床、专注工作、夜晚放松三个时间世界。

### 2.3 把操作变成因果开关

点击、旋转、开合、插入、撕开、倒出、喷洒等真实动作必须触发画面变化。观众会等待下一次操作，因为已经学会了规则。

```text
真实操作 → 立即反馈 → 世界/状态改变
```

触发动作必须来自商品或使用场景。随机响指、无来源白闪和任意魔法只能当转场，不能承担创意因果。

### 2.4 把功能变成一种角色权力

不要只问“商品像什么”，还要问“使用它的人突然拥有什么权力”。

|真实功能|用户获得的角色权力|
|---|---|
|多模式切换|调度员、导演、DJ、飞行员|
|收纳分类|军需官、档案管理员、游戏背包管理者|
|快速清洁|侦探、修复师、时间倒流者|
|温度调节|天气控制员、季节管理员|
|个性化推荐|选角导演、造型师、命运抽签者|

角色不是装饰。角色的动作规则必须与真实功能一一对应。

### 2.5 把结果证明变成蒙太奇奖励

主视频建立因果，照片、特写、俯拍、场景图负责快速展开结果。观众不是因为照片会动才继续看，而是因为每张照片都回答“选择它之后会怎样”。

结果图至少承担一种证明：使用场景、尺寸比例、风格身份、细节材质、前后差异或任务完成。纯氛围图不算结果。

### 2.6 用重复规则制造期待，用变化升级奖励

重复不是重复画面，而是重复同一条因果规则：

```text
第一次：教会观众规则
第二次：缩短过程，提高速度
第三次：改变幅度最大，给最终奖励
```

通常使用 3 次最容易被理解。每次都要在颜色、尺度、场景、身份、声音或结果强度上升级，不能只是机械换素材。

## 3. 创意不是套模板，而是匹配商品矛盾

同一种“选择系统”不适合所有商品。先确定商品最真实的消费矛盾，再选创意语法。

|消费者矛盾|适合的创意语法|不适合的做法|
|---|---|---|
|选项太多，不知道怎么选|选择器、试镜、抽签、平行世界|罗列所有 SKU 参数|
|功能抽象，看不见价值|控制台、扫描、状态可视化|只做漂亮使用场景|
|结果出现太慢|时间压缩、未来预览、前后蒙太奇|虚构即时功效|
|产品普通，缺少身份感|角色赋权、类型混搭、场景置换|随机加入科幻皮肤|
|需要信任和证明|实验、任务验收、现场测试|让 AI 奇观代替证据|
|使用步骤复杂|闯关、任务清单、装配游戏|一镜到底塞入所有步骤|

核心判断：创意形式是否解决了商品传播中真实存在的表达难题？如果没有，只是套用了一个好看的壳。

## 4. 新商品发散算法

在进入以下步骤前，先生成至少三套候选“成熟语法”：一个系统/游戏语法、一个媒介/文化语法、一个职业/物理语法。分别说明它与商品共享的真实动作、状态或消费者心理，再选择最自然的一套。

### 第一步：写商品真值，不写广告词

记录：可见形态、真实操作、可变状态、即时反馈、使用结果、用户犹豫和不可虚构边界。

### 第二步：找一个最有张力的“不可见过程”

选择、等待、比较、控制、整理、准备、恢复、分享、获得身份，通常比“产品是什么”更容易成为故事。

### 第三步：为它寻找三种外化方式

不要只想 App 界面。至少从三类中各找一个：

- **系统类**：控制台、调度中心、扫描仪、档案库、天气台、任务面板。
- **游戏类**：角色选择、装备栏、抽卡、闯关、能量条、技能树。
- **文化类**：试镜、点唱机、电视购物、邮局、老照相馆、课堂点名。
- **自然类**：四季、昼夜、潮汐、生长、结冰、风向。
- **关系类**：面试、约会、家庭投票、朋友推荐、未来的自己。

### 第四步：只写一条世界规则

```text
每当用户【真实操作】，就会看到【一种真实状态/结果】。
```

一句说不清，说明机制过载。

### 第五步：设计三次变化的升级关系

变化可沿一个轴升级：更快、更大、更近、更远、更日常到更意外、更个人到更社会、更预览到真实发生。

### 第六步：安排结果回扣

最后不是 Logo，而是回答：哪个结果被选中、为什么被选中、商品真实提供了什么、用户接下来进入什么场景。

### 第七步：按 AI 能力拆素材

让 AI 生成稳定状态和世界差异；让剪辑制造连续因果；让真实商品图、视频截帧或实拍承担精确外观与证明。

## 5. 跨品类举一反三

以下例子复用的是创意思维，不是服装内容。

### 5.1 机械外形耳机：驾驶舱权限

```text
真实锚点：旋钮、按键、指示灯、降噪/通透等模式
不可见过程：用户在不同环境中切换听觉注意力
远方世界：飞行驾驶舱
单一规则：每转一档旋钮，外部世界进入一种航行状态
三次结果：地铁噪声压低 → 办公室人声保留 → 户外环境提示恢复
回扣：回到真实耳机控制件和实际模式，不虚构性能数据
```

这里学到的不是手机 UI，而是“用户获得控制环境声音的驾驶权限”。

### 5.2 台灯：个人天气控制台

```text
真实锚点：亮度和色温调节
不可见过程：人在一天中调节精神状态
远方世界：气象台
单一规则：每滑动一次，房间进入一个时间天气
三次结果：晨光起床 → 白昼工作 → 暖色夜晚阅读
回扣：展示桌面照明范围、控制动作和真实光线变化
```

### 5.3 行李箱：游戏装备栏

```text
真实锚点：分区、容量、轮子、开合
不可见过程：出发前不断决定带什么
远方世界：角色装备栏
单一规则：每放入一类物品，就解锁一个旅行任务
三次结果：两日商务 → 周末户外 → 长途旅行
回扣：俯拍真实分区和关闭后的移动状态
```

### 5.4 咖啡胶囊/饮品口味：目的地登机牌

```text
真实锚点：不同口味、颜色、冲泡动作
不可见过程：今天想进入哪种情绪
远方世界：机场目的地选择
单一规则：每放入一种口味，早餐桌抵达一个不同城市/氛围
三次结果：清醒、轻松、浓郁等体验场景
回扣：真实冲泡、液体状态和入口反应；不虚构提神功效
```

### 5.5 清洁产品：现场修复任务

```text
真实锚点：喷洒、擦拭、污渍前后
不可见过程：用户判断哪里最需要处理
远方世界：侦探现场扫描
单一规则：扫描锁定一处污渍，喷一下进入修复任务
三次结果：桌面油渍 → 灶台痕迹 → 浴室水印
回扣：使用真实前后画面，不让 AI 生成效果证明
```

### 5.6 沙发/办公椅：一天的角色切换

```text
真实锚点：坐姿、靠背、脚托或模块组合
不可见过程：同一空间承担工作、休息、社交
远方世界：选角试镜
单一规则：每改变一个真实结构，用户进入一个新角色
三次结果：工作者 → 阅读者 → 朋友聚会主持人
回扣：展示真实调节结构和对应坐姿
```

### 5.7 香水：记忆试镜

```text
真实锚点：喷洒和香调信息
不可见过程：气味带来的身份与记忆联想
远方世界：电影试镜室
单一规则：每喷一次，同一个人进入一种不同电影类型
三次结果：清晨公路片 → 花园旧电影 → 夜晚都市片
回扣：回到瓶身、喷头和合规的香调描述，不声称无法证明的心理功效
```

### 5.8 软件模板：未来结果预览器

```text
真实锚点：选择模板、输入内容、导出结果
不可见过程：用户难以预判模板最终效果
远方世界：未来分支管理器
单一规则：每选择一个模板，立即闪现一个完成后的使用场景
三次结果：社交帖子 → 报告 → 演示文稿
回扣：返回真实界面操作和可验证输出
```

### 5.9 夜间/自动产品：后台夜班

```text
真实锚点：用户完成一次启动，商品在静置、循环或睡眠期间继续工作
不可见过程：等待期间具体发生了什么
远方世界：夜班、检修库、值守中心、温室或后台换场
单一规则：用户离场后，每个后台角色/工位完成一个真实阶段
三次升级：启动任务 -> 多工位同时运行 -> 用户回来验收结果
回扣：真实启动动作、运行状态与结果证据；后台奇观不能代替功效证明
```

这类创意的核心不是“微缩小人”，而是用一个代理系统替观众度过不可见时间。人物、机器、植物、图形进度或空间变化都可以承担代理，只要它们对应真实过程。

### 5.10 连续世界：语义接力

当一个创意需要穿过多个场景时，不要用无来源的闪白把场景串起来。让每两镜共享至少一个锚点：同一个动作、形状、材质、运动方向、尺度或概念。

```text
现实中的一个对象
-> 放大为可进入的地形
-> 地形变成产品内部的工作现场
-> 工作动作匹配真实使用动作
-> 真实结果把观众带回现实
```

评审问题：每一次切换能否用一句“因为上一镜的___，所以来到下一镜的___”解释？不能解释的场景通常只是随机蒙太奇。

## 6. AI 友好的创意组织

AI 不需要完整模拟现实，创意应允许它生成多个“稳定状态岛”，再由剪辑连接因果：

```text
状态 A 视频/照片
→ 真实操作近景
→ 声音 + 硬切
→ 状态 B 视频/照片
```

优先让 AI 做：不同世界、背景、身份氛围、单一姿势、短动作和静态结果图。

避免让 AI 做：长时间人物连续变形、精确多手指界面操作、反射、多人物复杂互动、商品结构和文字重绘。

创意越能被拆成稳定状态，越适合 AI；冲击力由状态之间的距离和剪辑因果产生，不依赖模型完成一个高风险长镜头。

## 7. 判断是不是同一种创意思维

完成发散后做五个测试：

1. **去内容测试**：去掉手机、人物和服装，机制仍成立吗？
2. **商品锚点测试**：操作和变化来自新商品真实特征吗？
3. **生活结果测试**：每个选项是否对应不同结果，而不只是换颜色？
4. **规则期待测试**：观众看完第一次变化后，会期待第二次吗？
5. **AI 降级测试**：视频生成失败时，照片 + 操作近景 + 剪辑仍能成立吗？

五项通过，说明学到的是创意思维；只剩相同 UI、白闪、换装或构图，说明仍在复制内容。
