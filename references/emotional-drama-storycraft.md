# 短视频·情感/剧情创作方法论知识库

> 用途：**情感 / 剧情类**短视频的创作参考库（不绑定单个项目），可持续扩充
> 结构：九章——创作 → 台词 → 分镜 → 构图 → 拍摄 → 导演 → 平台适配 → 理论谱系 → 串联用法
> 统一格式：每章 = **核心命题 / 工具清单 / 红线 / 案例注解**
> 案例注解均来自《我们还是分手吧》（v2.2），作为"方法论如何落进项目"的示范
> 建立时间：2026-09-17 ｜ 版本：v1.0

---

## 适用边界 · 与创意广告的区分（先读这一节）

**本库是"情感 / 剧情类"打法，不是全类型通用方法。** 案例来自情感短片，主体方法（缺失发动机、克制美学、负空间、情感赛道数据）都是为"有人物内心、关系冲突、克制叙事"的片子写的。接入项目时必须分清用途，否则会污染创意广告主线。

- **适用**：情感 / 剧情 / 关系冲突类短视频——有人物内心、有克制叙事、观众靠"共情/缺失"停留。
- **创意广告 / 纯广告片 / 带货片：只借鉴"故事编剧"这块**——即第一章（1.3 剧作结构、1.4 人物=欲望+缺陷+恐惧、1.5 悬念/信息差、1.6 节奏、目标-阻碍对撞）与第二章（2.1 短句口语、2.2 潜台词、2.3 金句）。这些是**跨类型通用的编剧手艺**，可放心取用。
- **以下情感类专属条目不得套用到广告片**：
  1. 缺失发动机的"缺失只能被显影、不能被说出"（1.2 红线）；
  2. "克制 = 稀缺"、写实克制作差异化（1.7）；
  3. 结尾留白、不点题、无字幕（1.6 / 九、验收红线第 5 条）；
  4. 负空间 / 空位美学作为叙事主角（第四章 4.1）；
  5. §7 情感赛道平台数据基准（r=-0.89、完播 38.5% 等）——那是情感线参考值，不是全项目基准。
- **理由**：广告片必须**显性做出购买理由 / 转化钩子**（见记忆 `daihuo-must-show-why-buy`），与情感片"缺失只显影不说破""结尾不点题"的目的相反。
- **一句话判据**：*广告片问"用户为什么买"，情感片问"观众缺什么"——编剧手艺共用，叙事目的不共用。*
- **量化留存门以生产 SOP 为准**：本库第九章验收红线是**情感/剧情项目的编剧自检清单**，不作全局门禁；项目级可量化的内容/节奏门见 `video-production-sop.md` §9 的 **[C] 内容丰满度门 / [R] 节奏卫生门**（全类型通用），两者不重复。

## 〇、知识库使用说明

1. **先读第一章（创作）**：它是发动机，后面所有章节都是在为它服务。
2. **每章的"红线"是硬约束**：违反红线的不是"不够好"，是"直接坏掉"。
3. **案例注解不是标准答案**：是"这套方法论在一条具体片子里怎么落"的示范，看的是方法，不是结论。
4. **新增方法论时沿用统一格式**，保持"命题/工具/红线/案例"四段。
5. **最高层的一句话工作流**（见第九章）：每一层都问同一个问题——**这里缺了什么？观众会用什么来填？**

## 一、创作方法论（剧作层）

### 1.1 情绪写作

**核心命题**：共情强度 = 内心强度 − 外在表达。外在表达越小，内心必须越大。两者一样小 = 面瘫；外在大于内心 = 狗血。克制风格要求内心层"大而隐"。

**工具清单**：
1. **未说出口的话**：每句台词背后压一句真实句子，演员按它演，观众从表情/停顿里读出来。
2. **心理节拍表**：每个节拍 = 表面行为 / 真实内心 / 肢体证据，三栏对应。
3. **情绪弧线与转折点**：每个角色必须有明确的"内心转变瞬间"（epiphany），转折前与转折后是两种状态。
4. **共情锚点**：让观众对号入座的细节，必须具体到时间、动作、物件（02:17、已读不回、空位）。

**红线**：未说出口的话永远不出口；内心层只进表演依据，不进台词、不进字幕、不进花字。说破即失效。

**案例注解**：A 的三句未说出口的话（「我还是爱你，只是我没有力气了」等）只出现在第三章心理节拍表里；A 的转折在 B2（"你还是不懂"），B 的崩塌在金句——两个转折点明确写入表演分界：金句前的 B 在"争取"，金句后的 B 只剩"接受"。

### 1.2 缺失发动机

**核心命题**：故事的发动机不是情节，而是缺失。情节只是"缺失被显影"的时间表。观众不是被"发生了什么"打动，而是被"什么没有发生、什么已经缺席"打动。

**工具清单**：
1. **缺失清单（由浅到深）**：回应缺失 → 当下缺失 → 听懂缺失 → 时间差。最深的发动机通常是"时间差/认知差"（一个人已到终点，另一个还以为在起点）。
2. **缺失的物理化**：把"缺什么"变成画面证据——空位、消失的物件、已读不回、未接的电话。缺失必须看得见，不能只靠台词说。
3. **情节→缺失重读表**：每个节拍都问"这里缺什么"，把表层情节的主语翻成缺失的主语。

**红线**：缺失只能被显影，不能被说出（字幕点题 = 杀死缺失）；把缺失补全 = 发动机变说明书。

**案例注解**：四层缺失（回应→当下→听懂→时间差）；空位不是布景是主角；B 的每句挽回都是"缺失的告白"（他说「我记得」，缺的正是记得）。

### 1.3 剧作结构

**核心命题**：短视频不是微电影的压缩，是"钩子-价值-闭环"的信息结构。平台数据是硬约束：完播率与前 3 秒跳出强负相关（r=-0.89），爆款前 3 秒信息承载量是普通视频的 2.3 倍。

**工具清单**：
1. **五段式**：钩子/推进/顶点/余波/留白，先定秒段再写台词。
2. **爆款节奏模型**：0–3s 建立冲突/悬念，5–8s 价值交付，12–15s 情绪闭环；金句落全片前 60%。
3. **首帧信息密度**：首帧必须自带"发生了什么"，禁止真空静场（静场超过 1s 无信息 = 首帧无信号）。
4. **反转设计**：情绪式反转（认知刷新）与情节式反转（事件翻转）二选一，不叠床架屋。
5. **目标-阻碍对撞**：一场戏一个核心动作，一次性推到结论（"没有了"）。

**红线**：慢节奏 × 长时长 = 完播自杀；前 3 秒不说人话，后面讲圣经也没用；结构服务于情绪，不为炫技。

**案例注解**：58s → 46s 压缩；金句 26.5s / 46s ≈ 57%，落进前 60%；开场从 2s 静场改为 0.5s + 行李箱物件先行。

### 1.4 人物塑造

**核心命题**：人物 = 欲望 + 缺陷 + 恐惧。观众记住的不是身份，是"他缺什么、他想要什么、他怕什么"。

**工具清单**：
1. **欲望 × 阻碍 × 代价**：他要什么？谁/什么挡着？得不到会怎样？
2. **缺陷驱动**：人物的缺陷就是剧情的发动机（B 的缺陷 = 迟钝的爱的"时间错觉"）。
3. **关系的"账本"**：让关系本身有未清算的账（记得/忘了、我改/没改）。
4. **转折瞬间**：人物的转变必须有明确触发点，不能突变。

**红线**：不给人物贴标签（渣男/作女）；转变必须有"那一秒"，否则观众不信。

**案例注解**：A = 等太久才开口的人（缺陷：不会表达痛苦，只会默默攒失望）；B = 以为来日方长的人（缺陷：迟钝）；两人合在一起 = "时间差"。

### 1.5 悬念与信息管理

**核心命题**：悬念 = 信息差（观众知道 X、角色不知道 X，或反过来）。把信息藏起来不是目的，让信息差在正确时刻闭合才是。

**工具清单**：
1. **信息差清单**：开场观众知道什么？角色知道什么？什么时候揭晓？
2. **迟到的揭示**：把"真相"推迟到情绪最高点揭示（金句 = 认知闭合的瞬间）。
3. **预埋-兑现**：开场埋的物件，收尾必须兑现（空位回扣）；预埋不兑现 = 断裂。

**红线**：悬念不是靠信息缺失，而是靠"观众知道结局、角色不知道"或"观众不知道、想知道"——两者都要有承诺。

**案例注解**：观众从首帧（行李箱）就知道"她真的要走了"，B 却还在侥幸——这就是全片最大的信息差；金句让 B 的信息差闭合，观众比 B 早 25 秒知道。

### 1.6 节奏设计

**核心命题**：情绪节奏 ≠ 情节节奏。松紧交替，重拍前必有轻拍；静默是节奏的一部分，不是空档。

**工具清单**：
1. **松-紧-松模型**：静场（松）→ 交锋（紧）→ 金句（最紧）→ 留白（松）。
2. **静默的三种用法**：开场静场（悬念）、句间停顿（重量）、结尾黑场（余味）。
3. **声音节奏**：人声优先，BGM 压底，只在顶点极轻抬升（卡点偏差 ≤0.2s）。
4. **停顿量化**：反应停顿 0.3–0.5s，长句停顿切短拍，静默有明确秒数。

**红线**：全程紧 = 疲劳；全程松 = 无聊；静默超过 2s 且无信息 = 真空。

**案例注解**：46s 内三处留白——开场 0.5s（呼吸感）、"没有了"后短静默、结尾黑场 1.5–2s；金句处 BGM 极轻抬升不盖人声。

### 1.7 共鸣与选题

**核心命题**：共鸣 = 让观众"对号入座"。选题先问：这个情绪池够不够大？这个细节够不够具体？

**工具清单**：
1. **情绪池判断**：分手、失望、等待、失去——情感赛道最大共鸣池。
2. **细节优先于主题**：主题（"沟通很重要"）不共鸣，细节（"等消息等到半夜"）才共鸣。
3. **克制 = 稀缺**：同赛道狗血泛滥时，写实克制是差异化溢价。

**红线**：抽象的情绪不共情；说教式主题 = 点题即降级。

## 二、台词方法论

### 2.1 口语与节奏

**核心命题**：台词是"说出来的"，不是"写出来的"。短句是短视频对白的默认语法。

**工具清单**：
1. **短句交锋**：一句一意，长句拆成短拍（"期待一次次落空之后，热情就耗光了"→"后来，就不等了"）。
2. **AB 语言区分**：A 短而定（决定感），B 急而找理由（慌乱感）——人物语速、句式即人设。
3. **删书面腔**：删"比喻、成语、书面词"，留动词和具体名词。
4. **字数-时长换算**：写实慢速约 4 字/秒；180 字 ≈ 45 秒台词 + 停顿余量。

**红线**：解释性台词 = 说教；角色替主题代言 = 出戏；台词长于画面信息量 = 话剧腔。

**案例注解**：全片约 150 字 / 46s；A 最短句 3 字（「没有了」），B 最长的句子也在 15 字内。

### 2.2 潜台词写作

**核心命题**：对白底下永远压着另一句话（麦基）。场景从来不是表面在讲的东西。

**工具清单**：
1. **双写**：先写表面句，再写内心句，只保留表面句（内心句进表演层）。
2. **对比式潜台词**：用"记得 A"反衬"忘了 B"（「我记得。可你忘了」）。
3. **复读与变奏**：同一词重复出现但意义翻转（"我改"→ B 说出口时是敷衍，A 听进去时是绝望）。

**红线**：潜台词一旦被台词说破，立即失效；不要让角色"解释自己的潜台词"。

**案例注解**：B3 的「我记得。可你忘了——那天你加班，一条消息都没有」——表面在谈餐厅约定，底下是"你记错了重点"。

### 2.3 金句设计

**核心命题**：金句 = 全片情绪的总结陈词，可截图、可引用、可评论。它是传播的最小单位。

**工具清单**：
1. **反转结构**：先否定对方的词（"不是小事"），再给出新定义（"是撑不住了"）。
2. **具象化**：把抽象情绪变成具体动作/时间（"等你有空"——把"失望"变成"等待"的实体）。
3. **预埋递进**：金句的核心词要提前出现至少两次（"等"出现三次：没消息→等到半夜→不会等你有空）。
4. **位置**：落全片前 60%；金句后保留余波（观众看到金句后更愿意看完收尾）。

**红线**：金句必须由人物说出（角色语言），不能是作者总结；金句与台词风格不一致 = 广告感。

## 三、分镜方法论

### 3.1 分镜原则

**核心命题**：一个镜头只说一件事。镜头时长 = 信息量 + 情绪重量。

**工具清单**：
1. **镜头-信息对应表**：每镜 = 机位 + 景别 + 内容 + 时长 + 情绪任务。
2. **反应镜头**：对白后给 0.3–0.5s 反应停顿——情绪靠"听 + 看"双层接收。
3. **插段镜头**：用物件特写打断对话节奏（手机屏幕 0.8s），制造"证据感"。
4. **切换点**：切换点标在台词处，正反打硬切贴合短句节奏。

**红线**：无信息镜头（空转）一律删；每镜必须有"任务"。

### 3.2 叙事连续性

**核心命题**：观众不出戏 = 空间/视线/动作连续。

**工具清单**：
1. **轴线规则（180°）**：正反打不越轴。
2. **视线匹配**：A 看的方向 = B 所在的方向。
3. **动作连续性**：起身-背包-关门，动作链不断。

**红线**：跳轴、视线错位 = 低级穿帮，直接毁掉真实感。

### 3.3 关键帧思维

**核心命题**：全片由几个"决定性瞬间"撑起来，其余都是过渡。

**工具清单**：
1. **关键帧清单**：首帧（信息密度）、转折帧（第一次正眼）、金句帧、空位帧。
2. **首帧测试**：遮住标题播前 3 秒，3 位目标用户 2 人以上说不出主题 = 重做开头。

**红线**：关键帧之间不能都是平推；每个关键帧都要能回答"为什么观众会记住它"。

**案例注解**：关键帧 = ①首帧（A 起身+行李箱）②手机 02:17 ③金句（第一次正眼）④空位收尾。

## 四、构图方法论（画面层）

### 4.1 负空间与空位

**核心命题**：空位不是没有内容，是最重的内容（"无画处皆成妙境"）。人物之间的距离 = 关系距离。

**工具清单**：
1. **关系构图**：双人构图中间的空段 = 关系的断裂。
2. **视线留白**：人物看的方向留出空，观众视线被引导到"缺失"上。
3. **物件锚定空位**：空位上放一件东西（倒扣相框/行李箱），空得更有重量。

**红线**：空位必须有"为什么空"；纯构图装饰 = 空洞。

**案例注解**：开场空位+行李箱（将走未走）→ 收尾空位（行李箱被带走，空得更彻底）——同一空位两次出现，完成回扣。

### 4.2 构图基础

**工具清单**：
1. **三分法**：主体放交点。
2. **框式构图**：门框/窗框做画框，强化"隔开"（关门戏）。
3. **前景遮挡**：过肩拍 = 窥视感 + 关系层。
4. **对称 = 僵持**（两人各占一端），**不对称 = 失衡**（一个要走的信号）。

**红线**：构图服务叙事，不为炫技；每条构图规则都要能说出"它在说什么"。

### 4.3 竖屏/横屏适配

**核心命题**：平台即语法。16:9 = 电影感 + 左右空位；9:16 = 信息流全屏 + 上下距离感。

**工具清单**：
1. 同一条片可做双版本；竖屏的空位是"上下两个世界"，距离感可能更强。
2. 横屏直发抖音信息流 = 首帧视觉占比小，前 3 秒跳出风险高（接受代价需用首帧信息密度对冲）。

**红线**：画幅选择先问分发目标，再谈美学。

## 五、拍摄方法论

### 5.1 景别叙事

**核心命题**：景别 = 情绪距离。

**工具清单**：
1. 近景/特写 = 内心（金句用慢推近）。
2. 中景 = 关系（正反打对话）。
3. 双人中景 = 空间距离（空位构图，横屏能同时容纳两人及中间空位）。
4. 景别切换 = 情绪推进（对话中从双人中景切到近景 = 从关系切到个人）。

**红线**：全程特写 = 窒息无环境；全程全景 = 无情绪；景别与情绪错位 = 出戏。

### 5.2 运镜语义

**核心命题**：每一种运镜都在说话，运镜必须与情绪同构。

**工具清单**：
1. **推** = 逼近内心/强调（A 说金句时慢推近）。
2. **缓摇** = 扫过现场/余味（空位扫过）。
3. **固定** = 克制/冷静（A 的稳 vs B 的不稳）。
4. **手持微晃** = 不安（可选：B 的慌乱）。
5. **下摇** = 揭示（镜头下摇带到行李箱 = "她真的是要走了"）。

**红线**：运镜与情绪错位 = 出戏（冷静时刻乱摇 = 灾难）；为运镜而运镜 = 炫技。

### 5.3 光影

**核心命题**：光即情绪。真实感是平台偏好的底层（自然光内容画质分反超过度滤镜）。

**工具清单**：
1. **单光源（暖黄台灯）**：深夜、私密、孤独。
2. **伦勃朗光/侧光**：半边脸亮半边暗 = 内心复杂。
3. **眼神光**：泪光前的最后一点亮。
4. **浅景深**：虚化环境 = 聚焦关系。
5. **轻微胶片颗粒**：写实质感，去广告感。

**红线**：高亮无影棚光 = 广告感，毁写实；滤镜过度 = 平台画质分反降。

### 5.4 声音（拍摄层）

**核心命题**：声音是半部戏。人声优先，环境声给真实，拟音给重量。

**工具清单**：
1. **环境底噪**：深夜时钟滴答/冰箱嗡鸣 = 第一秒的"深夜感"。
2. **拟音**：关门声 = 唯一重拟音，隔开两个世界。
3. **BGM**：全程压底，只在顶点极轻抬升；卡点偏差 ≤0.2s；人声信噪比（环境音衰减 ≥15dB）。
4. **呼吸声**：关门后 0.5s 极轻的压抑呼吸 = 余味放大器。

**红线**：BGM 抢人声 = 情绪失重；拟音缺失 = 画面假。

## 六、导演方法论

### 6.1 导演思维

**核心命题**：导演不是执行剧本，是执行"缺失"。演缺失，不演情节。

**工具清单**：
1. **演缺失不演情节**：A 不是"冷静提分手"，是"把缺失摆上桌时手在抖"。
2. **表演指导**：给演员内心依据（未说出口的话），不给情绪标签（"你要悲伤"）——给标签 = 演员只能演表面。
3. **配音指导**：按真实内心给语气（「没有了」= 遗憾不是冷漠；「我改」= 怕来不及不是敷衍）。
4. **肢体证据优先**：情绪全部落到可拍动作（不看 B、喉结滚动、关门轻而稳）。

**红线**：喊情绪 = 狗血；给情绪标签 = 表演失真；内心依据永远大于情绪指令。

### 6.2 节奏控制（导演的剪辑思维）

**工具清单**：
1. **情绪节拍表**：每拍时长 = 信息量 + 情绪重量，先定秒段再拍。
2. **静默管理**：开场 0.5s 呼吸、句间 0.3–0.5s 停顿、结尾黑场 1.5–2s。
3. **重拍前置**：金句在 55–60% 处，后面留余波（金句后观众反而更愿意看完）。

**红线**：平均用力 = 无高潮；为快而快 = 没有呼吸；留白不是没剪完，是做完了但故意不交付。

### 6.3 AI 直出导演（H3 / Seedance）

**核心命题**：AI 直出 = 提示词即导演。

**工具清单**：
1. **喂"真实内心"关键词**（强忍的疲惫/压抑的懊悔），比喂情绪标签（他很伤心）有效。
2. **单镜内给"动作 + 表情 + 语气"三件套**（眼眶泛红，强忍，尾音一丝颤）。
3. **一致性**：人设/场景/道具资产先行，关键帧锁死再生成。
4. **画内同期声优先**：无旁白/无 OS 时，台词直出 + 后期统一烧字幕。

**红线**：提示词写"他很伤心" = 模型给你模板化伤心；写"眼眶泛红，强忍，尾音一丝颤" = 真实。

## 七、平台适配方法论（抖音爆款标准，2025–2026）

### 7.1 数据基准

| 指标 | 基准 | 含义 |
|---|---|---|
| 前 2 秒跳出率 | >50% = 判定没人看、不推流 | 首帧必须在 2 秒内给信息 |
| 5 秒完播率 | 25–35% 合格 / 35–45% 正常 / >45% 优质 | 开头留人能力 |
| 完播率 | 爆款均值 45.7%（非爆款 18.3%） | 60s 需 ≥38.5% 才触发首轮流量池 |
| 前 3 秒信息量 | 爆款 = 普通视频 2.3 倍 | 首帧价值判断约 700ms–1.8s |
| 综合互动率 | 头部爆款 ≥8.2% | 评论+分享+点击 |
| 评论深度 | 开放式提问 → 评论深度 +3.2 倍 | 有效评论（≥5 字）单独加权 |
| 情绪型生命周期 | 5–10 天，点赞/评论比 ≤3.5 | 评论区情感共振是关键信号 |
| 发布后 2h | 回复前 50 条中 20 条 → 24h 推荐 +17.3% | 评论必须亲自运营 |

### 7.2 包装层（标题/评论/封面/话题）

**工具清单**：
1. **标题** = 情绪 + 悬念 + 反转（「我提分手那天，他很平静地问：是不是又生气了」）。
2. **置顶评论** = 开放式提问，引导 5 字以上有效评论。
3. **封面**：首帧截图 + 大字（字号 ≥ 封面高度 1/8）。
4. **话题**：主标签 ≤3 个，与封面文字、首句语音强一致。

**红线**：包装层与画面冲突（画面克制、标题狗血）= 观众被欺骗感；互动钩子可以只放包装层，画面保持纯留白。

## 九、方法论怎么串起来用

**一句话工作流**：

> 选题共鸣（题材层）→ 缺失发动机（剧作层）→ 情绪写作（表演层）→ 结构节拍（节奏层）→ 分镜构图（画面层）→ 拍摄光影（执行层）→ 导演表演（指导层）→ 平台包装（分发层）

**每一层都问同一个问题**：这里缺了什么？观众会用什么来填？

- 题材层：这个情绪池够不够大？
- 剧作层：这场戏的发动机是情节还是缺失？
- 表演层：这句台词底下压着哪句没说的话？
- 节奏层：重拍前的轻拍在哪？静默有秒数吗？
- 画面层：空位在说什么？这个镜头在说什么？
- 执行层：光在说什么？运镜在说什么？声音在说什么？
- 指导层：我给的是内心依据还是情绪标签？
- 分发层：标题让人点吗？评论区让人说吗？

**验收红线清单（发布前逐项过）**〔仅情感/剧情项目；量化留存门以 `video-production-sop.md` §9 [C]/[R] 为准〕：
1. 前 3 秒盲测：3 人 2 人以上说不出主题 → 重做开头。
2. 金句位置 ≤ 全片 60%。
3. 缺失全部有画面证据（物件/空位/动作），无台词解释。
4. 未说出口的话一句没出口。
5. 结尾留白无字幕点题。
6. 时长 × 节奏匹配完播基准（60s 档需 ≥38.5% 完播目标）。
7. 包装层（标题/置顶评论/封面/话题）与画面基调一致。

> 第 3、4、5 条是**情感/剧情专属**（缺失只显影、结尾不点题）——创意广告/带货片**不套用**，改以显性购买理由/转化钩子验收（见本文件顶部「适用边界」与记忆 `daihuo-must-show-why-buy`）。
