# 外部方法资料与可迁移结论

本文件记录公开文章中的方法性信息。文章是作者经验或品牌内容时，不把其中的效果数字直接当作行业事实；需要用自己的数据验证。

## Ribbi

来源：<https://ribbi.ai/blog/>

可迁移结论：

- 内容应优先采用平台原生格式，而不是先做一支传统广告再硬改平台版本。
- Brief 先定义“让谁产生什么感觉或行动”，再选择 Talking Head、开箱、舞蹈、生活方式或品牌片等形式。
- 测试优先集中在前 1-3 秒 Hook，并保留主体内容以降低变量混杂。
- 创意生产应连接趋势发现、制作、发布、监测和迭代，形成闭环。
- 将喜欢的构图、色彩、镜头、字幕和节奏存入可检索素材库，沉淀团队审美。

## Welly：故事行銷怎麼做

来源：<https://welly.tw/blog/story-marketing>

文章提出的核心要素：

- 先定义目标受众，分析需求和兴趣。
- 建立清晰情节：开始、冲突、高潮和结局。
- 用七个元素丰富故事：目标、阻碍、努力、结果、意外、转弯、结局。
- 将品牌价值自然放入情节，让产品成为解决问题的关键，而不是中途硬插 Logo。
- 用多媒体和合适渠道传播，并在结尾设计明确 CTA。

可转成创意规则：

```text
角色目标 → 现实阻碍 → 尝试/失败 → 意外转折 → 产品介入 → 可见结果 → 行动邀请
```

## 3DAY：广告影片 6 个步骤

来源：<https://3day.tw/6-steps-to-make-video/>

制作链条：

1. 确立影片目的：想对谁说什么，想达成什么结果。
2. 选择影片类型：情境、访谈、代言、KOL、微电影、动画、形象片等。
3. 写脚本和分镜：标明镜号、镜位、时长、画面和备注；分镜不一定精细，但必须可执行。
4. 前期准备：演员、场地、道具、人员、时间、拍摄顺序和通告单。
5. 现场拍摄：在预算和人员能力范围内完成画面、声音、灯光和细节。
6. 后期完成：素材备份、剪辑、调色、字幕、动效、音乐、音效和配音。

关键经验：

- 前期规划越细，现场越省钱、越少返工。
- 有多少人和资源，就设计多少复杂度，不要让形式拖累执行。
- 一条广告不要塞入太多主张；短视频需要快速吸引、制造悬念和直达重点。
- “参考素材库”是创意训练的一部分，但应提炼机制、重新创作，不逐句照搬。

## MorePower：Inbound Marketing

来源：<https://morepower.club/inbound-marketing/>

可迁移结论：

- 广告不是孤立内容，应放入“内容/SEO → 触达 → 信任 → 转化 → 复购/推荐”的获客系统。
- 长期内容的价值在于持续回答用户问题，形成可累积的自然流量和信任。
- 付费广告适合加速验证和放大有效主题，不能替代产品价值、内容基础和转化页面。
- 需要记录内容主题、流量来源、咨询、成交和 ROAS，判断每个创意在漏斗中的作用。
- 该页面包含课程和服务推广，案例数字属于其自述，应作为待验证案例而非普遍结论。
