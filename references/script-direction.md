# 抖音优先的短视频剧本（script-direction）

> **本文件用途**：抖音（及竖屏内容流平台）短视频项目的剧本阶段工作指南。覆盖从"创意路线确认后"到"可摄影视听脚本定稿"的完整编剧过程。
>
> 核心立场：**抖音是"内容流推荐引擎"，不是通用视频平台**。剧本由两个引擎共同驱动——
> - **传播工程（进攻，决定破圈）**：让观众**主动转发、评论、收藏、追更**。
> - **留存工程（防守，决定完播）**：让观众**前3秒停下、每一秒留下、把片看完**。
>
> 一句话区分：**看完，是观众为你做的；转发，是观众为自己做的。** 传播工程就是设计"观众为自己传播的理由"，留存工程则保证"有人能看完，传播才有载体"。两者缺一不可。

## 0. 抖音剧本总纲  〔改 2026-09-26 / Doubao；2026-09-27 立铁律5〕

抖音的推荐权重主要由**完播率、互动率（点赞/评论/转发/收藏）、关注转化**构成。剧本阶段就要为此设计，而不是等成片后补救。

| 抖音要什么 | 归属引擎 | 剧本阶段怎么响应 |
|---|---|---|
| 完播率 | 留存（防守） | 前3秒钩子 + 逐秒事件密度（§9、§10） |
| 转发 | 传播（进攻） | 社交货币 / 关系连接 / 情绪过载（§3、§4） |
| 评论、点赞 | 传播（进攻） | 站队 / 对号入座 / 争议 / 提问（§4） |
| 收藏 | 传播（进攻） | 实用清单 / 步骤 / 避坑（§3 动机5） |
| 关注转化 | 传播（进攻） | 人设辨识度 + 系列追更钩子（§5、§11） |

**铁律（优先级最高，覆盖所有编剧步骤）：**

1. **前 3 秒不可浪费在片头/logo/氛围/铺垫上**——第一帧就有可抓的动作、冲突、利益或悬念（§10）。
2. **每一秒都要有"再看一个"的新东西**——动笔前排事件储备清单，不留停滞窗（§9）。
3. **动笔前先定"传播核"**——这条片凭什么被主动转发？给观众一个为自己传播的理由（§2-§6）。
4. **结尾不是"结束"，是"钩子"**——要么给互动指令，要么留让人想评论/回看的点，绝不用标语式总结收尾（§4、§6）。
5. **默认高唤醒、少用留白（2026-09-27 立 · 国内流量场硬铁律）**——① 情绪：以**高唤醒**（解气、爽、爆笑、震撼、愤怒、燃、感动到哭出来）驱动，**禁止让低唤醒情绪（沉默的难过、怅惘、平淡悲伤、崩点静默、安逸）主导全片**，低唤醒抑制转发；② 表达：**少用不点题、开放式、纯画面的留白式表达**，国内用户不习惯"自己悟"，要**直接、给到位、说清楚**——情绪给足、观点亮明、结尾收口或给明确指令；③ 短停顿用于蓄力可以，但不能用长留白 / 黑场 / 空镜代替表达。纯克制留白仅在确有把握的特定文艺向、且显式标注代价时才可破例。

> ⚠️ 边界：抖音优先不意味牺牲质量。低俗、擦边、夸大功效、伪造证据依然违规且会被限流（见 §16 红线）。"让人停留、让人传播"和"诚实"不冲突。

## 1. 双引擎总模型  〔改 2026-09-26 / Doubao〕

抖音主流短视频脚本不是戏剧三段式（起承转合），而是**传播 + 留存双引擎**。创意路线确认后、动笔前，先套这个模型：

```text
┌─ 传播工程（进攻 · 决定破圈）──────────────────┐
│ 传播核：观众为自己什么而转？（六大动机，§3）      │
│ 传播机关：金句/@某人/站队/名场面/争议…（§4）      │
│ 传播路径：主攻 转发/评论/收藏/涨粉（§5）          │
└────────────────────────────────────────┘
            ↑ 传播需要"有人看完"作载体
┌─ 留存工程（防守 · 决定完播）──────────────────┐
│ 黄金3秒钩子（§10）→ 逐秒事件推进（§9）→ 互动收尾 │
└────────────────────────────────────────┘
```

**动笔前自查：**
- [ ] 能不能一句话说清"观众凭什么转发"（传播核）？
- [ ] 前3秒钩子能不能一句话说清"凭什么停下"？
- [ ] 中段每 2-3s 有没有至少一个新事件？
- [ ] 结尾有没有互动钩子，而不是标语总结？
- [ ] 主情绪是高唤醒吗？全片有没有靠长留白 / 不点题糊弄（铁律5）？

# 上篇 · 传播工程（进攻，决定破圈）  〔新增 2026-09-26 / Doubao〕

## 2. 传播工程总览：人为什么主动传播  〔新增 2026-09-26 / Doubao〕

**传播工程的目标**：让观众在没有任何人要求的情况下，主动把内容转发、评论、收藏，并因此带来算法的二次、三次分发，实现破圈。

关键认知：**观众转发不是为了帮你，是为了完成他自己的"社交任务"**——塑造形象、表达态度、维系关系、释放情绪、表明归属。传播工程就是把这些"自我任务"提前埋进内容里。

设计顺序：
1. 先定**传播动机**（这条片满足观众哪个自我任务，§3）。
2. 再选**传播机关**（用什么具体内容机关触发，§4）。
3. 明确**传播路径**（主攻转发/评论/收藏/涨粉，§5）。
4. 填**传播画布**并过**传播力自检**（§6、§7）。

> 🎯 与留存的分工：传播是目的，完播是前提。没人看完就没人转，但只看完不转也不会爆。

## 3. 六大传播动机（诊断罗盘）  〔新增 2026-09-26 / Doubao〕

每条内容**至少命中 1 个**，命中 2 个以上传播力更强。逐个对照诊断：

### 动机 1 · 社交货币（让分享者脸上有光）
- **心理**：分享能让自己显得有见识、消息灵、懂行、有品位、比别人先知道。
- **内容特征**：稀缺信息、内部消息、冷知识、独家方法、"90% 的人不知道"、可炫耀成果。
- **诊断问题**：有没有"值得拿去显摆"的东西？观众转发后，在朋友眼里会不会显得更厉害？

### 动机 2 · 替我表达（观点代言 / 说出心声）
- **心理**：这条片精准说出了我想说却说不好的话；转发 = "这就是我的态度/处境"。
- **内容特征**：金句、立场、群体心声、"互联网嘴替"。
- **诊断问题**：有没有一句话，让某群人想喊"对对对这就是我"？

### 动机 3 · 关系连接（转给具体的人）
- **心理**："这让我想起你""转给需要的人"。转发是维系关系、表达关心、找话题的社交动作。
- **内容特征**：强指代、"@你那个总 XX 的朋友"、特定人群的共同记忆。
- **诊断问题**：观众看时，脑子里会不会立刻浮现一个具体的人？

### 动机 4 · 情绪过载（高唤醒情绪驱动）
- **心理**：高唤醒情绪——愤怒、极度好笑、震撼、爽、感动、震惊——积累到"不分享难受"，必须靠分享释放。**低唤醒情绪（沉默的难过、怅惘、平淡悲伤、崩点静默、安逸）会抑制分享，不得主导全片（铁律5）。** 国内流量场宁可情绪给满、直接点破，也不要"沉默的高级感"。
- **内容特征**：强情绪、名场面、反转打脸、治愈、愤怒点。
- **诊断问题**：情绪强度到了"必须找人说/转给人看"的程度吗？是高唤醒情绪吗？

### 动机 5 · 实用价值（有用，先收藏 / 转给需要的人）
- **心理**：内容实用，怕自己以后用得上（收藏），或觉得对某人有用（转发）。
- **内容特征**：清单、步骤、攻略、模板、避坑、资源。
- **诊断问题**：内容具体到"照着就能做"吗？有没有让人"先收藏，要用时找得到"的价值？

### 动机 6 · 身份归属 / 话题参与（我是这群人 / 我没掉队）
- **心理**：参与大家都在玩的梗、挑战、话题，表明"我是这个群体的一员"。
- **内容特征**：热门梗、挑战、接力、模仿、群体暗号。
- **诊断问题**：能不能套上当下正热的玩法/梗/BGM？有没有让某群体觉得"这是我们的"？

## 4. 传播机关库（把传播做成可植入的内容机关）  〔新增 2026-09-26 / Doubao〕

动机要变成剧本里可勾选、可落地的"机关"。原"互动收尾"是其中的末端机关，现统一在此：

| 机关 | 怎么做 | 喂给哪个动机 | 放置位置 |
|---|---|---|---|
| **金句机关** | 一句可截图、可引用、可当签名的话 | 2 替我表达 / 1 社交货币 | 中段、结尾 |
| **@某人机关** | 制造"这就是 XX"的强指代（"总说要减肥的朋友"） | 3 关系连接 | 中后段、收尾 |
| **站队机关** | 制造一个可争论的点，逼人选边站 | 4 情绪 / 6 归属 | 开头、中段 |
| **对号入座机关** | "你是哪种人？扣 1 / 扣 2" | 6 归属（拉评论） | 中段、收尾 |
| **悬念未解机关** | 故意留一个没说完/没揭晓的点 | 2、4（拉评论、回看） | 收尾 |
| **挑战接力机关** | "@你那个朋友来做 / 转给需要的人" | 6 归属 / 3 关系 | 收尾 |
| **名场面机关** | 制造极具冲击、可被截图做梗的画面 | 4 情绪过载 | 中后段 |
| **争议观点机关** | 提一个反主流但有一定道理的观点 | 4 情绪 / 2 表达 | 开头、收尾 |
| **内幕揭秘机关** | 给"内行才知道"的稀缺信息 | 1 社交货币 | 开头、中段 |
| **干货清单机关** | 可保存的清单/步骤/模板/避坑 | 5 实用价值 | 中段 |
| **提问机关** | 问一个具体、低门槛、好回答的问题 | 2、6（拉评论） | 收尾 |

**收尾话术示例（末端机关）：**
- 提问："你的赛道是什么？评论区告诉我。"
- 转发："转给那个正在纠结的朋友。"
- 收藏："先收藏，要用的时候拿出来。"
- 系列："下条我拆你赛道，关注我。"

> 🎯 规则：① 机关要具体、低门槛、给理由，不能只喊"点个赞"；② 收尾的互动最好在中段就埋点，结尾收口，不凭空问；③ 不靠卖惨、不制造虚假焦虑换传播。

## 5. 传播路径选择（明确主攻方向）  〔新增 2026-09-26 / Doubao〕

一条片不可能同时主攻所有传播，选"主 + 次"，据此安排机关：

| 主攻路径 | 内容重点 | 关键机关 | 主推动机 |
|---|---|---|---|
| **转发破圈** | 社交货币 + 关系 + 情绪 | @某人、转给谁、名场面 | 1 / 3 / 4 |
| **评论刷屏** | 站队 + 对号入座 + 争议 | 站队、提问、悬念 | 4 / 6 / 2 |
| **收藏沉淀** | 实用 | 清单、步骤、避坑 | 5 |
| **涨粉追更** | 身份归属 + 系列钩子 | 人设、连载、留钩 | 6 |

> 🎯 系列化与辨识度：涨粉靠"可追更"。固定开场/口头禅/视觉锤，让用户一刷就知道是你；每支片结尾留连载钩子，把单条爆款变成可复制的模板。

## 7. 传播力自检闸门（进攻门）  〔新增 2026-09-26 / Doubao〕

逐项自检，任一不过先回剧本层改：

- [ ] 能用一句话说清"观众为自己什么而转发"？（至少命中 1 个动机）
- [ ] 有没有一句可截图 / 可引用的金句？
- [ ] 观众脑子里会不会浮现一个具体的人（@谁 / 转给谁）？
- [ ] 主情绪是不是**高唤醒**，强度到了"不分享难受"？
- [ ] 有没有可站队 / 可对号入座 / 可争论的点？
- [ ] 标题和封面本身有没有传播欲（好奇 / 冲突 / 利益）？
- [ ] 收尾有没有具体、低门槛、给理由的互动指令？

> 🎯 与转化 CTA 的关系：广告片的 CTA（购买/私信/落地页）保留，但**互动传播 ≠ 转化 CTA**——前者让内容被更多人看到，后者让看到的人行动；可叠加，但要分清主目标。

# 下篇 · 留存工程（防守，决定完播）

## 8. 先写节拍，再拆镜头  〔改 2026-09-26 / Doubao〕

"拍"指观众理解、期待、感受或判断发生一次变化，不等于一个镜头。一个长镜头可以有多拍，多次切镜也可能一直没有推进。

写出开场状态、关键兑现与结果，再安排连接它们所需的最少节拍。**"最少节拍"由事件储备清单决定，不由叙事结构决定。**

| 时间/镜号 | 可见动作与可听声音 | 观众已知 / 仍期待 | 本拍改变或深化什么 | 删除损失 | 引擎作用 |
|---|---|---|---|---|---|
| 按任务填写 | 写实际行为，不写抽象情绪结论 | 好奇片写待解问题，感官片写正在期待的触感 | 信息、选择、关系、证据或感官状态 | 若无损失则删除/合并；有意留白说明作用 | 标注"钩子/推进/兑现/互动"+秒数 |

这张表可与制作镜头表合并；补上景别、文字、资产来源、生成/实拍分工即可，不重复输出两套镜头。时长按实际动作与语言估算。

> 🎯 每个节拍都要能回答"观众为什么没在这一秒划走"。写不出的拍，删。

## 9. 事件储备清单（留存硬门）  〔新增 2026-09-26 / Doubao〕

原 SOP 把"事件密度 [C] 闸门"放在分镜阶段量化，存在时序错位——**现提前到剧本定稿**：

```text
# 事件储备清单（剧本阶段）

目标时长：____ s
全片"新事件"总数：____
AEI（平均事件间隔）= 时长 / 事件数：默认 ≤2.5s

逐拍新事件清单：
| 序号 | 时间点 | 新事件（动作/台词/信息/情绪/关系/悬念） | 属于哪个节拍 |
|---|---|---|---|
| 1 | 0-3s | 钩子事件：____ | 钩子 |
| 2 | 3-6s | 推进事件：____ | 推进 |
| ... | ... | ... | ... |

检查：
- 是否存在任一 ≥2.5s 窗口"零新事件"（画面在动≠在推进）？有→退回复排
- 事件条数 ×2.5s ≈ 片长；事件不够→压时长，禁用空镜/慢动作/氛围注水拉长
```

**判断标准：**
- **新事件** = 观众能感知的推进：新动作 / 状态突变 / 反应 / 新台词 / 揭示 / 情绪转 / 关系变化 / 悬念递增。
- **停滞窗**（任一 ≥2.5s 零新事件）是留存头号杀手，剧本阶段标出删掉。
- **单通道陷阱**：每拍信息通道（动作/对白/表情/道具/环境/声效）应 ≥2；"站桩念白 / 纯氛围空镜"判稀，加通道或删。
- **增量原则**：每拍写出"相对上一拍推进了什么"；写不出增量的是注水拍，删。

> 🎯 与 SOP 关系：此处是剧本层 [C5]，分镜阶段 [C1-C4]/[R] 仍按 SOP 逐拍验证。剧本层先定事件，分镜层再落镜头。

## 10. 钩子设计：A/B 候选 + 3 秒预期  〔新增 2026-09-26 / Doubao〕

前 3 秒的竞争对象是"用户在信息流里一划而过"。剧本阶段即产出钩子候选并预估停留。

| 钩子类型 | 用法 | 适用场景 |
|---|---|---|
| 反常识结论 | 挑战行业默认做法，但必须能用内容证明 | 知识/观点 |
| 利益承诺 | 开头直接给"看完你能得到什么" | 干货/教程 |
| 悬念前置 | 一个异常画面/半句话，让人必须看下去 | 剧情/故事 |
| 站队冲突 | 让不同立场的人一上来就有反应 | 争议/观点 |
| 结果先行 | 先展示最终效果/结果，再倒推 | 演示/开箱 |
| 连续动作 | 一个不可逆、满足感强或有悬念的动作 | 手工/过程 |

**钩子 A/B 候选（必填）：**

```text
钩子 A：____（类型：____）首句/首画面：____
  3 秒停留预期（高/中/低）：____ 与中段承诺衔接：____
钩子 B：____（类型：____）首句/首画面：____
  3 秒停留预期（高/中/低）：____ 与中段承诺衔接：____
```

> 🎯 钩子必须与中后段**兑现同一承诺**；禁止"钩子很猛，后文无关"。

# 落地篇 · 编剧执行

## 11. 让人物通过选择成立  〔保留 2026-09-26 / Doubao〕

只为有人物的路线使用：人物想完成什么，习惯怎样做，什么阻止他，最后做了哪个不同选择？阻力可以很小（习惯性忙碌、欲言又止、穿搭不确定）；不必制造悲惨身世。

| 模糊写法 | 可表演写法 | 变化依据 |
|---|---|---|
| 她疲惫却温柔 | 清单已经合上，她又伸手把胸花摆正 | 完成工作后仍放不下照料习惯 |
| 她终于自信 | 她把家务物件放回去，提包走向等她的人 | 从继续忙碌转为参与自己的时刻 |
| 他很尴尬 | 他第三次拿起同一条不匹配的线，又原样放回 | 尴尬来自动作重复 |
| 食物让人满足 | 手准备放下，停一下，再取一小块；留咀嚼间隙 | 仅为虚构/真实体验，非普遍证明 |

允许人物不笑、不哭、不说教。先拍刺激与反应，再决定台词是否必要。保留人物主动性，不默认靠他人认可或买了商品才获得尊严。

> 🎯 行为化让"选择/反应"可见，是留存所需的"事件"，也是情绪过载的载体。

## 12. 组织知情差与兑现  〔保留 2026-09-26 / Doubao〕

- **观众先知道**：让人等待角色发现或完成，适合观察式幽默、参与判断。
- **角色先知道**：让人寻找可见线索，揭晓时回想"原来前面是这个意思"。
- **同步体验**：共同等待操作结果、声音释放或材质变化，适合证明与感官片。

选一种主知情差，不要求每片悬疑。暂留答案时仍给观众方向；片尾不能突然引入从未铺垫的新事实。转折可以是决定、关系变化、证据出现或感官完成，不必是变身。

> 🎯 知情差是"悬念递增"引擎，喂给事件储备清单；别三条混用导致看不懂。

## 13. 让商品进入关键体验  〔保留 2026-09-26 / Doubao〕

商品可提供解决办法、成为感官对象、完成搭配、承载赠予或参加仪式。给它一个可辨认的关键动作及真实细节。"装下整场婚礼用品"必须有容量依据。商品不必制造人物成长，但不能等故事结束才作无关贴片。片尾真实素材的光线、构图与前文尽量连续，真实保真优先于无痕转场。

> 🎯 商品关键动作尽量安排在**前中段**——抖音 8-10s 有一波掉档，商品参与越早越能留住"想看结果"的人。

## 14. 台词、声音与停顿（少用留白）  〔改 2026-09-26 / Doubao；2026-09-27〕

- 台词像这个人此刻会说的话；删复述画面的句子和"从此活出自我"式总结。
- 每个关键节拍选一个主要承载通道（画面/对白/旁白/字幕/环境声），其他辅助，不把所有通道叠成同一句。
- 声音可先于画面引出期待；旁白短于片长不是错误，不为填满时长补口号。
- **区分停顿与留白（铁律5）**：短停顿（0.3–0.8s）用来蓄力、给反应，是好的；**长留白、不点题、开放式收尾要少用**——国内用户要"说清楚、给到位"，关键情绪和观点别只靠画面让观众猜。
- 删除解释性旁白再读脚本定位缺失；读出台词预演动作并计入反应、取放、视线与商品识别时间；超时先删重复，不极端调速。

**抖音特有要求：**
- **短句优先**：长句、书面腔会被划走；拆短句、加停顿。
- **口语前置**：第一句就用日常语气，不要"大家好今天给大家……"的开场腔。
- **情绪词适度**：真实不尬喊。
- **字幕承载**：关键信息、数字、金句上字幕（后期确定性渲染），大量用户静音刷。

## 15. 三轮改稿（双引擎视角）  〔改 2026-09-26 / Doubao〕

1. **路线轮**：检验传播核、观看承诺、商品角色是否成立。
2. **导演轮**：把解释换成行为，确定知情顺序与关键反应。
3. **减法轮**：删重复字幕、强行升华、无效转场、过多台词。

**追加两轮专项：**
- **传播轮（进攻）**：核对六大动机命中、金句、@某人、站队/争议、收尾机关；过传播力自检（§7）。
- **留存轮（防守）**：逐秒过事件储备清单，标停滞窗；检查钩子 3 秒内出现、收尾有互动。

每轮记录"原问题 -> 改动 -> 预期改善 -> 新代价/待验证"，保留可比较版本；版本更新不代表更优，可选回较早版。先在脚本与低成本预演中处理，不变成固定多次付费生成。

## 16. 亲密与高冲击张力设计（按内容需要选用）  〔保留 2026-09-26 / Doubao〕

**问题背景**：克制/留白（见 `emotional-drama-storycraft.md`）不是全类型通用打法。甜宠 / 强关系情侣 / 爽感 / 短剧向，观众要**简单直接、反差强、有视觉冲击力**的兑现。刷剧为看现实里得不到的——夸张、代入、愿望兑现、情欲张力带来的"联想·记住·幻想"。

**目标是"情欲张力"不是"露骨"**：让人联想、记住、幻想，靠渴望被压住、就差一点的临界感、喘息与眼神；裸露/生理特写/脱衣挑逗既不撩又违规。

**先判赛道**：克制线问"观众缺什么、靠留白填"；高冲击线问"这拍给没给到爽点、有没有反差、让人联想"。两条线别混用。

**封顶线（主动做足）**：
1. **动作层**：强吻/热吻/疯狂亲吻、突然拉近/壁咚、扣手腕、揽腰、额抵额、欲拒还迎。
2. **张力层**：喘粗气、咬唇、喉结滚动、指尖犹豫又落下、眼神从躲闪到锁死、话被吻断——微表情+停顿+急促呼吸比动作本身更抓人。
3. **临界点张力（重点）**：即将亲密前的狂热——喘息、咬唇、急切亲吻、越贴越紧、一触即发；镜头收在临界点（渐隐/切黑/门关上/手推灭灯），把想象交给观众。
4. **反差层**：先冷/克制，再突然爆发；一场戏只顶一个高潮。

**红线（硬约束，只挡会被封的那截）**：
- **做满**：情欲张力、临界前戏狂热、让人联想幻想的撩——核心卖点，主动做足。
- **不做**：① 露骨性行为过程；② 以性化身体为卖点（裸露、生理特写、脱衣挑逗当主体）。封顶到"拥吻+贴近+临界张力"，往下不写、不生成。
- **为什么**：抖音/视频号/快手把"低俗/软色情/擦边"列为点名违规品类，直接限流、封 dou+、封号。露骨版不撩又毁号，张力版又撩又安全。

**落地手艺**：
- 状态突变亲密动作用 **FL2VA 锁首尾帧**，逐动词写，单首帧 I2VA 会漏演。
- 给脸、给手、给呼吸：顶点用近景/特写兑现微表情与细节。
- 真实质感优先：肤质、呼吸、自然光，禁塑料感/蜡感/磨皮假脸。

## 17. 总自检与成片复核  〔改 2026-09-26 / Doubao〕

### 17.1 剧本定稿前总自检（任一不过回剧本层，不进分镜）

**传播（进攻）：**
- [ ] 传播画布填满？命中 ≥1 个传播动机？
- [ ] 有可截图金句？有可站队/对号入座/争论点？
- [ ] 观众会浮现具体的人（@谁/转给谁）？主情绪高唤醒？
- [ ] 收尾有具体、给理由的互动指令？
- [ ] **主情绪高唤醒、全片无低唤醒主导？没有用长留白 / 不点题 / 黑场空镜代替表达（铁律5）？**

**留存（防守）：**
- [ ] 前3秒有可抓钩子且产出 A/B 候选？
- [ ] 事件储备清单填满、AEI≤2.5s、无停滞窗？
- [ ] 每拍信息通道 ≥2，无站桩念白/纯氛围空镜？

**执行：**
- [ ] 商品关键动作在前中段、有事实支持？
- [ ] 台词短句口语化、关键信息计划上字幕？
- [ ] 动作/台词能在时长内完成，摄影机拍得到所有内容？

### 17.2 成片复核（人工看整片）

不能只查四张截图。完整播放并听审，定位首屏、第一次推进、主要兑现、结尾；检查表演与剪辑是否实现节拍、商品能否辨认、停顿是蓄力还是空转、配乐是否掩盖动作对白。

**抖音追加项：**
- 前3秒实际效果是否符合钩子预期（可小范围试看）。
- 是否有 8-10s 掉档（钩子空头/中段没兑现）。
- 结尾互动是否真的落地（有没有引导评论/转发）。
- 情绪是否真的"给足"（高唤醒），还是靠留白 / 沉默让观众自己体会——后者按铁律5判不达标。

无法播放/听审时写明限制，不把抽帧检查记作验收通过。未作观看者测试时结论仅为创作判断；待验证项要具体，不声称必然提高完播或转化。
