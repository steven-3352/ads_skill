# 从创意到可表演的脚本

用于脚本展开、改稿和成片叙事验收。创意入口与统一创意门见 `creative-attention.md`。先处理观看体验，再处理分镜格式；只给用户与当前任务相关的细节。

> **情感/剧情类项目**深化"把情绪落实成表演"时，另见 `references/emotional-drama-storycraft.md`（潜台词双写、未说出口的话、金句、心理节拍表）。创意广告/带货片只借鉴其第一、二章编剧内核，不套用情感专属红线（缺失只显影、结尾不点题、克制=稀缺）。

## 1. 先写节拍，再拆镜头

“拍”指观众理解、期待、感受或判断发生一次变化，不等于一个镜头。一个长镜头可以有多拍，多次切镜也可能一直没有推进。

写出开场状态、关键兑现与结果，再安排连接它们所需的最少节拍。开场可以是一个未完成动作、可辨认矛盾、直接结果或感官邀请；不要为所谓强钩子添加与后文无关的事故、争吵或惊吓。

| 时间/镜号 | 可见动作与可听声音 | 观众已知 / 仍期待 | 本拍改变或深化什么 | 删除损失 |
|---|---|---|---|---|
| 按任务填写 | 写实际行为，不写抽象情绪结论 | 好奇片写待解问题，感官片可写正在期待的触感或完成 | 信息、选择、关系、证据或感官状态 | 若无损失则删除/合并；有意留白说明其作用 |

这张表可与制作镜头表合并；补上景别、文字、资产来源、生成/实拍分工即可，不要重复输出两套相同镜头。时长按实际动作与语言估算，节拍数量不固定。

## 2. 让人物通过选择成立

只为有人物的路线使用：人物想完成什么，习惯怎样做，什么阻止他，最后做了哪个不同选择？阻力可以很小，例如习惯性忙碌、欲言又止、穿搭不确定；不必制造悲惨身世。

把情绪指令翻译成行为：

| 模糊写法 | 可表演写法 | 变化依据 |
|---|---|---|
| 她疲惫却温柔 | 清单已经合上，她又伸手把胸花摆正 | 完成工作后仍放不下照料习惯 |
| 她终于自信 | 她把刚拿起的家务物件放回去，提包走向等她的人 | 从继续忙碌转为参与自己的时刻 |
| 他很尴尬 | 他第三次拿起同一条不匹配的线，又原样放回 | 尴尬来自动作重复，而非挤眉弄眼 |
| 食物让人满足 | 手原本准备放下，停一下，再取一小块；保留咀嚼间隙 | 仅为虚构表演或真实体验，不能当普遍效果证明 |

允许人物不笑、不哭、不说大道理。先拍刺激与反应，再决定台词是否必要。保留人物主动性，不默认靠子女认可、伴侣赞美或买了商品才获得尊严。外部角色可以提示或回应，不能无意中取代主角的选择。

## 3. 组织知情差与兑现

- 观众先知道：让人等待角色发现或完成，适合观察式幽默、参与判断。
- 角色先知道：让人寻找可见线索，揭晓时能回想“原来前面是这个意思”。
- 同步体验：共同等待操作结果、声音释放或材质变化，适合证明与感官片。

选择适用的一种，不要求每片悬疑。暂留答案时仍给观众足够的方向；片尾不能突然引入从未铺垫的新事实来制造反转。广告开场承诺测容量，就应兑现容量判断，不能最后只给漂亮外观。

转折可以是决定、关系变化、证据出现或感官完成，不必是变身。镜头中的动作看起来连续却缺少心理或功能原因时，运镜和特效无法补上因果。

## 4. 让商品进入关键体验

商品可以提供解决办法、成为感官对象、完成搭配、承载赠予或参加仪式。选定角色后，给它一个可辨认的关键动作及对应真实细节。

例如包的提起、佩戴与礼服关系可以支持搭配表达；“装下整场婚礼用品”必须有容量依据。商品不必制造人物成长，但不能永远等故事结束才作为无关贴片出现。片尾真实素材的光线、构图与前文尽量连续，真实保真优先于无痕转场。

## 5. 台词、声音与留白

- 台词应像这个人在这个时刻会说的话。删去只复述可见动作的句子，以及“从此活出自我”式替角色总结人生的话。
- 每个关键节拍选择画面、对白、旁白、字幕、环境声中的主要承载者，其他通道辅助。静音版本可以补必要字幕，但不把所有通道叠成同一句话。
- 声音可以先于画面引出期待，动作完成后可以保留安静。旁白短于片长不是错误；不为填满时长补口号。
- 删除解释性旁白再读脚本，定位失去的必要信息；优先补行为、证据或少量字幕。对白驱动的喜剧、访谈不必删除对白，声音驱动的广告不强求无声保留全部体验。
- 读出台词并预演动作，计入反应、取放、视线转移与商品识别时间。超时先删重复信息，不用极端调速或把多个复杂动作塞进一秒。

## 6. 三轮改稿，各修一个问题

用于用户要求打磨、多个版本或方案存在明显问题时；简单任务不必展示全部过程。

1. **路线轮**：检验观看承诺是否具体、兑现是否值得等、商品角色是否成立。保留目标与事实，允许更换入口；已经确认的路线则只在范围内修正。
2. **导演轮**：将解释换成行为，确定知情顺序与关键反应；让人物或演示操作推动变化。
3. **减法轮**：删重复字幕、强行升华、无效转场和过多台词，检查承诺、商品与结尾能否保住。减法导致难懂就恢复必要线索。

每轮记录“原问题 -> 改动 -> 预期改善 -> 新代价/待验证”，保留完整可比较版本。版本更新不代表更优；按目标推荐，可以选回较早版。不要把三轮变成固定三次付费生成，先在脚本与低成本预演中处理。

## 8. 亲密与高冲击张力设计（按内容需要选用）

**问题背景**：现有情感线默认走克制/留白（见 `emotional-drama-storycraft.md`），但那不是全类型通用打法。甜宠 / 强关系情侣 / 爽感 / 短剧向的片子，观众要的是**简单直接、反差强、有视觉冲击力**的兑现，平淡叙事、句句留白、引人深思在这条赛道上就是没人看。**为什么短剧爆**：刷剧是为了看现实里得不到的——夸张、代入、愿望兑现、情欲张力带来的"联想·记住·幻想"。所以剧本设计到情侣强关系时，必须**在人物内心、表情、亲密动作上下狠功夫，主动设计出有冲击力的情欲张力**，不能默认交白卷、也不能只冷静念台词。

**目标是"情欲张力"，不是"露骨"——两者天差地别**：让人**联想、记住、幻想**的视觉冲击，靠的是渴望被压住、就差一点的临界感、喘息与眼神——这是要做足的爽点引擎；而裸露 / 生理特写 / 脱衣挑逗那种**露骨**版本既不撩（想象空间被填满就没劲了），又直接违规。把张力做满、把露骨切掉，才是短剧真正的配方。

**先判赛道（一句话判据）**：*克制线问"观众缺什么、靠留白填"；高冲击线问"这一拍给没给到爽点、有没有反差、有没有让人联想"。* 两条线别混用——克制片强上狗血亲密＝廉价，高冲击片处处留白＝闷死。开工前先定这片走哪条。

**封顶线（可做、且应主动做足）**——情侣强关系里把张力演到位，不要只冷静念台词：
1. **动作层**：强吻 / 唇吻、热吻、疯狂亲吻、边吻边拥抱、突然拉近 / 壁咚、扣手腕、揽腰、额抵额、欲拒还迎的身体拉扯。
2. **张力层**：喘粗气 / 呼吸急促、咬嘴唇、喉结滚动、指尖犹豫又落下、眼神从躲闪到锁死、话说到一半被吻断——用**微表情 + 停顿 + 急促呼吸**把荷尔蒙逼出来，比动作本身更抓人。
3. **"临界点"张力（重点做足，不是禁区）**：两个人**即将发生亲密关系前**的那种狂热——喘息变重、咬唇、疯狂而急切的亲吻、身体越贴越紧、"马上就要发生"的一触即发。这一层**正是擦边张力的顶点，要主动设计、演到位**。镜头收在这个临界点上（渐隐 / 切黑 / 转场 / 门关上 / 手推灭台灯），把想象空间交给观众——**收在"就差一点"比拍出后续更撩、也不触红线**。往下的行为本身不写、不拍、不生成（见下方红线）。
4. **反差层**：冲击力来自落差。先冷 / 先推 / 先克制，再突然爆发；先端着，再破防。平均用力＝没有高潮（同 `emotional-drama-storycraft` §6 松-紧模型，此处紧的一头往"炸"走而非往"崩"走）。一场戏只顶一个亲密高潮，别句句加码。

**红线（只挡会害你被封的那一小截，硬约束）**：
- **要做满的**：情欲张力、性张力、临界前戏的狂热（喘息 / 咬唇 / 疯狂亲吻 / 一触即发）、让人联想与幻想的撩——这些**不在红线内，是这条赛道的核心卖点，主动做足**。
- **不做的**：① 露骨性行为的具体过程；② 以**性化身体为卖点**的镜头——裸露、生理部位特写、脱衣挑逗当主体。封顶就到"拥吻 + 身体贴近 + 就差一点的临界张力"，镜头收在临界点，往下不写、不生成。
- **为什么就卡这一条**：国内平台（抖音 / 视频号 / 快手）把**"低俗 / 软色情 / 擦边"作为被点名的违规品类**写进处罚条款——不是"软色情算不算色情"的争论，是平台拿这个标签直接限流、封 dou+、封号。露骨版本因此**既不撩（想象空间被填满）、又毁账号**，双输；而情欲张力版本**又撩、又安全**——这正是短剧真能爆的原因。与全项目合规经验同一逻辑（见记忆 `no-brand-products-in-videos`：违规内容会限流）。

**落地手艺（接生产 SOP）**：
- **状态突变的亲密动作用 FL2VA 锁首尾帧**（突然拉近、被吻断、揽腰入怀这类改变身体位置 / 状态的动作），摆好落点、逐动词写，单首帧 I2VA 会漏演（见记忆 `fl2va-for-state-change-actions`）。
- **给脸、给手、给呼吸**：亲密顶点用近景 / 特写兑现微表情与细节（指尖、喉结、睫毛、贴近的侧脸），别用远景糊过去。
- **真实质感优先**：肤质、呼吸、自然光，禁塑料感 / 蜡感 / 磨皮假脸（见记忆 `iphone-realistic-no-plastic-texture` / `soft-light-no-facial-glare`）。

## 7. 开拍前与成片后检查

开拍前完成删镜、商品替换、承诺兑现与动作计时检查。只有关键动作需要生成验证时，再按已批准预算做最小验证；不为脚本评审自行调用付费服务。

成片不能只查四张截图。完整播放并听审，定位首屏、第一次推进、主要兑现和结尾；检查实际表演与剪辑是否实现节拍，以及商品能否辨认。检查停顿是蓄力还是空转，配乐是否掩盖动作和对白。静音检查用于必要信息可读性，不用于否定声音本身的创意价值。

无法播放/听审时写明限制，不把抽帧检查记作叙事验收通过。未作观看者测试时，结论只能是创作判断；待验证项应具体，例如“清单含义能否在两秒内读懂”，不要声称必然提高完播或转化。
