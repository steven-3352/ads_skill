## 铁律 0：一切以故事原文为准

故事原文（用户提供的 `story/*.md` 或口述原始故事）是**唯一事实源**。人物、动作、台词、主题、机关一律以原文为准；剧本、分镜、提示词、剪辑、旁白都不得偏离或"自行加戏改味"。新发现的缺陷要**上报**、不要擅自改故事。

## 一、驱动方式：从故事推导，在编剧阶段就定

**定义**：驱动 = 把观众一秒秒往前拉、并组织剪辑的发动机。

### 铁律 1：驱动不是剪辑阶段的补救，是编剧阶段的产出
- 写 / 完善剧本时，**必须同时判定"这片由什么驱动"**，并让剧本结构、节拍、台词、机关都服务于该驱动。
- 判定依据 = **故事原文 + 主题**（不是先有方法论再套故事）。先读懂原文想说什么，再决定用什么发动机说。
- 驱动一旦定了，后续分镜/提示词/剪辑都是在**兑现**这个驱动，不能中途换挡或散架。

### 驱动清单

| 驱动 | 发动机 | 适合 | 代表 |
|---|---|---|---|
| 对白驱动 | 台词给信息/因果/转折 | 有多幕**情节**、信息量大 | 《托孤》 |
| 旁白驱动 | 第一/三人称独白讲意义 | 有内心独白/回望 | 情感短片 |
| 动作·事件驱动 | "接下来会怎样"的物理因果 | 强情节、少话 | 悬疑/动作 |
| 物件·意象驱动 | 一个反复出现的物件扛住含义 | 单一处境、靠象征 | 《副驾》空副驾 |
| 对比·结构驱动 | 意义从并置本身长出来（then/now、有/无） | 靠对仗/match-cut 说话 | 《副驾》有她↔空座 |
| 音乐·节奏驱动 | 音乐规定情绪曲线与剪切点 | 少对白、重情绪 | MV |
| 氛围驱动 | 光影+表演+调色堆气氛 | **不可单独使用** | —— |

### 关键判据
- 有多幕情节、信息量大 → **对白 / 旁白**驱动（用"话"承载因果与情绪转折）。
- 单一处境、靠象征或回望 → **物件意象 + 对比结构**为主引擎，**音乐**为动力，**旁白**点睛。
- **氛围永远不能单独驱动**：氛围没有前进矢量，单用 = 幻灯片的根源。必须挂在音乐 / 悬念 / 对比之上。

### 组合原则（大多数片子是分层的）
一个**主引擎** + **动力（音乐）** + **点睛（旁白/字幕）** + **缝合（声音动机/声画桥）**。
**在剧本里就标注每一层由谁承担**，别到剪辑才想。

- 例·《托孤》：对白=主引擎（话讲一个故事），连续声音托底。
- 例·《副驾》：对比结构+物件（空副驾、红灯伸手 07有她↔10空座）=主引擎；音乐=动力（治"缺一口气"）；极简旁白=点睛（把"对着空座说话"点破成普世认知）；声音动机=缝合 then↔now。
  一句话：**托孤靠"话"讲一个故事，副驾靠"反差+音乐"说破一件心事。**

## 二、无幻灯片连贯性 SOP【强制】（MiniMax-H3 / SeaDance）

**根因**：自动分镜只输出单镜画面，缺前后视觉锚点、微运镜、过渡规则；独立生成的分镜硬切后 = 幻灯片；单镜无动态 = 画面发闷。

### 五条强制前置规则
1. **相邻分镜共用视觉锚点**：前镜落幅锚点 = 后镜起幅锚点（完全一致）。这是治 PPT 的根——**事后剪不出来，必须用锚点匹配的首/尾帧重新生成**；不能重生成时，用 0.3s 叠化 + 微推做近似。
2. **相邻镜统一 0.3s 叠化过渡，禁纯硬切**。
   - 例外：**情绪性签名硬切**（如暖硬切冷）可保留，但必须是"设计过的那一次"，不是默认偷懒。
3. **单镜 1.8–3s，禁超 4s**。
4. **每镜携带 1 种微运镜，禁纯静止定镜**（静止=发闷=慢）。静止镜用 2× 上采样后慢推（zoompan）消抖。
5. **全片光影色调参数统一**，避免跳色；必要的冷暖对比让色变发生在叠化中，不要"啪"地跳。

### 单镜 6 段结构
镜号+精准时长 / 起幅锚点(承上镜落幅) / 主体画面+环境微动态 / 小幅连贯运镜轨迹 / 统一光影色调参数 / 落幅锚点(为下镜留衔接)。

### 从主题到成片自动 SOP
1. 主题录入：明确核心场景、情绪、实拍质感。
2. **剧本 skill 按动作节点拆段落**（不按固定时长切块），同时定驱动（见第一节）。
3. 套导演级分镜模板，自动补全锚点、运镜、光影参数。
4. 按对应模型参数导出单镜独立视频。
5. 批量添加 0.3s 叠化，拼接为连贯成片。

## 三、慢感诊断五因（验收自查）

片子"慢/闷/像 PPT"时，逐条查（平均单镜时长≈3s 也可能很慢，因为慢感不来自时长）：
1. **匀速无快切段**：全片一个节奏，缺对白驱动的 1–2s 快切段提气。
2. **单镜内部运动飘慢还长 held**：AI 生成动作本就飘慢，还长时间保留。
3. **沉默无前进动力**：没有连续人声/音乐往前拉。
4. **静止镜过多**：故意做静的镜头占比过高。
5. **慢尾**：结尾长镜 + 死黑主题卡拖节奏。
