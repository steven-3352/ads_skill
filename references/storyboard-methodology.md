# 分镜方法论（推理层）

> **定位**：本文是「分镜」这一环的**推理层**——只回答「为什么这样拆、何时用哪种镜型与生成模式、怎么判好坏、出问题回到哪一步」。
> **权威边界**：产出模板、门禁、状态机、模型路由的**唯一权威是 `video-production-sop.md`**（§9 节拍映射、§10 镜头规格、§12 图片闸门、§5 模型路由、§13 文字对白）。**本文不复述这些字段与条款**，只在需要时给结论并指向 SOP 章节，避免两处漂移。
> **覆盖**：视频镜头分镜 / 图片关键帧分镜 / 图文（小红书 5 图）分镜。
> **来源**：有边界地吸收《口播驱动情感短剧分镜设计》案例手册的创作推理层（标「【吸收】」）。情感专属手法在广告/带货片的边界见第 7 章。

---

## 1. 第一性原理

**分镜 = 把「观众状态如何变化」翻译成「可被一张图证明、可被一个模型生成、可被删检验收的镜头序列」。**

合格分镜同时满足三个约束（缺一即翻车）：

| 约束 | 判据（权威在 SOP） | 违反后果 |
|---|---|---|
| 每拍有新推进 | §9 [C] 门 | 观感慢、留不住人 |
| 每镜能被一张关键帧证明 | §12 图片闸门 | 生成漂移、付费打水漂 |
| 每镜删了有损失 | 逐拍不可删 | 冗余、幻灯片 |

**信息逐层向下继承，不丢失**（全流程主轴，也是「连贯」的物理保证——任一镜都能回溯到它服务的观众状态变化）：

```
观众状态曲线(SD) → §9 节拍映射 → 镜型+生成模式(本文4-5章) → §10 镜头规格 → 关键帧(§12) → 视频 → 验收 → 终剪
```

SOP 硬规则：§10 镜头表必须**继承** §9 节拍映射，不得另起炉灶。本文其余各章都是在这条链的某一环上补「怎么决策」。

## 2. 叙事层：先定观众状态，再拆节拍

- 动手拆镜前先写**观众状态曲线**（好奇→理解→认同→行动），并把情绪翻译成**可拍摄的具体行为**（详见 `script-direction.md`）。
- 叙事层模板是 **§9 节拍映射表**（字段与填法见 SOP §9），本文只强调两个后文反复要用的论断：
  - **「本拍新增」是核心字段**——这一拍要观众**看到**什么新东西。选不出，该拍/该镜就不该存在。（贯穿第 3、4、6 章）
  - **事件储备定片长；留存病根在内容层，不在切换频率**（§9 [C] 门结论）。长镜只要镜内有推进也留得住人——这是第 6 章节奏诊断的前提。

## 3. 逐句拆镜工作流【吸收】

> SOP 只有原则（align-voice-to-picture：旁白按真实时间逐句重放），**未成工作流**。这里补齐。
> **适用**：旁白/口播/对白驱动的叙事片、情感微剧。**不适用**：纯演示、产品硬广（用第 2 章「本拍新增」原则即可）。

**两个底层机制：**
- **连续音频铺底**：口播/对白/环境声是一条**连续**时间轴，画面在其上切换——声音不断、情绪不断。
- **同场景多景别**：优先在**同一场景内换景别/机位**（全→中→近→特），而非频繁换场景。这是「切很多刀却不散」的关键：空间锚点不变，观众不迷路。

> **🔴 硬红线·已固化为机器门禁（死命令 `ban-dead-air-content`）**：以上「连续音频铺底」不再是靠人读自觉的软约束。**禁止留白式内容**——对白驱动片时长必须服从对白密度：每镜时长 = 对白字数 ÷ ~4 字/秒 + 必要动作余量，密度不得低于 **3.0 字/秒下限**（爆款样本 ~4.5，成片建议 3.3–3.8）。`scripts/validate-production-plan.mjs` 已加**对白密度门**：凡覆盖 `dialogue` 通道的生成单元，`对白字数 ÷ durationSeconds < 下限`（可经 `constraints.minDialogueCharsPerSecond` 调）即 fail。历史教训：本约束曾只写在本文档、未进校验器，导致「30 字标 16 秒」的留白虚标一路放行 = 片子慢。唯一例外＝崩点/告别的有意静默（第 7 章），须在 plan `unit.dialogueDensityExempt` 具名写明理由才豁免。**预告片反向坑**：不是拉长而是砍对白留钩子，密度也别冲过头（>4.5 会赶到听不清，违反 `commercial-dialogue-legibility`）。

**七步：** ①锁口播逐句编号 → ②每句标「本拍新增（要看到什么）」 → ③每句配一个镜型（第 4 章） → ④相邻句判定：默认同场景换景别，只有真跳空间/时间才换场景 → ⑤道具/视线接力衔接 → ⑥标崩点与金句（第 7 章） → ⑦回填 §9/§10。

**示例**（同场景换景别，音频连续）：
```
L1「我以为我们能一直这样。」  → 中景：两人隔餐桌不对视（定关系）
L2（3 拍停顿，无词）          → 近景：她的手停在杯上（崩点留白）
L3「你早就想走了吧。」        → 正打特写：她抬眼
L4（无词）                   → 反打特写：他移开视线（兑现「不敢对视」）
```
四刀同在餐桌场景内换景别、音频连续——连贯不散，却拆出 4 个可独立生成/验收的镜。

## 4. 镜型学【吸收】

> SOP 只有「景别」字段 + 「按场景选镜头语言」原则，**无镜型清单**。这是一套**可选决策清单**（非强制套用）。「生成模式」列的完整定义见 SOP §5。

| 镜型 | 何时用 | 模式 | 常见错误 |
|---|---|---|---|
| 定场镜 | 建立空间/关系 | I2VA/Ref2VA | 太久、无信息 |
| 人物近景/特写 | 情绪内心，演微表情/眼神/停顿 | Ref2VA | 用中景糊过去，情绪没顶出来 |
| 正反打对话镜 | 对白/关系摩擦（覆盖剪辑核心） | Ref2VA×2 机位 | 两人同框一镜到底念台词=幻灯片 |
| 物品镜/道具特写【吸收·改造】 | 状态变化落点、道具接力 | FL2VA/I2VA | 当装饰空镜——**必须承担叙事职责**：它变了什么，或接住上一镜什么 |
| 手部/动作特写 | 兑现改变物体状态的动作 | **FL2VA** | 用 I2VA 单首帧→动作漏演 |
| 闪回/时间标记镜【吸收】 | 时间跳跃 | Ref2VA/I2VA | 打字幕「三年后」——**改用换装/光线/道具变化**标记，成片零字幕 |
| 签名镜/固定机位 | 冷线、克制、品牌记忆锚点 | I2VA(静止) | 到处用，失去「签名」意义 |
| 空镜/氛围镜 | 崩点留白、呼吸、过场 | T2VA/I2VA | 无 soundscape 的无声镜(违 §13)；不承载情绪又不删 |

**两条铁律：** ①镜型服务「本拍新增」，给不出新东西的镜删掉。②【吸收】**物品镜不是空镜**：要么标记状态变化（杯满→空、相框立→倒），要么接住上一镜（道具接力）。

> **明细取用**：完整 12 维镜头表列头、物品镜 6 规则、镜型组合规律，见案例附录 `references/cases/narration-driven-emotional-microdrama-storyboard.md` 第二节，本文只给决策骨架不复述明细。

## 5. 镜头语言决策树【吸收】

```
这场戏的性质是？
├─ 对白/关系摩擦     → 正反打覆盖剪辑（暖线可长呼吸镜／冷线静止覆盖机位不动）
├─ 改变物体状态/兑现 → FL2VA 首尾帧 + 手部特写 + 摆落点 + 逐动词
├─ 情绪内心/崩点     → 近景/特写，静接静，崩点后留白镜（第 7 章）
├─ 时间跳跃          → 闪回/时间标记镜（换装/光/道具，不打字幕）
└─ 氛围/过场         → 空镜 + soundscape；且「要么承载情绪、要么删」
```

- **覆盖剪辑 vs 一镜到底**：一场戏拆多机位正反打**剪到一起**才连贯；一镜到底=幻灯片（前 3 版不连贯的根因）。
- **但长镜≠慢、短镜≠快**：镜内有无推进才是关键（呼应 [C]）。情绪长呼吸镜只要有微表情推进就不是幻灯片。
- **动接动衔接（motion-match-cut）**：剪辑点两侧运动连续，**前置到首尾帧生成侧**（尾帧运动趋势=下一镜首帧起势），不靠后期硬裁；情绪戏留「静接静」。

> **明细取用**：声音 6 层、转场/衔接 7 个技术开关的可填清单，见案例附录 `references/cases/narration-driven-emotional-microdrama-storyboard.md` 第二节 ③④。

## 6. 节奏诊断：先测再断【吸收】

> [R] 节奏门是**观感卫生层，不凌驾叙事**（[C] 优先）；ASL/中位镜长**只是诊断信号，非硬指标**。

**诊断顺序（关键，避免误判）：** 手册辨析「**感觉丝滑 ≠ 切得少**」，所以「觉得慢」时**不许拍脑袋说切太少/太多**：
1. **先测中位镜长**（中位比平均抗极值），拿到客观数字；
2. **再逐拍看有无停滞窗**（[C]）；
3. **定位哪层病**：中位镜长正常仍慢 → **内容层病**（回第 2 章补事件，不是多切几刀）；确实过长且镜内无推进 → 剪辑层可动，但先确认不是内容层。
4. **规则：拆解节奏前先测中位镜长再下结论。**

> 反例：「小猪」项目 ASL 正常但观感慢，根因在内容层——不测就断必误判。

[R] 门三条款（钩子门/静默门/竖屏门）的具体判定见 SOP §9.1。

## 7. 情绪落到镜头层：崩点留白 · 金句卡 · 道具接力【吸收，注意边界】

> 把情感机制**落到镜头层**，是 `emotional-drama-storycraft`（偏剧作）到分镜的桥。
> **边界**：这些是**情感/剧情片**工具。带货/广告片只借编剧内核，**不套情感专属红线**（缺失只显影、克制=稀缺、结尾不点题、负空间）；广告片以**显性购买理由/转化钩子**为准。

- **崩点留白**：情绪最高点后给一个留白镜（静默/空镜/背影/手停），不用台词解释。成片零字幕；静默 >2s 铺 room tone 过静默门。
- **金句卡**：题眼/金句留一个**干净镜头**顶出来，收音干净、不与其他信息抢（呼应 commercial-dialogue-legibility：一片讲透一个错位，别句句加码）。
- **道具接力**：一件道具跨镜衔接兼情绪载体（相框/杯子/手机），承 §9「前后衔接」字段与 motion-match。例：上镜「放下杯子」尾帧 → 下镜「空桌上的杯子」首帧（缝住两镜，且「空桌」标记「人走了」）。

## 8. 生产层：让分镜可复现、不翻车

> 这是项目相对纯创作手册的**结构性优势**。字段/路由/条款权威在 SOP，本文只把散点串成一条**锚定链**并给决策要点。

**关键帧锚定链**（成功率主因）：
```
人物母板(身份根) →认可→ 各镜 --reference 母板 → 每镜关键帧先行 → §12 图片闸门
  →通过后锁提示词+绑 SHA-256（视频阶段不得改写）→ 视频生成 → 人工逐帧查字幕+效果验收
```

决策要点（细则见 SOP 对应章节）：
- **身份锁**：有人物先出母板，各镜引用，避免换脸。
- **图片闸门（§12）**：首帧证初态、尾帧(仅 FL2VA)证终点、参考图(Ref2VA)只需引用；**未证明不得付费生成**。极近景/手部关键帧首句「面部不入画+填满画面」禁中景。
- **生成模式选择**：改变物体状态/位置 → **FL2VA**；需身份锁 → Ref2VA；不改状态只动 → I2VA；空镜氛围 → T2VA。完整路由与 Seedance 语法见 SOP §5。
- **§10 镜头规格**（9 字段）与 **§13 文字/对白**（成片零字幕、每单元必带音效+对白、落版文字后期图形层）：填法与条款见 SOP，本文不复述。
- 先预演「动作/台词能否在时长内演完」再定生成单元（SD 动作时长验证）。

> **明细与实证取用**：AI 生成专属约束逐条、决策树、逐句填空的空白镜头表，以及 V1/V2 真实数据与 ffmpeg 镜长实测，见案例附录 `references/cases/narration-driven-emotional-microdrama-storyboard.md`。

## 9. 三种分镜各自怎么做

### 9.1 视频镜头分镜（主）——继承链走一遍（示意：餐桌分手）

| 拍 | 本拍新增 | 镜型 | 模式 | 道具接力 |
|---|---|---|---|---|
| B1 | 建立「两人已无话」 | 定场中景 | I2VA | — |
| B2 | 手停在杯上（崩点前） | 手部特写 | FL2VA(手停→收回) | 杯子→ |
| B3 | 说出真相（金句卡） | 正打特写 | Ref2VA | 视线 |
| B4 | 移开视线（兑现不敢对视） | 反打特写 | Ref2VA | 视线反向 |
| B5 | 崩点留白：空桌上的杯 | 空镜(room tone) | I2VA | →承 B2 |

每镜可回溯到它服务的状态变化；同场景换景别、音频连续；B2/B5 用杯子接力，B5 是留白镜。

### 9.2 图片关键帧分镜

**关键帧不是独立作品，是「分镜的可验证证据」**（§12）。为每个视频镜头设计：首帧证初态、FL2VA 尾帧证终点（如 B2 首帧「手握杯」→尾帧「手离、杯留桌」锁住「放下」防漏演）、Ref2VA 引用母板锁身份、母板先行、极近景框死面部不入画、产品落幅/CTA 帧用文生图无参考静物。验收即图片闸门：证不了对应那一拍就重做，别急着付费生成视频。

### 9.3 图文（小红书 5 图）分镜

5 图 = 一条**静态分镜叙事**（视频验收后派生、恰好 5 张、同一视觉系统、文字后期渲染）。SOP §16 只给内容槽，本文把**镜型意识**吸收进来补构图：

| 图 | 内容槽 | 镜型意识 | 构图/景别 |
|---|---|---|---|
| 1 | 封面 Hook | 钩子镜 | 冲突/悬念/金句，中近景，留白放标题 |
| 2 | 场景/痛点 | 场景中景 | 人+环境，真实使用场景 |
| 3 | 核心卖点 | 产品特写/使用手部 | 产品占主体，手演使用姿态 |
| 4 | 细节/证据 | 对比/细节特写 | 前后对比或材质微距 |
| 5 | 总结/CTA | 落版镜 | 干净区放 CTA，后期图形层渲染 |

图文是视频的跨平台延展，不得反过来替代视频。
