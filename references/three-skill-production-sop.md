# 三 Skill 协作生产 SOP

本 SOP 规定 `ad-creative-expert`、`screenwriting-master` 与 `seedance-prompt-zh` 的分工、分流和交接。`ad-creative-expert` 始终是商业总控；只有需要故事化表达时才调用 `screenwriting-master`。

## 1. 路由判断

在创意路线阶段先判断表现形式，不要默认所有广告都故事化：

| 路线 | 判断信号 | 调用链 |
|---|---|---|
| 直接广告 | 痛点→演示→证明→CTA；产品动作本身是看点；无人物关系或情绪转折 | ads → Seedance → ads |
| 创意广告 | 规则、变形、尺度跳跃、媒介模拟、产品奇观；15 秒以内可独立理解 | ads → Seedance → ads |
| 故事广告 | 需要角色目标、阻碍、关系、潜台词、情绪转折或反转才能成立 | ads → screenwriting → ads → Seedance → ads |
| 品牌短片/剧集 | 需要 1 分钟以上、人物弧光、世界观、分集结构 | screenwriting 与 ads 协作；Seedance 只执行选定镜头 |

若直接广告在 15 秒内能够用“一个 Hook + 一个产品动作 + 一个结果 + 一个 CTA”讲清楚，明确跳过编剧 Skill。只有当跳过故事会损失理解、情绪或记忆点时，才进入 `screenwriting-master`。

## 2. 沟通闸门

### 第 1 轮：锁定任务

由 ads Skill 询问或合理假设：产品事实、购买者/使用者/观看者、平台、地域、目标、时长、素材、证据、限制和预算。输出 Brief 诊断，不生成付费素材。

### 第 2 轮：确定表现形式

至少比较三条机制不同的路线，并对每条标注：

- 表现形式：直接 / 创意 / 故事
- 首 1–3 秒 Hook
- 产品事实与动作
- 是否需要人物关系和情绪弧
- 15 秒内是否能闭合
- Seedance 难点、成本和风险

让用户选择路线或混合路线。用户选择后，路线类型即锁定；除非改变路线、超出已披露成本或需要新权限，不再反复确认。

### 第 3 轮：按路由执行

- 直接/创意广告：ads 输出镜头任务单，直接交给 Seedance 写提示词。
- 故事广告：screenwriting 先输出核心动作、人物、冲突、结构和可摄影剧本；ads 再压缩成广告镜头任务单。
- 长内容：screenwriting 完成相应格式的阶段产物，ads 负责商业接口和平台切条。

### 第 4 轮：生成与验收

Seedance 每次只解决一个镜头难题，单段通常 4–15 秒。ads 负责真实商品素材、字幕/CTA 后期、剪辑、声音、视频验收和 5 张小红书图文。

## 3. 交接字段

### ads → screenwriting

```text
产品事实 / 受众 / 平台 / 传播主张 / 必须出现的产品动作 /
必须保留的证据 / 时长 / 禁用表达 / 期望情绪 / CTA
```

### ads → Seedance

```text
镜头编号 / 时长 / 叙事功能 / 首帧 / 尾帧 / 主体 / 场景 /
动作 / 运镜 / 景别 / 声音 / 必须保持 / 禁止出现 / 前后镜头衔接
```

Seedance 提示词必须明确每个 `@图片`、`@视频`、`@音频` 的职责，分时段描述动作，避免指令冲突；品牌、中文、价格、数字和 CTA 默认由后期渲染。

### Seedance → ads

返回最终提示词、素材引用表、生成参数、风险、需要后期修正的内容和是否可进入剪辑。失败只重做最小失败镜头，并记录增量成本。

## 4. 直接/创意广告的 15 秒模板

```text
0–2 秒：异常 Hook 或产品结果先行
2–6 秒：建立一条可看懂的规则
6–11 秒：真实操作触发一次主要变化
11–13.5 秒：结果和产品证据
13.5–15 秒：真实商品图、品牌和 CTA
```

可压缩为 8–12 秒；不得为了套结构增加无关剧情。每段 Seedance 生成只承担一个主要动作，最终商品证明使用原图或实拍。

## 5. 质量门

交给下一个 Skill 前，检查上游交付是否能回答：谁在看、为什么停留、产品做了什么、结果如何证明、下一步是什么。没有答案时退回 ads 创意阶段，不让 Seedance 用漂亮画面掩盖策略缺口。

视频完成后检查：动作因果、人物/商品一致性、文字安全区、真实商品证据、时长、音画和平台规格；通过后才制作恰好 5 张小红书图文。
