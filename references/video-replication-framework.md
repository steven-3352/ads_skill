# 短视频创意机制蒸馏与跨品类复刻框架

本参考文件用于把一组视频样本转换为可迁移的创作系统。它描述的是机制，不是对样本的逐镜头复制。所有“事实”必须来自素材观察；所有“规律”都标记为待验证假设。

下文的认知落差、世界观和规则优先用于样本机制迁移，不是全部广告的通用门槛。路线总评使用 `creative-attention.md` 的统一创意门；人物、证明与感官路线按各自观看承诺判断。分镜展开使用 `script-direction.md`，不能用转场参数代替叙事节拍。

## 0. 创意判断总纲

### 0.1 机关型迁移的“认知落差”

普通商品信息不会自动变成内容。选择机关型迁移时，目标观看体验可以是：

```text
“怎么会想到这样？”
→ “原来这个动作/功能可以这样理解。”
→ “这个商品确实解决了一个问题。”
```

创意的基本公式是：

```text
熟悉符号/世界 A
+ 商品独有的事实、形态或动作 B
+ 一个可重复的视觉规则 C
= 意外但看完合理的观看体验
```

“新鲜”不是堆滤镜、换颜色或加入随机特效；“反差”也不是把两个无关物件硬放在一起。A 和 B 必须有可解释的连接，C 必须能在画面中被看见，最后必须回到商品真实价值。

### 0.2 复制机制，不复制资产

|低价值表面复制|可迁移的机制蒸馏|
|---|---|
|照搬人物、服装、台词、音乐、IP 道具|提取观众奖励、叙事规则和动作机关|
|照搬同一转场|提取“什么动作触发什么变化”|
|把商品放进漂亮背景|让商品真实功能成为剧情发生的原因|
|追求每帧相似|保留观看节奏、认知落差和结果证明|

### 0.3 五步模块是镜头，而不是硬性清单

“形态联想 + 功能转译 + 场景置换 + 动作戏剧化 + 结果回扣”是一条优先顺序，不代表每个商品都要机械地走五遍。先判断商品最强的创意入口：

- **形态强**：外观、材质、结构、灯光或声音有鲜明识别度，从形态联想开始。
- **行为强**：开合、旋钮、喷洒、倒出、扫描、折叠等动作有戏，从功能转译和动作戏剧化开始。
- **情绪强**：商品解决的是安心、放松、效率、陪伴或身份表达，从状态叙事和场景置换开始。
- **文化强**：商品天然连接某个年代、职业、仪式或流行符号，从文化混搭开始。

选择 2-4 个最有证据的模块即可。若某一步没有商品事实支撑，就跳过或换入口，不要为了完整而补一个空洞的“飞机/机甲皮肤”。

### 0.4 创意核心五问

在写脚本前先回答：

1. 这个商品最独特、最容易被看见或听见的事实是什么？
2. 它可以和哪个相距较远、但观众能立即认出的世界发生关系？
3. 这个世界只需要遵守哪一条简单规则？
4. 哪一个真实操作会触发最有冲击力的变化？
5. 奇观结束后，观众凭什么相信商品真的有用？

如果第 1、4、5 问答不出来，创意通常只是视觉包装；如果第 2、3 问答不出来，内容通常会回到普通介绍。

## 1. 样本事实档案

对每条视频建立一行记录，至少包含：

|字段|记录内容|
|---|---|
|身份|文件名、标题、话题、时长、画幅、帧率|
|首屏|0-1 秒出现的主体、动作、文字、声音|
|结构|按时间段标出 Hook、铺垫、变化、结果、CTA|
|镜头|景别、机位、镜头运动、主体位置、背景和道具|
|动作|触发转场的动作、遮挡物、方向、速度、连续性|
|服化道|服装层级、颜色、发型、妆容、道具和品牌露出|
|后期|剪切、速度、叠化、遮罩、抠像、跟踪、字幕、滤镜|
|声音|音乐来源/类型、BPM 感受、节拍点、拟音、环境声、对白|
|结果|观众最终看见的身份变化、产品证据或情绪落点|

技术元数据只描述可验证事实，不把文件名中的标签当作内容效果证据。

## 2. 从样本蒸馏机制

用“输入 → 操作 → 输出 → 观众奖励”描述每个创意：

```text
可识别的日常/文化符号
→ 一个简单且可重复的动作规则
→ 画面或身份的突然变化
→ 好奇、爽感、收藏价值或购买想象
```

常见机制库：

1. **结果先行 + 教程证明**：先给夸张结果，再用编号步骤、手机录屏或错误示范解释如何实现。适合工具、软件、家居和美妆。
2. **固定机位连续换装**：机位、人物站位和背景锁定，只改变服装/道具；用遮挡、跳切或动作匹配制造“瞬变”。适合服装、配饰、家具改造。
3. **遮挡物匹配转场**：让手、衣物、球、门、镜面或道具完整遮挡画面，再在同一运动方向切入下一状态。关键是遮挡边界、运动方向和曝光一致。
4. **角色规则化变装**：把红绿灯、监狱、地鼠、沙漏、苹果等符号变成角色/场景规则，服装变化成为剧情结果，而非孤立展示。
5. **选择器/抽签/游戏化穿搭**：用老虎机、截图、进度条或手势让观众“参与选择”，降低硬广感并提高重复观看。
6. **三视图/资料卡展示**：正面、侧面、背面或尺码图按清晰顺序呈现，解决“上身效果看不全”的疑虑；适合服装、箱包、家具。
7. **状态叙事**：以低能量、晚安、出门、赴会等可识别状态开场，用环境、色温和节奏变化把产品功能/穿着体验转成情绪结果。
8. **实拍与合成世界拼接**：真人动作保持连续，背景切换到插画、AI 场景或节目界面；必须保留主体轮廓、光向和阴影的连续证据。
9. **形态语义转译**：把产品外形、控制件、灯光、材质或机械声联想到驾驶舱、机甲、实验室、乐器、建筑等系统；让真实操作成为“启动、校准、锁定、变形、发射”等戏剧动作。
10. **类型混搭/时代错置**：把商品放入两个原本不在一起的类型，如老电视购物 × 科幻控制台、便利店 × 童话、办公室 × 竞技游戏；用类型规则制造反差，同时保留商品证据。
11. **尺度反转**：把小物拍成巨型设施，把大物压缩成口袋工具，或让镜头进入商品内部；尺度变化必须服务于容量、覆盖、便携或精密等真实卖点。
12. **物品拟人/角色分工**：给商品一个明确职责（导航员、守门人、维修师、助理），让它推动事件而不是只被展示；拟人化不等于虚构功效。
13. **规则/限制变游戏**：把电量、时间、容量、步骤、颜色或模式变成倒计时、闯关、抽签、交通信号等可重复规则，促使观众等待下一次变化。
14. **揭示与回环**：先让观众误以为看的是某种世界或事件，结尾用真实商品特写重新解释开头；结尾可与首帧呼应，增加重播价值。
15. **声音先行**：先用启动声、机械咔嗒、拉链、蒸汽、倒入或提示音建立世界，再让画面追上声音；适合画面简单但操作反馈明确的商品。
16. **语义接力/逐层入境**：相邻镜头共享一个动作、形状、材质、尺度或含义，让观众从现实逐层进入产品内部世界；每次转场都要能指出上一镜留下的视觉线索。
17. **后台夜班/时间代理**：把夜间、自动、静置、循环或缓慢形成的不可见过程，改写成用户离场后仍在运行的后台系统；适合扫地、充电、清洗、发酵和夜间护理，但幻想不能替代结果证明。

## 3. 五步创意模块

五个模块共同构成一条“从商品事实到观看奇观，再回到购买理由”的创意链。每一步都要写出可检查的中间产物。

### 3.1 形态联想：从商品的可见线索找到远方世界

不要只看“像不像某个东西”，要做一次产品语义盘点：

|观察层|要问的问题|可能的联想入口|
|---|---|---|
|轮廓/几何|第一眼像什么结构？圆、舱、塔、胶囊、砖、镜面？|驾驶舱、建筑、棋盘、太空舱|
|材质/触感|金属、玻璃、软胶、织物、磨砂会让人想到什么？|仪器、珠宝、医疗、玩具、唱片|
|控制件|旋钮、按键、滑轨、接口、屏幕如何运动？|仪表盘、游戏手柄、档案柜、乐器|
|光/色|指示灯、反光、渐变、颜色组合有什么语义？|警报、能量核心、舞台、交通信号|
|声音/反馈|按下、旋转、合上、插入时有什么真实声音？|发射、换挡、装填、扫描、开锁|
|尺度/重量|拿在手里、放在桌上或进入空间的比例如何？|微型城市、重型机械、便携装备|
|使用姿势|用户是握、戴、推、拉、贴、倾倒还是等待？|驾驶、维修、施法、调音、实验|
|文化/年代|包装、字体、颜色或使用仪式让人联想到哪个年代/社群？|90 年代电视、街机、邮局、校园|

从至少 3 个不同类别生成候选联想，并写成一句话：

```text
商品的【具体线索】像【远方世界的具体部件】，因为【可解释的相似性】。
```

例如机械外形电子产品不要只写“未来科技感”，而写：

```text
侧面的散热栅格和旋钮像飞行器的仪表舱，因为用户需要旋转、调节并观察指示灯。
```

**产出物**：3-7 个联想句、每个联想对应的视觉部件、真实商品线索和潜在观众奖励。

### 3.2 功能转译：把真实操作改写成世界里的动作

先列真实功能，再建立一对一的“动作翻译表”；不要先写科幻剧情再强行补功能。

|真实商品动作/价值|世界观里的动作|画面证据|不可虚构的边界|
|---|---|---|---|
|按键启动|系统通电/引擎点火|按键特写、灯光依次亮起|不能暗示增加不存在的动力|
|旋钮调节|校准航向/锁定频段|手指旋转、数值或指示灯变化|数值必须来自真实可验证范围|
|折叠/展开|机甲展开/基地部署|结构前后对照|不能增加不存在的关节或部件|
|快速加热/制冷|能源充能/温度舱切换|时间、温度或结果特写|功效、速度需有证据|
|分类/收纳|装填弹药/整理装备|物品进入对应位置|容量和尺寸按实物呈现|

每个戏剧动作都要能回答：“如果拿掉商品，观众还能相信这件事由谁完成吗？”如果答案是“任何魔法都可以”，说明商品没有成为因果核心。

**产出物**：功能-隐喻映射表、一个主动作、一个辅助动作、每个动作的产品证据镜头。

### 3.3 场景置换：把商品送进一个有规则的世界

场景不是背景图，而是会改变观众理解商品的“解释系统”。确定以下 6 件事：

1. **世界类型**：驾驶舱、维修站、竞技场、老电视、童话、实验室、便利店、太空站等。
2. **角色关系**：谁在操作，商品扮演什么职责，观众站在哪个视角。
3. **单一规则**：每按一次、每转一格、每响一声或每完成一步，世界发生什么变化。
4. **冲突/任务**：需要启动、拯救、赶上、修复、选择、穿越还是完成倒计时。
5. **进入与退出**：从真实生活进入幻想，或先幻想后揭示真实；结尾必须回到商品。
6. **混搭来源**：最多组合 2-3 个强符号，避免世界观变成无关元素堆积。

场景置换的三种强度：

- **叠加**：真实环境不变，只加界面、灯光、字幕和声音；成本低、商品最稳。
- **穿越**：一个遮挡、开门、屏幕或镜面把现实切入另一世界；记忆点强，需连续动作。
- **完全置换**：整段进入新世界；视觉冲击大，但必须在结尾用实物和功能证据收回语义。

**产出物**：一句世界观设定、一个世界规则、一个任务、进入/退出镜头和视觉约束。

### 3.4 动作戏剧化：让操作成为剧情的开关

每条片子只设置一个主动作机关，其他动作服务于它。将主动作拆成：

```text
准备（观众看懂目标）
→ 蓄力/犹豫（制造期待）
→ 触发（按、转、抬、遮、敲、拉）
→ 变化（世界/状态/尺度改变）
→ 结果（产品完成任务）
```

动作设计要同时写出四个层面：

- **身体动作**：手势、姿态、方向、速度和起止位置。
- **镜头动作**：固定、推近、环绕、俯拍或主观视角；不要在一个短片里堆过多运镜。
- **剪辑动作**：硬切、遮挡切、形状匹配、速度变化或画中画；标出具体切点。
- **声音动作**：动作前的留白、触发拟音、变化瞬间的冲击和结果后的空间声。

优先选择 AI 容易完成的动作：单物体移动、短距离推拉、遮挡、灯光变化、背景变换、简单旋转。把多手指精细操作、复杂多人交互和长时间连续变形拆成多个 4-6 秒片段，或用实拍覆盖。

**产出物**：主动作分解表、动作起止帧、转场方式、AI/实拍标记和失败备用动作。

### 3.5 结果回扣：奇观之后必须留下购买理由

结果回扣不是“最后放一张商品图”，而是完成因果闭环：

```text
奇观发生
→ 观众理解奇观对应哪个真实动作
→ 看到产品如何带来真实结果
→ 得到一个明确下一步
```

至少保留以下镜头中的两个：

- 商品整体与真实尺寸/比例
- 关键结构或材质特写
- 实际操作前后对比
- 可验证的参数、步骤、容量或使用限制
- 真实用户场景中的结果

创意片的 CTA 也要与世界观相呼应，但不能遮掉事实，例如“进入详情舱”之后仍要能点击商品页，而不是只留下抽象口号。

**产出物**：事实证明镜头、合规文案、商品定格、CTA 和“如果去掉奇观仍成立”的版本。

### 3.6 不适合五步全开的商品怎么办

用下列入口选择树：

```text
有鲜明外形/材质/声响？
├─ 是 → 形态联想 → 功能转译
└─ 否
   有强操作或可视化结果？
   ├─ 是 → 功能转译 → 动作戏剧化
   └─ 否
      有强情绪/生活状态？
      ├─ 是 → 场景置换 → 结果回扣
      └─ 否 → 文化符号/规则游戏 → 先创造可见冲突，再回扣商品事实
```

不要为了“像样本”而给普通商品强行安上机甲、宇宙或复古皮肤。好的联想必须提升商品原本就有的意义；如果换成另一个商品后片子几乎不变，应退回产品拆解。

### 3.7 机械感电子产品的完整示例

假设商品是一款有旋钮、指示灯、散热栅格和实体按键的桌面电子设备，真实卖点是模式切换、可调节和桌面使用。

|模块|拆解结果|
|---|---|
|形态联想|旋钮+指示灯+栅格 → 飞行器仪表舱/机甲能源核心；相似点是“控制、反馈、机械结构”|
|功能转译|按键=通电；旋钮=校准模式；指示灯=系统状态；模式切换=任务切换|
|场景置换|桌面变成小型控制台；操作者执行“启动并锁定目标”的任务；只用一条规则：每次确认后仪表盘进入下一状态|
|动作戏剧化|手按下→灯光逐层亮；旋钮转动→镜头推近；确认键→短暂遮挡/闪白；设备进入真实工作状态|
|结果回扣|幻想界面退去，回到真实桌面，拍设备正在运行，并展示旋钮、灯光和模式切换；字幕只写经证实的功能|

建议成片结构：0-2 秒先亮出“未启动的控制台”冲突；2-7 秒完成两次真实操作与 AI 视觉增强；7-10 秒完成一次强变化；10-15 秒回到实物、功能证据和 CTA。AI 生成控制台、灯光和背景；商品正面、按钮操作和最终运行状态用商品图/实拍锁定。

## 4. 新商品拆解与方案生成

拿到一个新商品时，先做“商品拆解”，再做“创意发散”。不要从“我想模仿哪条样本”开始；先判断商品有什么独特事实，哪些事实值得被放大。

### 4.1 建立商品真值卡

只记录能从商品、说明书、实拍或品牌资料确认的内容：

```text
品类/型号：
核心用户与购买场景：
用户正在做什么、卡在哪里：
真实功能（最多 3 个）：
可见结构/材质/颜色/灯光/声音：
真实操作动作（按、转、拉、折、倒、贴、穿、等待）：
可证明结果（前后、步骤、容量、速度、尺寸、触感）：
不能说的功效/限制/安全边界：
可用资产（商品图、实拍、包装、品牌字体、音频）：
平台、时长、预算和制作能力：
```

把功能控制在 1 个主张、最多 2 个辅助证明；卖点越多，越难形成单一的创意规则。

### 4.2 做“产品语义扫描”

针对真值卡逐项提取：

|扫描项|写法示例|
|---|---|
|一个第一眼形状|“像一个小型舱体/薄片/圆盘”|
|一个可重复动作|“旋钮每转一格，指示灯改变”|
|一个触觉或声音反馈|“合上时有明确咔嗒声”|
|一个用户姿态|“需要双手展开/单手携带/贴近使用”|
|一个状态变化|“凌乱→分类、冷→热、暗→亮、离线→连接”|
|一个情绪/身份|“准备出发、恢复秩序、获得掌控感、放松”|
|一个文化编码|“老式仪表、街机、实验室、邮局、校园”|
|一个可视化限制|“只有 3 档、只能放下特定尺寸、需要等待 10 分钟”|

其中至少 2 项要成为片子的创意锚点。没有锚点时，先补拍产品动作或寻找真实使用场景，不要用泛化的“高级、未来、治愈”填空。

### 4.3 找“意外邻居”，不要找万能世界

从产品锚点出发，先生成 5-10 个跨领域邻居，至少覆盖三类；如果已经找到 3-5 个同时有商品证据、可视规则和制作路径的候选，就停止发散，不为满足数量继续硬找：

- **职业/系统**：驾驶舱、手术室、控制塔、维修站、厨房后场、档案室。
- **文化/年代**：老电视、街机、校园广播、邮局、录像厅、赛博杂志。
- **自然/尺度**：气象站、火山、潮汐、微缩城市、巨型设施、显微世界。
- **叙事/游戏**：闯关、抽签、倒计时、任务简报、解谜、守门。
- **角色/关系**：导航员、守夜人、裁判、维修师、调音师、训练员。

每个候选必须写成：

```text
商品锚点 + 意外邻居 + 一条世界规则 + 观众奖励
```

例如：

```text
旋钮/指示灯
+ 飞行器仪表舱
+ 每确认一次，仪表进入下一航段
+ 观众等待“起飞”并理解模式切换
```

不要一开始就选“科幻”或“机甲”这种大词；先找具体部件、具体动作和具体任务。距离越远越有新鲜感，但至少要保留一个可立即理解的相似点。

对于“等待期间发生作用”的商品，再补问一次：**用户停止主动操作后，什么真实过程仍在继续？** 可以把它转译成夜班、值守、检修、发酵日程或自动调度；如果现实中没有持续过程，不得为了故事虚构一个后台系统。

### 4.4 评估候选创意

用 1-5 分给每个候选打分，记录理由：

|维度|权重|判断标准|
|---|---:|---|
|意外度|25%|不是常见品类广告联想，能产生“没想到”|
|一秒可懂|20%|首帧/首个动作能看出规则，不靠长旁白|
|商品相关性|20%|联想来自商品真实形态、动作、结果或场景|
|视觉与声音潜力|15%|有可拍的形状、运动、光、节拍或拟音|
|AI/制作可行性|10%|能拆成短片段，商品可被稳定锁定|
|证明与品牌适配|10%|结尾能自然回到事实与购买路径|

保留总分最高的 3 个方向，但要求“商品相关性、一秒可懂、证明与品牌适配”均不低于 3 分。意外度高但相关性低的方向，通常是炫技；相关性高但意外度低的方向，通常是普通介绍。

### 4.5 选创意入口和模块组合

从最高分方向中选一条创意主线，不要把所有机制拼成素材大杂烩：

```text
产品形态是记忆点？
→ 形态联想 + 场景置换 + 结果回扣

产品操作是记忆点？
→ 功能转译 + 动作戏剧化 + 声音先行

用户状态是记忆点？
→ 场景置换 + 规则/倒计时 + 结果回扣

商品有多种模式/颜色/组合？
→ 选择器/游戏化 + 规则变化 + 资料卡证明

商品需要强信任证明？
→ 结果先行 + 教程/演示 + 三视图/参数回扣
```

每条片只设一个“主创意句”和一个“主动作机关”：

```text
主创意句：把【商品真实特征】看成【具体世界/角色】，每次【真实操作】就会【可见变化】，最后证明【真实结果】。
主动作机关：一个动作，触发一次最重要的变化。
```

### 4.6 先写“创意骨架”，再写文案

用 6 个节点排成 9-20 秒的骨架：

1. **钩子**：结果、冲突、异常世界或不可逆动作在 0-2 秒出现。
2. **识别**：让观众看出商品和世界规则，不要超过 2 秒解释。
3. **准备**：展示目标、操作前状态或任务简报。
4. **触发**：真实商品动作与拟音同步。
5. **奇观/变化**：AI 背景、尺度、角色、颜色或世界发生一次强变化。
6. **回扣**：退回真实商品，展示至少两个事实证据，给 CTA。

如果片子没有第 4 步，商品很可能只是道具；如果没有第 6 步，观众可能记住的是特效而不是商品；如果第 1 步无法独立成立，先换 Hook，不要靠后半段补救。

### 4.7 做“反硬套”检查

交付前逐项回答：

- **换品测试**：把商品换成同类竞品，创意是否完全不变？若是，缺少商品锚点。
- **去奇观测试**：去掉 AI 背景，真实操作和结果是否仍然有意义？若否，缺少产品证明。
- **一句规则测试**：能否用一句话说明每次动作会带来什么变化？若否，规则太复杂。
- **首秒测试**：静音看首 1 秒，能否看懂冲突/结果/动作？若否，重新设计首帧。
- **因果测试**：奇观是否由真实操作触发，而不是任意闪光或随机变形？若否，重写动作。
- **可行性测试**：是否包含 AI 不稳定的细小文字、多手指、多人连续互动、长镜头精密变形？若是，拆段或改为实拍。
- **合规测试**：所有功效、参数、对比和安全暗示是否有证据？没有就改为可验证的体验描述。

### 4.8 处理商品证据和未知字段

把信息分为“已确认、可由画面观察、未知”三类。未知信息不能通过 AI 想象补齐；可以继续做氛围创意，但必须把主张降级为中性描述。

|容易出错的证据|可靠做法|禁止做法|
|---|---|---|
|屏幕数字、单位、Logo、按钮标签|从原图裁切保留，或用后期叠加已确认文本|让视频模型重绘精确数字/中文/Logo|
|透明、反光、液体可见度|用商品抠图、遮罩和真实内容层合成；先确认画面确实看得见|凭 AI 生成的折射暗示容量、材质或内容可见|
|翻盖、折叠、旋钮等可动部件|补拍一段固定机位操作，或提供开合前后参考图|用一张闭合商品图声称动态结构或单手便利|
|尺寸、重量、容量和手持比例|加入真实手持、桌面比例或测量图|只靠 AI 人物手臂推断大小|
|速度、温度、功效、耐用性|使用说明书、检测报告或真实演示作为来源|把视觉变化当成性能证明|

交付时给每个关键主张附“证据来源”和“是否需要补拍”。如果证据不足，改写为“展示温度显示”“看见内容物”“打开后进入使用状态”等描述，不写精确数值或效果承诺。

## 5. AI 与实拍的分工

### 5.1 让 AI 做“想象”和“组织”

AI 适合：

- 生成跨领域联想、世界观和多套 Hook
- 把普通房间变成驾驶舱、实验室、老电视、游戏界面或微缩世界
- 生成背景、灯光、粒子、风格混搭和短时转场
- 根据商品图生成 4-6 秒的单动作产品片段
- 生成临时音乐、拟音、环境声和节拍版本
- 自动粗剪、卡点、字幕草稿和平台尺寸版本

### 5.2 把真实性留给商品图、实拍和后期

不要完全交给 AI：

- 商品的 Logo、中文文字、按钮标签、接口数量和精确几何
- 手指精细操作、多人接力、长时间连续变形
- 尺寸、容量、速度、温度、功效和安全证明
- 最终品牌片尾、价格和购买路径

推荐“混合模式”：AI 生成世界和变化，商品图/实拍锁定商品和关键操作，剪映或其他编辑器完成字幕、Logo、参数和最终拼接。

### 5.3 只给商品图时的生成顺序

1. 用商品图生成 3-5 张概念静帧，先确定联想世界和构图，不急着生成视频。
2. 盘点资产：闭合/正面图、可动部件图或操作实拍、屏幕/Logo 特写、手持/尺寸参照。缺哪一项，就在脚本中降低对应主张等级。
3. 选择一个世界和一个主动作，把片子拆成 2-6 秒片段；每段只完成一个动作。透明材质、精确数字和复杂运动默认使用 1.5-3 秒背景动画 + 静态商品层。
4. 每段都明确写 `@商品图` 的用途：外观参考、首帧、产品特写或尾帧；可动部件没有第二张图/实拍时，不把图生视频结果当功能证明。
5. 要求固定机位、稳定比例、不要新增部件、不要生成文字；把字幕、Logo、价格、数字和参数后置，用原图裁切或人工叠加。
6. 失败时优先改成静止产品 + AI 背景/光效、2.5D 推近或遮罩转场，不要反复要求模型完成复杂连续动作。
7. 用 AI 粗剪后逐帧检查商品轮廓、透明/反光、数字、动作因果和最终结果；不合格片段单独重生或改为实拍。

### 5.4 通用 AI 提示词骨架

```text
@商品图作为商品外观和比例参考，保持颜色、结构、Logo 区域和关键细节不变。
如果商品有可动部件，优先让商品保持静止、只生成背景/灯光/界面；只有提供开合前后参考或实拍时，才生成一次短动作。
生成 9:16、2-6 秒短片段，只完成一个真实操作或一个背景变化：【动作】。
场景置于【具体世界】，世界规则是【一条规则】。
0-1 秒出现【Hook/冲突】；中段完成【操作→变化】；最后 0.8-1 秒展示【真实结果/商品特写】。
镜头使用【固定/推近/俯拍】；在【遮挡/触发动作】处完成转场。
音乐为【节奏/情绪】，加入【拟音】并与动作同步。
不要改变商品结构，不要新增功能，不要重绘屏幕数字、中文文字、Logo、价格或参数，不要复杂多人动作。
```

### 5.5 三档制作策略

|档位|AI 负责|实拍/后期负责|适用情况|
|---|---|---|---|
|低成本|背景、灯光、单个转场、音乐|商品静物、手部操作、字幕|商品结构复杂或预算低|
|标准|世界观、多个短片段、声音和粗剪|关键操作、产品细节、品牌片尾|大多数电商/内容广告|
|高完成度|概念预演、合成世界、角色和镜头变化|商品实拍、演员、精确跟踪、最终调色混音|品牌片或重点投放|

### 5.6 最低资产门槛与降级路径

只有一张白底商品图时，允许做“概念广告”，但把真实演示的等级降为“视觉示意”。至少缺失以下任一资产时，不要把 AI 画面当作证据：

- **可动部件资产**：没有开合/旋转/折叠前后图或短实拍，就只做静态商品层、背景变化或图形揭示。
- **细节资产**：没有屏幕/Logo/接口特写，就不展示精确数字、文字或数量；使用“显示区域”“接口设计”等中性标注。
- **比例资产**：没有手持或环境参照，就不宣称便携、容量或尺寸；只做产品定格。

最稳的最低补拍是：固定机位 3 秒，记录一次真实操作（开始姿态→动作→停住→恢复），锁曝光和白平衡。无法补拍时，采用“AI 背景 1.5-3 秒 + 原图抠图 + 后期字幕”的降级方案，创意规则不变但证明强度降低。

### 5.7 用成功视频状态派生后续素材

当一条生成视频已经获得稳定的人物、商品/服装和场景状态时，优先从视频截取清晰稳定帧，作为后续照片、特写或新场景的唯一真值参考。不要继续混用更早的概念图和文字描述重建同一状态。

```text
稳定视频状态
→ 截取人物/商品清楚的状态帧
→ 只改变背景、景别或单一姿势
→ 派生照片/插入镜头
→ 回到剪辑增加信息密度
```

提示词必须声明哪些内容允许改变、哪些内容必须逐项保留。若参考帧同时包含人物与商品/服装，优先只用该帧，避免多个参考中的身份、比例和细节相互冲突。

## 6. 可执行的转场规格

每个转场必须写成制作参数，而不是“做一个酷炫转场”：

- **触发动作**：挥手、抬物、转身、跳起、推镜、关门等；标明开始/结束姿态。
- **遮挡与切点**：遮挡覆盖画面的比例；在运动模糊最强或完全遮挡的帧切换。
- **连续性**：相机高度、焦段、人物脚位、光向、背景线、道具位置保持一致。
- **拍摄方法**：固定机位/三脚架、标记站位、锁曝光白平衡、拍干净板、至少 3 次成功动作。
- **后期方法**：跳切、遮罩、抠像、跟踪、速度曲线、叠化或画中画；注明软件和素材需求。
- **失败保护**：动作不齐时使用遮罩补帧、音效掩盖切点，或改为更稳的硬切。

## 7. 剪辑与声音规则

- 先按动作和节拍标记素材，再决定音乐；不要让音乐替代结构。
- 首 1-3 秒必须出现结果、冲突、不可逆动作或明确问题。
- 变化段用短镜头和强切点；信息/教程段允许更长镜头并加编号字幕；结果段留出至少 0.8 秒让观众看清产品。
- 音乐承担情绪和节拍，拟音承担动作的观看反馈（啪、刷、咔、呼、叮），环境声承担空间真实感；三者不要全部拉满。
- 标明每个声音是“商品实录声”还是“设计拟音”。未录到的声音只能当设计拟音，不得用来证明防漏、材质、耐用或结构品质。
- 关键动作前可留 2-4 帧静音或降噪，动作瞬间加入拟音，再回到音乐，形成听觉“卡点”。
- 字幕遵循静音可懂、每屏一个信息、避免遮挡服装细节；教程类用编号和箭头，氛围类用少量短句。
- 按“新信息出现频率”判断节奏，不按成片总时长或素材长度判断。选择器、状态变化和结果展示类短视频，通常让手机/操作、变化结果、场景证明在约 0.3-1.6 秒内交替出现；具体区间仍需按动作可读性调整。
- AI 生成时长只是素材容量，不是剪辑义务。删除起势前等待、动作完成后停顿和重复站立帧；每个状态只保留一个最清楚的动作。
- 当视频动作不足但状态稳定时，用同状态的全身照片和细节照片补充信息，而不是要求视频模型生成更多连续复杂动作。单张照片可用 0.3-0.8 秒轻推/轻拉，并在音乐重拍硬切。
- 触发镜头与结果镜头交替排列：`操作/选择 → 2-4 帧闪白或硬切 → 结果动作 → 结果照片 → 下一次操作`。白闪只遮切点，不承担长转场。

音乐和复古/节目化声音要确认可商用授权；不得直接使用受保护的节目片段、台标、角色音色或品牌识别音。平台要求时，在交付中标注 AI 生成或合成内容。

## 8. 跨品类改写算法

迁移时保留“观看机制”，而不是替换名词。按以下顺序执行：

1. **提取奖励**：样本让观众获得的是惊讶、爽感、参与、证明、情绪安慰、身份想象还是重播线索？只选 1-2 个主奖励。
2. **提取规则**：把样本压缩成一句“当【动作/条件】发生，画面就【变化】”的规则，去掉服装、人物、颜色和音乐。
3. **寻找商品锚点**：从新商品真值卡中选一个形态、动作、状态、限制或结果，让它自然承担这条规则。
4. **重建世界**：选择与商品锚点有相似语义、但和品类有距离的世界；定义角色、任务、单一规则和进入/退出方式。
5. **换成产品证明**：用尺寸/容量、材质触感、步骤数、速度、模式、使用前后或真实限制替换样本中的造型展示。
6. **按 AI 能力重排**：把世界、背景、灯光、合成和声音交给 AI；把商品精确外观、关键操作、文字和参数交给商品图/实拍/后期。
7. **平台化重写**：为抖音/TikTok 前置动作，为小红书增加可保存的细节，为 Meta 设计静音可懂第一帧，为电商更早呈现商品和购买动作。

### 8.1 迁移是否成功

同时通过以下测试才算真正蒸馏：

- **机制测试**：去掉样本资产后，一句话仍能描述动作规则。
- **商品测试**：换成同类竞品后，至少有一个关键镜头、动作或结果必须改变。
- **因果测试**：奇观由商品真实动作触发，而不是靠随机特效。
- **理解测试**：静音观看前 2 秒，能看出冲突、规则或结果。
- **证明测试**：结尾至少有两个可验证商品事实。
- **可生成测试**：AI 生成失败时，可退化为静止商品、背景合成或实拍操作，创意仍成立。

若只通过机制测试而没有商品测试，是泛创意；只通过商品测试而没有机制测试，是普通产品演示；两者都通过，才是“意外连接但看完合理”。

## 9. 样本集的初步观察（事实与假设分开）

**观察到的事实**：基础目录内 11 条素材均为移动端竖屏，其中 10 条带标题、1 条为无标题文件名；另有 1 条用户单独提供的卡诗晚安蜜样本，当前合计分析 12 条。时长约 9-50 秒；多使用固定或低运动机位；服装/道具变化占据主要叙事；部分视频使用白底资料卡、手机界面、节目界面或合成背景；标题普遍使用口语化情境和话题标签。逐条创意语法、观众角色和跨品类结论见 `references/sample-set-creative-distillation.md`。

**可迁移假设（需投放验证）**：结果先行、动作卡点和可参与选择可能提升停留/重播；固定机位降低拍摄复杂度并提高换装连续性；“情绪状态 + 穿搭结果”比单纯罗列款式更容易形成记忆；教程/三视图能降低观众对“只是滤镜”的怀疑。
