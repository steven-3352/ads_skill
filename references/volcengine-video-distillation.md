# Volcengine 视频样本蒸馏报告
样本目录：/home/ubuntu/mvstudio-workspace/volcengine-doc/，共 11 条竖屏 MP4。10 条 1080x1920、1 条 720x1280；均 25fps，时长约 11.73-17.40 秒，含 H.264/AAC。随机文件名不能当主题证据；OCR 仅读到少量词，因此区分事实、推断和机制。
## 一、逐条事实卡
每条记录：内容、结构时间点、Hook、镜头、剪辑、声音、购买理由、证据等级。内容使用：初始状态 -> 触发事件 -> 产品介入 -> 可见变化 -> 结果/选择 -> 行动。删旁白仍应看懂；删产品后事件不应仍成立。
## 二、深度蒸馏维度
内容：真实阻力、触发、产品因果、结果。拍摄：运动是否服务信息，光向/主体/比例/遮挡是否连续，产品特写是否给材质结构或前后对照。Hook：异常结果、未完成动作、反常尺度、系统改写、极近细节或声音先到，并写明何时兑现。购买：至少一种可验证证据 + 一种情绪/身份奖励。声音：触发音、材质音、结果声让观众听懂动作。
## 三、不要复制模板，蒸馏机制
删除品牌、人物、服装、场景、音乐、颜色、台词和转场名称，只保留：真实阻力/欲望 -> 熟悉系统或物理规则 -> 产品动作触发 -> 可见状态变化/爽点 -> 真实证据回扣。机制包括结果先行后揭密、一动作一变化、熟悉系统借壳、选择外化、重复升级、尺度转译、声音先行、后台过程可视化、语义接力。
## 四、同品质制作 SOP
1. 写商品真值卡。 2. 选一个与商品共享真实动作/状态/心理的创意语法。 3. 定义首秒观看问题和第几秒的产品答案，明确爽点。 4. 从 15 秒微故事时间线起步：0-2s Hook；2-5s 关系/阻力；5-10s 产品动作；10-13s 结果证据；13-15s 故事回扣、商品与自然 CTA；需要更完整内容时可扩展，但单条不得超过 120 秒。 5. 逐镜写首帧、动作、尾帧、运镜、声音、素材职责和后期边界；每段只解决一个动作难题。 6. 奇观后给两种真实证据和具体 CTA。
## 五、三道质量门
创意门：不看画面仍能说清阻力、规则、产品因果和奖励。观看门：首3秒有问题，每2-3秒有信息/状态变化，声音增强动作。信任门：外观、功能、文字、参数、结果有真实证据，AI奇观不冒充事实。
## 六、三 Skill 落地
ads_skill：用事实卡、Hook、购买理由和质量门做主题/路线/平台/成本/验收。screenwriting-master：所有视频必经，既负责人物故事，也负责趣味、视觉、幽默和感官内容的概念、推进与兑现；15 秒缩小内容规模，更长成片再增加节拍和复杂度。模型提示词 Skill：把已确认镜头任务转为对应模型格式；文字、品牌、价格和精确结构交给后期/真实素材。
## 七、边界
当前目录没有标题、脚本、投放数据和可靠音频转写，不能断言具体片子的转化率或功效。本文件沉淀的是分析优秀广告并做出同等品质的判断与生产方法，不是复刻模板。
