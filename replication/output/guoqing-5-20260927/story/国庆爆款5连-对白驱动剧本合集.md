# P1｜《你说你要冷静，可你冷的是我》（冷暴力）

**片名候选**：《你每冷我一秒，我心里就凉一分》/《你说你要冷静，可你冷的是我》/《我一个人唱独角戏》
**场景**：普通居家夜晚，客厅到沙发，因小事（他又晚归/忘事）起争执。**道具**：耳机、手机、沙发。
**人物**：A 她（焦虑型，要当场说开）；B 他（回避型，主张冷静）。

**两派与定位**
- 她派：你一沉默就把我丢在情绪里，冷处理=冷暴力，比吵架疼一百倍。
- 他派：气头上说狠话更伤人，冷静是成熟、是让着你。
- 爆款逻辑：回避型 vs 焦虑型是全网最经典人格对撞，两派都极度理直气壮，评论区自动分两派互辩。

### 节拍表

| 段 | 时间 | 功能 |
|---|---|---|
| U0 | 0–2.5 | cold open：金句定性冷暴力 |
| U1 | 2.5–8.5 | 她要说法，他起身要冷静 |
| U2 | 8.5–15.5 | 她追拦，他戴耳机回避 |
| U3 | 15.5–22.5 | 她追问"不说话什么意思" |
| U4 | 22.5–30.5 | 两套逻辑正面撞 |
| U5 | 30.5–37.5 | 组合拳：我要的是"我在" |
| U6 | 37.5–43.5 | 他辩解，她钉死"比骂我疼" |
| U7 | 43.5–50.5 | 收口：一个人唱独角戏 |

### 完整台词（零旁白）

**【U0 0–2.5s · cold open】**（A 眼红近景，背景略虚，直视、轻声却狠）
A：你以为你不说话，是让着我？你每冷我一秒，我心里就凉一分。
（0.3s 停顿，确定性转场字幕"10 秒前"，暗转进入顺叙。）

**【U1 2.5–8.5s】**（客厅暖光明亮，两人刚起争执）
A：你能不能别走，坐下，我们把话说清楚。
B：现在说能说出什么？都在气头上，说出来全是狠话。
B（起身）：我不想跟你吵，都冷静冷静。

**【U2 8.5–15.5s】**
A（跟上去拦在他面前）：我不要冷静！我现在就要说！
B（绕过她，走到沙发坐下，戴上耳机，不看她）：你先冷静吧。
A（站在原地，声音从高变委屈）：你看看我……

**【U3 15.5–22.5s】**
A（走到他面前，盯着他）：你不说话是什么意思？是我错了，还是你不想理我了？
B（闭着眼深呼吸，不接，耳机还戴着）：……
A（声音抖）：你骂我两句都行，你别这样晾着我。

**【U4 22.5–30.5s】**
A（一把摘下他耳机）：你知道吵架我最怕什么吗？不是你跟我争，是你一转身，把我一个人丢在情绪里。
B（压火）：我冷静是不想说狠话伤你，这也错了？
A：可你冷静的时候，我满脑子都是"他是不是不爱我了"。

**【U5 30.5–37.5s】**
A（眼红，声抖但不停）：我要的从来不是你认输。
A：是你别走、你看着我、告诉我一句"我在"。
A：你一沉默，我就觉得被你丢下了，那种感觉比吵架疼一百倍。

**【U6 37.5–43.5s】**
B（无奈也有点冤）：我真不是冷暴力，我就是不会在气头上说话。
A（盯着他，一句钉死）：可你现在这样，比骂我还疼。
B（被砸得愣住，张嘴没说出话）：……

**【U7 43.5–50.5s】**
A（眼泪掉下来，反而平静，后退一步抱住自己手臂）：原来最伤人的不是吵架。
A：是我一个人，站在这儿，唱独角戏。
（她不再追，转身坐到另一边抱着膝盖；B 伸手想拉又停住。镜头停在两人之间的距离，不黑场。）

### 传播工程（进攻）
- **顶点金句（cold open）**："你每冷我一秒，我心里就凉一分。"
- **收口判决**："最伤人的不是吵架，是我一个人唱独角戏。"
- **@某人**：@那个一吵架就说"我想静静"的他。
- **置顶评论（只放置顶）**：
  > 吵架后该不该先冷静？觉得冷静才成熟、避免说狠话的扣1；觉得不说话=冷暴力、必须当场说开的扣2。我看哪派人多。
- **话题**：#冷暴力 #回避型人格 #情侣吵架 #情感共鸣
- 命中动机：④情绪过载（憋屈想替她说话）★★★｜③关系连接（@回避型伴侣）★★★｜②嘴替★★｜⑥人格身份归属★★。

### 留存工程（防守）
- 前 3s 金句直接定性、立场强；"10秒前"制造"她为什么这么说"的悬念。
- **29 个事件 / 50.5s，AEI ≈ 1.74s ≤ 2.5s**；无 ≥2.5s 零事件窗（B 的沉默均被 A 的追问填满，不是空镜）。
- 节奏：高冲击起 → 追拦升级 → 对撞 → 组合拳 → 距离定格收口。

### 包装层
- **发布文案**：
  > 一个想当场说开，一个想各自冷静。你越躲，我越崩溃。@那个一吵架就说"我想静静"的他 #冷暴力 #回避型人格 #情侣吵架
- **封面**：U5/U6 A 红着眼直视帧 + 大字"你冷的是我"。

### 制作要点（H3）
- B 的回避要演成"真心怕说狠话"，不能演成冷漠/嘲讽；全程不戴无所谓的笑。
- B 的"沉默"镜头必须有 A 的动作或台词同步填充，避免生成纯静默空镜。
- 道具连贯：耳机戴上→被 A 摘下；机位尾帧接首帧；客厅灯光明亮暖调。
- U0 复用 U5/U6 A 近景素材，剪辑前置，不单独生成。

# P2｜《我翻的不是旧账，是没被接住的委屈》（翻旧账）

**片名候选**：《你怎么又翻旧账》/《我翻的不是旧账，是没被接住的委屈》/《等我不翻了，就是不在乎了》
**场景**：家里玄关到沙发，他又一次犯了同样的错（答应陪她却没做到）。**道具**：手机（聊天记录）、包、沙发。
**人物**：A 她（攒了一次次失望）；B 他（觉得早该过去了）。

**两派与定位**
- 她派：旧账翻不完，是因为每次都没被接住——没道歉、没真改。
- 他派：当时你说没事，现在又翻，老揪着不累吗，人要往前看。
- 爆款逻辑：男女两派最经典对吵，金句最狠、截图率最高。

### 节拍表

| 段 | 时间 | 功能 |
|---|---|---|
| U0 | 0–2.5 | cold open：那些事我记到现在 |
| U1 | 2.5–8.5 | 同样的错第三次，她列举 |
| U2 | 8.5–15.5 | 他说过去了，她点破"没说≠没在意" |
| U3 | 15.5–22.5 | 他主张往前看，她指出又发生 |
| U4 | 22.5–30.5 | 旧账翻不完=没被接住 |
| U5 | 30.5–37.5 | 翻的是没处放的难过 |
| U6 | 37.5–43.5 | 让人翻篇的不是时间 |
| U7 | 43.5–50.5 | 收口：不翻了=不在乎了 |

### 完整台词（零旁白）

**【U0 0–2.5s · cold open】**（A 眼红近景，声不大却重）
A：你以为我愿意翻？那些你觉得早过去的事，我一个人，记到现在。
（0.3s 停顿，转场"10 秒前"。）

**【U1 2.5–8.5s】**（同样的错又发生，B 放包/换鞋，A 看着他，很平静）
A：你知道吗，这是第三次了。
B（皱眉）：哪三次？你看你，又开始翻旧账。
A：上个月你说陪我，没来；上上个月，同样的话。

**【U2 8.5–15.5s】**
B（不耐烦）：这事儿不都过去了吗？当时你也没说啥啊。
A（声音很轻）：我没说，不代表我没在意。
A：我当时笑着说"没事"，你就真当没事了。

**【U3 15.5–22.5s】**
B（摊手）：那你当时不说，现在翻出来，有意思吗？人得往前看。
A（眼睛红了）：我往前看了，是它一次次又发生。
A：今天这事儿，跟上次、上上次，一模一样。

**【U4 22.5–30.5s】**
A（眼泪在眼眶，一句接一句）：你知道旧账为什么翻不完吗？
A：因为每次我都没真正被接住——没一句"我知道你委屈了"，没一次你真的改。
B（语气软了，挠头）：我以为你早不气了……

**【U5 30.5–37.5s】**
A（眼泪掉下来）：我翻的不是那几件事。
A：是我一次次咽下去、没地方放的难过。
A：它们堆在心里，一遇到相似的事，就全冒出来了。

**【U6 37.5–43.5s】**
A（很认真盯着他）：真正让我翻篇的，从来不是时间。
A：是你让我觉得"这事，真的过去了"。
B（被砸得说不出话，小声）：……那我现在改，还来得及吗。

**【U7 43.5–50.5s】**
A（抹了下眼泪，反而平静）：我也想不翻。
A：可失望这东西，它不打招呼，自己就冒出来。
A（很轻，像判决）：等我哪天不翻了，不是我释怀了——是我不在乎了。
（她起身去倒水、放下手机，留 B 一个人坐在原地。镜头停住，不黑场。）

### 传播工程（进攻）
- **顶点金句（cold open）**："那些你觉得早过去的事，我一个人记到现在。"
- **收口判决**："等我不翻了，不是释怀，是我不在乎了。"
- **@某人**：@那个总说"你怎么又翻旧账"的他。
- **置顶评论（只放置顶）**：
  > 吵架爱翻旧账，到底谁的问题？觉得老翻是不放过彼此的扣1；觉得旧账是没被接住的委屈、该说清的扣2。
- **话题**：#翻旧账 #失望 #情侣吵架 #情感共鸣
- 命中动机：④情绪过载★★★｜②嘴替（金句密集）★★★｜③@伴侣★★｜⑥话题参与★★。

### 留存工程（防守）
- **25 个事件 / 50.5s，AEI ≈ 2.02s ≤ 2.5s**；对白持续推进，无长静默。
- 节奏：金句定性 → 列举事实 → 点破机制（没被接住）→ 组合拳 → 判决收口。

### 包装层
- **发布文案**：
  > 我翻的不是旧账，是当时没被你接住的委屈。@那个总说"你怎么又翻旧账"的他 #翻旧账 #失望 #情侣吵架
- **封面**：A 含泪平静帧 + 大字"我翻的是委屈"。

### 制作要点（H3）
- A 全程"平静里压着委屈"，不是歇斯底里；眼泪在 U5 掉、U7 收住。
- B 从"不耐烦"到"语软"到"语塞"有层次，不能一直硬或突然变脸。
- 手机聊天记录可由后期/道具处理，画面不依赖模型生成文字。

# P3｜《国庆出游，我做了20页攻略，他只带了个人》（旅行攻略）

**片名候选**：《我做了20页攻略，他只带了个人》/《旅行最累的是只有我认真》/《剩下的行程你来》
**场景**：国庆热门景区门口/车站广场，一个连续场景，人潮、行李在身边。**道具**：手机（预约码/攻略）、背包、行李。
**人物**：A 她（操碎心）；B 他（甩手掌柜）。

**两派与定位**
- 她派：我查天气路线门票餐厅，你一句我都行就全甩给我，出问题还怪我。
- 他派：我本来就不挑、跟着走，你非要整这么细，计划赶不上变化。
- 爆款逻辑：国庆全民出游强蹭节点，"一个人操心像带孩子"是情侣旅行第一争议。

### 节拍表

| 段 | 时间 | 功能 |
|---|---|---|
| U0 | 0–2.5 | cold open：只有我一个人在认真 |
| U1 | 2.5–8.5 | 核对预约码，他找不到 |
| U2 | 8.5–15.5 | 排长队他烦躁、怪累 |
| U3 | 15.5–22.5 | 又出状况他怪攻略，她反问 |
| U4 | 22.5–30.5 | 20页攻略 vs 一句我都行 |
| U5 | 30.5–37.5 | 别让我一个人扛 |
| U6 | 37.5–43.5 | 他要接手，她提条件 |
| U7 | 43.5–50.5 | 递手机让他定，自己空出手 |

### 完整台词（零旁白）

**【U0 0–2.5s · cold open】**（A 疲惫近景，背景是模糊人潮）
A：旅行最累的不是赶路，是从头到尾，只有我一个人在认真。
（0.3s 停顿，转场"10 秒前"。）

**【U1 2.5–8.5s】**（景区门口人挤人，A 低头核对，B 两手空空跟后面）
A（边操作边念）：预约码、身份证……你的呢，截图发你了，找出来。
B（掏手机翻半天）：啊？发哪了，我没看到。
A（深吸气）：我昨晚发你三遍。

**【U2 8.5–15.5s】**（排长队，太阳晒）
B（烦躁）：怎么这么多人，这得排到什么时候。
A：我攻略里写了这个点要早来，是你非要睡懒觉。
B（嘟囔）：出来玩搞这么累，至于吗。

**【U3 15.5–22.5s】**（往前走，发现走错入口/餐厅要等两小时）
B（抱怨）：你攻略咋做的，这不对那也不对。
A（停下转头看他）：我做攻略的时候，你在哪？
B（一愣）：我……我不是说我都行，听你的吗。

**【U4 22.5–30.5s】**
A（盯着他，一句句）：我做了20页攻略，查了天气、路线、门票、餐厅。
A：你一句"我都行"，就把所有事都甩给我了。
B（有点冤）：我本来就不挑，你非要整这么细……

**【U5 30.5–37.5s】**
A：我不是非要你安排。
A：是你能不能上点心，别让我一个人扛，像带个孩子出门。
A：我也想，偶尔当一次什么都不用想的人。

**【U6 37.5–43.5s】**
B（被说动，伸手）：那……手机给我，剩下的我来弄。
A（没立刻给，看着他）：出了问题，你别又怪我。
B（挠头，小声）：……知道了。

**【U7 43.5–50.5s】**
A（把手机递给他，平静）：行，下一个景点怎么走、几点预约、吃什么，你定。
（B 接过手机，对着人潮和攻略一脸发懵；A 退后一步，第一次把双手空出来。镜头停在 B 手忙脚乱、A 终于松下来的对比，不黑场。）

### 传播工程（进攻）
- **顶点金句（cold open）**："旅行最累的不是赶路，是只有我一个人在认真。"

# P4｜《我想要张能看的照片，他拍了100张废片》（旅行拍照）

**片名候选**：《他拍了100张废片》/《我气的不是拍得丑，是你不认真》/《照片我自己能拍，只是想和你一起》
**场景**：国庆景点打卡点，人多排队，她穿好看衣服摆姿势。**道具**：手机、自拍杆。
**人物**：A 她（想要美照/留回忆）；B 他（不耐烦、随手拍）。

**两派与定位**
- 她派：你敷衍的不是照片，是我想和你留回忆这件事。
- 他派：我拍了上百张你都不满意，人这么多，别耽误排队。
- 爆款逻辑：最高频、画面感强、轻松又真实，极易@和模仿，二创/跟拍空间大。

### 节拍表

| 段 | 时间 | 功能 |
|---|---|---|
| U0 | 0–2.5 | cold open：你连好好拍都不愿意 |
| U1 | 2.5–8.5 | 交代构图，他随手拍 |
| U2 | 8.5–15.5 | 废片，他嫌事多 |
| U3 | 15.5–22.5 | 又拍废，他催排队 |
| U4 | 22.5–30.5 | 拍照是想留我们的样子 |
| U5 | 30.5–37.5 | 你敷衍的是留回忆 |
| U6 | 37.5–43.5 | 上百张没一张认真看我 |
| U7 | 43.5–50.5 | 自拍收口，本来想和你一起 |

### 完整台词（零旁白）

**【U0 0–2.5s · cold open】**（A 苦笑，举着手机里的废片）
A：我气的从来不是拍得丑，是你连好好给我拍一张，都不愿意。
（0.3s 停顿，转场"10 秒前"。）

**【U1 2.5–8.5s】**（打卡点人多，A 整理头发找背景）
A（期待，交代）：就这儿帮我拍一张，人放中间，脚贴着画面底边，显高。
B（随手举手机咔嚓两下）：好了。

**【U2 8.5–15.5s】**
A（凑过来看：闭眼/糊/半个身子/全是人）：这……我眼睛闭着，人就这么点，后面全是人。
B（不耐烦叹气）：你事儿真多，我再拍一张，行了吧。
A（忍了，重新摆好）：……你认真点。

**【U3 15.5–22.5s】**（B 又拍，还是歪的，全程没蹲下没看画面）
A（无奈）：你能不能蹲下点，等我眼睛睁开、表情好了再按？
B（提高音量）：人这么多，拍两张得了，后面还排队呢。

**【U4 22.5–30.5s】**
A（情绪上来）：我为什么非要在这儿拍照，你知道吗？
A：这趟旅行、这个假期，我想留点我们一起的样子。
B（嘟囔）：记脑子里不就行了……

**【U5 30.5–37.5s】**
A（眼红，一句句）：你敷衍的不是照片。
A：是我想和你一起留下回忆，这件事。
A：我不要你拍成摄影师，就为我多花五分钟，认真一点，不行吗？

**【U6 37.5–43.5s】**
B（有点冤也有点烦）：我都拍了上百张了，你没一张满意，到底要我怎样？
A（被噎住，自嘲笑了）：……上百张，没有一张是认真看我的。

**【U7 43.5–50.5s】**
A（拿回手机，平静）：算了，不麻烦你了。
（她转身，礼貌拦住路过的小姐姐/举起自拍杆，自己调整角度，笑着拍下。B 举着停在拍照界面的手机愣在原地。）
A（轻声，像判决）：照片我自己能拍……只是我本来，想和你一起。
（镜头停在她自拍的笑脸和 B 尴尬的脸之间，不黑场。）

### 传播工程（进攻）
- **顶点金句（cold open）**："我气的不是拍得丑，是你连好好拍一张都不愿意。"
- **收口判决**："照片我自己能拍，只是本来想和你一起。"
- **@某人**：@那个给你拍照永远敷衍的他。
- **置顶评论（只放置顶）**：
  > 对象拍照敷衍/拍得丑，你会生气吗？觉得是态度问题、该生气的扣1；觉得他尽力了、要求别太高的扣2。
- **话题**：#国庆旅行 #拍照 #情侣旅行 #情感共鸣
- 命中动机：③@某人★★★｜④情绪过载（又气又鼻酸）★★★｜①社交货币（拍照梗，易跟拍/晒对比）★★｜②嘴替★★。

### 留存工程（防守）
- **24 个事件 / 50.5s，AEI ≈ 2.10s ≤ 2.5s**；每轮"拍—看—指出问题"循环推进。
- 节奏：金句 → 第一组废片 → 第二组废片升级 → 点破动机 → 组合拳 → 自拍反转定格。

### 包装层
- **发布文案**：
  > 想要张能看的照片，他拍了100张废片，还嫌我要求高。@那个给你拍照永远敷衍的他 #国庆旅行 #拍照 #情侣旅行
- **封面**：A 一脸无奈举着废片 + 大字"100张废片"。

### 制作要点（H3）
- "废片"是核心梗，可由后期/真实拍摄呈现（闭眼、构图歪），画面里的照片内容不依赖模型生成。
- B 演出"我尽力了但不耐烦"，不能演成故意使坏；结尾尴尬、有点理亏。

# P5｜《国庆7天5场婚礼，我的钱包在渡劫》（随份子）

**片名候选**：《7天5场婚礼，钱包渡劫》/《成年人的人情躲不掉》/《自己办事时一起记着》
**场景**：国庆前晚上，家里沙发，两人对着手机里一堆电子请柬。**道具**：手机、计算器（口播算账）。
**人物**：A 她（被人情困住）；B 他（觉得不值）。

**两派与定位**
- 她派：人情不是光用钱算，是面子、关系、以后相见，不去怕被说不懂事。
- 他派：十年不联系还发请柬就是冲钱，无效社交该断，钱花刀刃上。
- 爆款逻辑：覆盖最广（情侣单身都中）、轻松吐槽、强时效、易@朋友。

### 节拍表

| 段 | 时间 | 功能 |
|---|---|---|
| U0 | 0–2.5 | cold open：人情一个都躲不掉 |
| U1 | 2.5–8.5 | 数请柬、报价 |
| U2 | 8.5–15.5 | 算账小三千，质疑十年没联系 |
| U3 | 15.5–22.5 | 冲钱来 vs 怕被说 |
| U4 | 22.5–30.5 | 该断 vs 怕戳脊梁骨 |
| U5 | 30.5–37.5 | 人情用面子关系一起算 |
| U6 | 37.5–43.5 | 分类处理、能省一半 |
| U7 | 43.5–50.5 | 该去还得去，自己办事一起记 |

### 完整台词（零旁白）

**【U0 0–2.5s · cold open】**（A 苦笑，数着手机请柬）
A：我累的不是随份子那点钱，是成年人的人情，一个都躲不掉。
（0.3s 停顿，转场"10 秒前"。）

**【U1 2.5–8.5s】**（晚上沙发，A 翻通知，B 凑过来）
A（数）：1号小学同学、2号大学室友、4号同事、6号远房表妹……七天，五场。
B（咋舌）：一场随多少？
A：起步五百，关系好的得一千。

**【U2 8.5–15.5s】**
B（拿手机算账）：五场，小三千，你一个月工资没了。
A（叹气）：那能咋办，人家请柬都发来了。
B：那个小学同学，你是不是十年没联系了？

**【U3 15.5–22.5s】**
A（犹豫）：……是没怎么联系，可人家特意@我了。
B（摊手）：这就是冲着份子钱来的，你去了就是冤大头。
A（为难）：不去，背后人家怎么说我。

**【U4 22.5–30.5s】**
B：钱要花在刀刃上，这种无效社交，该断就断。
A（摇头）：你以为我愿意随？我心疼钱，可更怕被人戳脊梁骨说不懂事。
B（嘟囔）：死要面子活受罪……

**【U5 30.5–37.5s】**
A（认真看他）：成年人的人情，不是光用钱算的。
A：是用面子、关系、以后好不好相见，一起算的。
A：我要的不是你替我心疼钱，是你理解我的为难。

**【U6 37.5–43.5s】**
B（语气软下来）：……那哪些必须去，你定，我陪你。
A（想了想）：室友和同事得去，其余的我随个红包、人不到。
B（点头）：这还差不多，能省一半。

**【U7 43.5–50.5s】**
A（一条条回消息，平静）：该去的还得去，这就是大人的假期。
A（顿，转头认真看他）：但有一条——咱们自己办事的时候，这些人情，你得陪我一起记着。
B（笑，伸手）：行，一起记。
（两人凑在一起对着手机，镜头停在那摞电子请柬和两人商量的画面，不黑场。）

### 传播工程（进攻）
- **顶点金句（cold open）**："我累的不是钱，是成年人的人情一个都躲不掉。"
- **收口**："我们自己办事时，这些人情一起记着。"（务实、不黑场）

  > 国庆扎堆随份子，你会去吗？八百年不联系、坚决不去的扣1；人情往来、该去还得去的扣2。

### 留存工程（防守）
- **25 个事件 / 50.5s，AEI ≈ 2.02s ≤ 2.5s**；数请柬、算账、辩论、给方案层层推进。

### 制作要点（H3）
- 基调轻松吐槽、不沉重，两人是"一起面对"而非对立（结尾要站到一边）。
