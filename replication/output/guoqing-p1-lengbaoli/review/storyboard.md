## S-U1 炸点钩子·扯耳机（0.0–5.0s）

### A. 故事与节拍
- 对应原文：U1「戴什么耳机！看着我！看着我！我跟你说话呢！」「我没躲你……我是怕一开口，话说重了。」
- 不可丢失：耳机从 B 头上被扯下的完整动作；B 的动机台词"怕一开口话说重了"
- 节拍 ID 与通道：U1-B1 · picture / dialogue / action_sound / ambience；U1-B2 · transition（后期数码推近）
- 节拍功能：建立（钩子）
- 单一观看重点：耳机被一把扯下
- 观众进入时：零信息
- 离开时新增：她被晾到崩溃，他在躲但自称是怕伤她——两派立场亮出
- 删除损失：钩子与冲突起因

### B. 时间、主体与动作
- 时间/时长：0.0–5.0s
- 连续时空：SC_LIVING 夜晚
- 主体位置：引用场景总设定——B 坐沙发中间偏右（画右），A 站其左前方（画左）
- 动作：A 手已抓头梁 → 0.6s 内扯下（B 头发被带乱、手机滑到腿上）→ A 攥耳机俯身吼 → B 猛抬头后缩、手攥膝盖、快速解释
- 表演/视线：A 俯视瞪 B，急气；B 先低头紧锁眉，被吓抬头，眼神慌躲不敢久看她；B 全程不笑不嘲讽
- 道具：耳机 B 头上 → A 右手里；手机 B 手里 → B 腿上

### C. 画面设计
- 景别：中景双人（A 腰上、B 坐姿全上身）
- 机位与角度：轴线观众侧，沙发正前方，略低机位（约坐姿 B 胸口高），微仰
- 构图：A 画左占高位，B 画右低位；沙发、落地灯在后
- 运镜：手持极轻微晃，跟扯的动作；静中有动
- 光线：沿用总设定，无差异
- 环境微动态：耳机漏音音乐骤远
- 禁止项：可读字/logo、耳机品牌标识、手机屏朝镜头、越轴、B 露笑

### D. 镜间衔接
- 与前镜关系：首镜
- 前镜依据：无
- 本镜承接：片头即动作进行中，无静帧头
- 是否共用边界帧：U1-last 同时作为 U2 首帧（共用，保证耳机/手机/站位状态不跳）
- 与后镜关系：连续动作（动接动）
- 留给后镜的状态：A 站画左、右手攥耳机；B 坐画右仰头看她，手机在腿上
- 后镜应承接：同身份/服装/站位/光色、耳机在 A 手里、手机在 B 腿上
- 首尾帧运动状态：起始 = 运动（A 手臂向画左后拉扯）；收尾 = 运动（A 手臂开始扬起）
- 剪辑点衔接类型：与后镜 = 动接动（甩耳机动作起点）

### E. 声音与后期文字
