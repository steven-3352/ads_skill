# 分镜 S01(前戏甜告白)

## A. 故事与节拍
- 对应原文:男(轻声,带笑)「我喜欢你。」+ 女(雀跃)「你再说一遍?」
- 不可丢失信息/动作:开口即告白(钩子)、女孩惊喜绽笑、镜头开始拉升起飞
- 节拍 ID 与交付通道:B1(对白+表演)、B2(对白+运镜)
- 节拍功能:建立 + 钩子
- 单一观看重点:两人甜的对视与告白瞬间
- 观众进入时知道/期待:开头 3s 内听到"我喜欢你",好奇会发生什么
- 观众离开时新增认知/感受:告白已出、女孩雀跃、世界即将起飞
- 删除本镜会损失:人物锚点与情感起点,后续穿界失去主语

## B. 时间、主体与动作
- 时间位置与预计时长:0–3.5s
- 连续时空:清晨山路车旁(现实)
- 主体及位置:男孩女孩中景相对而立,车与远山为背景
- 主要动作目标:说出告白 → 女孩反应 → 镜头起升
- 起点→过程→转折→终点:静立对视 → 男孩轻声告白 → 女孩眼睛一亮绽笑「你再说一遍?」→ 镜头随其仰头上升、两人开始缩小、云气漫入上缘
- 人物表演、视线与反应:男孩耳根发红忍笑、目光躲闪又坚定;女孩由怔到惊喜绽笑、视线上扬
- 道具起始→结束状态:车静止;两人由平视 → 镜头抬升转微俯

## C. 画面设计
- 景别及变化:中景 → 缓拉远升高(到 3.5s 人物缩到画面 ~20%)
- 机位与角度:平视起,顺女孩上扬视线转为微俯的上升
- 构图与视觉焦点:两人居中偏下,上方留天空气口给"起飞"
- 主要运镜理由:上升是穿界的物理动机,必须在此启动
- 光线与色彩:清晨柔金侧光、通透暖调、无硬阴影
- 环境微动态:微风拂发、草木轻摇、晨雾薄流
- 画面禁止项:大特写、夸张面部、杂乱背景、饱和刺眼、字幕

## D. 镜间衔接
- 与前镜关系:首镜
- 前镜提供的依据:无
- 本镜如何承接:—
- 与后镜(S02)关系:设计性无缝转场(上升运动延续)
- 本镜为后镜留下的状态:镜头正在上升 + 云气开始漫入上缘
- 后镜应承接:上升方向、暖光调、云气入画的形状 → 匹配叠化进天上
- 验证方法:边界帧共享上升构图 + 云气位置对照

## E. 声音与后期文字
- 对白及说话人:男孩「我喜欢你。」(轻声带笑)/ 女孩「你再说一遍?」(雀跃)
- 旁白:无
- 后期字幕:前戏 2 句对白入**结构化字幕清单**→ 后期用 `tools/burn-subtitles.sh` 统一烧;底部 15–18% 安全区在文生图时留干净;生成镜**不直出字幕**

## H. 音效/声音设计(edit-plan 同步)
- ①环境底噪/拟音:清晨微风底噪、清晨鸟鸣、远处极淡山谷空气感;告白出口 **0.3s 环境抽真空**托台词
- ②人声层:**真人对白**(男+女双句),尚无后期回响(回响从 S02 起)
- ③音乐床走向:极轻的暖色钢琴/弦乐单音铺底,B2 末起**一记轻盈上升音(rising cue)**预告起飞 → 音乐从此"由弱到强"的起点

# 分镜 S02(天上·起飞)

- 单一观看重点:冲出云海、天地通透的辽阔

## B. 时间、主体与动作
- 时间与时长:3.5–6.0s
- 连续时空:云层之上(梦境无缝续接现实上升)
- 主体及位置:柔散暖光巨晕居上,云海铺满,两人已成云间微小暖点(5–8%)
- 主要动作目标:穿透云层、视野炸开

## C. 画面设计

- 机位与角度:持续上升转平移俯视
- 构图与视觉焦点:巨晕与地平线,巨量留白,人物点缀
- 主要运镜理由:延续上升=无缝转场;揭示巨物需大范围移动
- 光线与色彩:柔散暖金巨晕、通透暖调、漫射无硬影(去低饱和冷调)
- 环境微动态:云气流动、光晕呼吸
- 画面禁止项:硬切、大特写、人物占画、刺眼饱和、字幕

## D. 镜间衔接
- 与前镜(S01):设计性无缝转场
- 前镜提供的依据:上升运动 + 上缘云气形状
- 本镜如何承接:接住云气→展开为云海,上升不中断
- 与后镜(S03):同向下俯运动 + 云海→雪山脊线形状匹配
- 本镜为后镜留下的状态:云海拢成山脊轮廓、下俯启动
- 验证方法:边界帧云/山脊形状对照、运动方向一致

## E. 声音与后期文字
- 对白及说话人:男孩「我——喜欢——你!」(迎风放大)——**全片最后一句真人对白**
- 后期字幕:B3 告白句入字幕清单(后期烧)

## H. 音效/声音设计
- ①环境底噪/拟音:钻出云顶的 **whoosh 上升风声**、高空气流、云层空气感;巨晕显现时一记暖色"光晕绽开"氛围音
