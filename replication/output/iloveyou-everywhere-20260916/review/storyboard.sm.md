## 关键镜 SOP A–G 填空（选 SM01 前戏 / SM05 海底巨鲸 / SM07 收尾 三个关键立基帧）

### SM01 · 人间前戏（立基关键帧：双人中景甜告白）

- **A 景别/构图**：中景双人，16:9，两人各占画面一侧，中间留一线呼吸；低机位微仰，天空占上 1/3。
- **B 主体/巨物**：无巨物；主体=男孩女孩。为全片唯一的"人物给足"拍，后续所有界的 5–10% 尺度落差由此锚定。
- **C 人物**：East Asian 中国面孔，青春干净素人感，男主母板锁身份、女主母板锁身份；男孩浅色T恤，女孩浅色连衣裙；耳根微红、垂眼又抬眼／女孩含笑。
- **D 光线/调色**：清晨暖金斜光，漫射柔光无硬阴影，通透暖调（灰蓝底 + 暖米高光，非低饱和冷调）。
- **E 运镜**：起手near-static，说出口瞬间镜头随气流极缓上扬。
- **F 声音**：微风底噪 + 低频心跳；出口 0.3s 环境抽真空托台词「……我喜欢你。」
- **G 转场出**：上升气流 → 画面上扬穿向云层（同向运动起手）。

### SM05 · 海底巨鲸（立基关键帧：巨鲸极远景）

- **A 景别/构图**：极远景，16:9；巨鲸横贯/斜贯画面深处，占画面主体，四周大量通透水体留白；若有人物锚点则 0–5% 悬浮点缀。
- **B 主体/巨物**：**巨鲸**（用户锁定海底锚点），体量压倒全画，尺度落差在此达峰。
- **C 人物**：本拍人物基本不入画（或极小剪影），身份不需再锁。
- **D 光线/调色**：海面折射的光帘自上而下、悬浮微粒、蓝中透暖的通透水下光；无冷调压抑，保持空灵明亮。
- **E 运镜**：镜头持续向下潜行，跟随鲸缓游的同向运动。
- **F 声音**：叠加第四层人声回响 + 鲸的低频胸腔共鸣感（"海替他回答"）。
- **G 转场进/出**：进=穿海面光帘匹配叠化；出=鲸尾迹引导镜头继续下潜，匹配叠化入海床裂隙。

### SM07 · 收尾（立基关键帧：上帝视角俯瞰 → 回落双人甜脸）

- **A 景别/构图**：先极远景上帝视角俯瞰天地五界层叠；后回落到 SM01 同机位双人中景甜脸收束。
- **B 主体/巨物**：上帝视角俯瞰的"天地全景"本身为最后一个尺度巨物；随后尺度交还人物。
- **C 人物**：双人回到画面主体（60%+），女孩笑着回答；身份沿用母板。
- **D 光线/调色**：万物暖光通透，情绪最亮最甜。
- **E 运镜**：光过曝破土上拔 → 到俯瞰 → 缓回落定格双人甜笑。
- **F 声音（后期）**：亿万层叠「我喜欢你」从五界涌回、铺满声场后归拢，收束到女孩真人回答「……我也喜欢你。」（或留白让笑收）。
- **G 转场进**：地下晶洞光过曝叠化上拔承接。
