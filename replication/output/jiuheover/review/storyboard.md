## S01（U1）钩子·物件先行 + 苏晚问出轨（pre-lap）

### A. 故事与节拍
- 对应原文：【钩子】「在我们在一起这几年，你有没有过，出轨？」
- 不可丢失：物件（白瓷瓶+满杯）先行；钩子人声 pre-lap 第 0 秒即入耳
- 节拍功能：建立（前 2s 推流命门——最猛问上来）
- 观众离开时新增：这不是普通饭局，是一场要摊牌的真心话局

### B. 时间、主体与动作
- 时间/时长：0–5s（5s）
- 连续时空：是（全片同一小酒馆靠窗老位置，sceneId s1）
- 主体位置：苏晚坐桌一侧；镜头由前景物件带到她近景
- 动作起→止：手把满杯放下 → 镜头带到她脸 → 她看着对面、忍着问出轨

### C. 画面设计
- 景别/机位：竖屏 9:16 近景（物件起→她脸），iPhone 手持轻晃真实质感
- 光线：暖白偏暖顶灯+桌面吊灯，明亮温暖、看得清脸（不压暗）
- 道具：素白无标白瓷瓶+两只玻璃白酒杯（无文字/logo/标签）；酒位=满（递减线起点）
- 禁止项：anti-subtitle 零字幕；East Asian 中国人面孔随母板 A；无品牌

### D. 镜间衔接〔重中之重〕
- 为后镜留状态：问题已抛出、等对面回答；机位在她侧（U2 切到他侧=正反打）
- 后镜（U2）承接：陈叙答"没有/你希望有"，相邻单元交替机位

### E. 声音与后期文字
- 对白：苏晚（pre-lap 先入，随后入画同步）「在我们在一起这几年，你有没有过，出轨？」
- 音效必带：窗外雨声 + 店内环境 + 满杯放桌轻磕声
- 后期字幕：无

### F. 故事板 Panel
- 画格数：1（I2VA 单首帧）；P1=物件+苏晚近景（`prompts/U1-first.json`）

### G. 单元级验收
- 钩子人声第 0 秒入耳✔；物件/白瓷瓶合规✔；明亮暖白✔；零字幕✔；为 U2 留正反打机位✔
