# 01《虾壳》

预计时长：约 105 秒

## 核心戏剧动作

林晚想若无其事地吃完一顿同事聚餐，却被一盘虾和受伤的手指逼回一段已经结束的关系。

## 完整剧本

【场景 1：餐馆包间 / 夜 / 现在】

一只完整的白灼虾躺在林晚面前的小碟里。

同事小周夹来第二只。

小周：这盘就你没动。减肥啊？

林晚把虾夹回公盘。

林晚：懒得剥。

小周：喜欢吃还懒。

旁边的人继续聊天。筷子碰碗，虾壳被掰开，发出清脆的一声。

林晚抬眼。

【场景 2：公司聚餐 / 夜 / 四年前】

同样一声脆响。

陈屿低着头剥虾，面前已经堆了一小摞虾壳。林晚正和同事说话，碗里不断多出剥好的虾。

林晚夹起一只。

林晚：你能不能快点？我这边都断供了。

陈屿：着什么急。

虾壳尖刺进陈屿的食指。他缩了一下，指腹冒出一颗血珠。

林晚：扎了？

陈屿把手指含了一下，抽出纸巾按住。

陈屿：没有。

林晚：那你快点。

陈屿看她一眼，拿起下一只虾。

同事老赵从桌对面伸筷子。

老赵：给我来一个。

陈屿把刚剥好的虾放进林晚碗里。

陈屿：自己剥。

桌上笑起来。林晚也笑，低头把虾吃掉。

【场景 3：出租屋餐桌 / 夜 / 四年前】

外卖盒摊在桌上。陈屿一边看电脑，一边替林晚剥小龙虾。

林晚伸筷子去夹。

陈屿按住她的筷子。

陈屿：辣的在左边。你胃不舒服，吃右边。

林晚：吃个虾也管。

陈屿把一碗剥好的虾肉推给她。

陈屿：那你别吃。

林晚夹走最大的一只。

林晚：你管我。

陈屿继续看电脑。被扎破的手指上，缠着一小圈创可贴。

【场景 4：餐馆包间 / 夜 / 现在】

小周把剥好的一只虾放进林晚碗里。

小周：给。省得你懒。

林晚看着虾肉。

小周已经转身加入另一边的谈话。

林晚夹起虾，停在半空，又放下。

她从公盘夹回一只完整的虾。

【场景 5：餐馆洗手台旁 / 夜 / 现在】

林晚低头剥虾。壳从中间断开，尖刺扎进食指。

她迅速缩手。

指腹冒出一颗血珠。

周围的声音渐远，只剩水龙头滴水和她的呼吸。

她抽出纸巾，按住伤口。另一只手继续把虾壳剥完。

林晚把虾放进嘴里，慢慢嚼。

林晚（OS）：后来我才知道，他不是喜欢剥虾。

她把染上一点血的纸巾折起来，压在碟子下面。

林晚（OS）：他只是记得，我喜欢吃。

餐桌上的谈笑声重新涌回来。

画面停在她面前那一小堆不太完整的虾壳上。

切黑。

## 视听锚点

- Hook：第一只被退回公盘的虾。
- 时间转场：虾壳脆响连接现在与四年前。
- 情绪证据：同样被扎破的手指，不使用哭泣。
- 结尾回扣：过去是整齐的虾肉，现在是不完整的虾壳。
