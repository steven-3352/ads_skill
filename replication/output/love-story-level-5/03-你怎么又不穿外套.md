# 03《你怎么又不穿外套》

预计时长：约 110 秒

## 核心戏剧动作

林晚在一连串小麻烦里寻找那个总能接住她的人，最后发现他已经不在生活里。

## 剧本

【场景 1：写字楼门口 / 夜 / 现在】

雨下得很密。林晚站在屋檐下，手机电量 2%。她翻包：口红、纸巾、钥匙、一支断掉的笔。没有伞。她低头看脚，右脚鞋跟断了。

雨线斜着打进屋檐，鞋面很快洇出一圈深色。她把断掉的鞋跟捡起来，放回包里。

手机弹出低电量提示。她打开聊天列表，手指停在一个没有备注的号码上，打字：`你有没有……`。停住，全部删掉。

【场景 2：办公室 / 下午 / 四年前】

林晚打喷嚏。陈屿从抽屉里拿出药，又从包里掏出面包。

林晚：你抽屉是药店吗？

她把药盒举到眼前晃了晃，手却已经把面包撕开。

陈屿：饭后吃。

林晚：我没吃饭。

陈屿：所以有面包。

他起身去接水。林晚看着他的包。

【场景 3：地铁站出口 / 傍晚 / 四年前】

雨突然落下来。陈屿把伞撑开，伞柄递给林晚。

林晚：你呢？

陈屿：我走快点。

他半边肩膀淋在伞外，伸手把她往伞里推。

伞面上的水顺着骨架往下流，陈屿的袖口先湿透。林晚看见了，把伞柄往他那边挪了一寸。

林晚：你怎么又不穿外套？

陈屿：我不冷。

林晚把自己的外套往他肩上扯。伞向她这边偏过去。

【场景 4：办公室 / 夜 / 四年前】

陈屿的包放在椅背上。林晚拉开拉链，里面整齐放着充电宝、创可贴、止痛药、胶带、小雨伞和一枚备用纽扣。

林晚：你是不是把我当小学生？

她一样样拿出来排在桌上，排成一条歪歪扭扭的线，嘴上嫌弃，手却没有放回去。

陈屿：你今天已经把三件东西弄坏了。

林晚：哪三件？

陈屿：鞋跟、手机，还有——

林晚：还有什么？

陈屿把创可贴放回包里。

林晚：你能不能别什么都管？

陈屿手上的动作停住。

陈屿：好。

他把东西一样样收回去。

【场景 5：便利店门口 / 夜 / 现在】

林晚买了一把伞和一卷胶带。她坐在门口缠鞋跟。手机自动关机。

店员：要不要帮你粘一下？

林晚：我自己来。

胶带缠歪了。她拆开重来，手指被胶带黏住，停下来吹了一下。

她站起来，撑伞走进雨里。

林晚（OS）：我以前嫌他婆婆妈妈。后来才发现，我弄丢的是一个总能接住我的人。

雨声盖住车声。她的背影消失。

## 视听锚点

低电量、断鞋跟和下雨同时发生作为 Hook；百宝箱用物件特写表现；“好”是关系转折；结尾让她买到同样的工具，却没有买回那个人。
