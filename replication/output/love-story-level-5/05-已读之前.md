# 05《已读之前》

预计时长：约 118 秒

## 核心戏剧动作

林晚回到最后一条没有回复的消息，试图找到正式的分手时刻，却只找到双方逐渐停止发消息的过程。

## 剧本

【场景 1：地铁 / 夜 / 现在】

车厢晃动。林晚打开旧聊天窗口。最底部一条消息：`陈屿：你最近还好吗？`下面没有回复。

地铁进站，手机屏幕被车窗反光切成两半。她的拇指停在输入框上。

【场景 2：手机与生活碎片 / 交错 / 四年前】

字幕：`男孩离职后，第1天。`陈屿的聊天框：`你最近还好吗？`林晚看见，锁屏。

字幕：`第3天。`陈屿输入：`最近忙吗？`全部删除。

字幕：`第7天。`林晚在茶水间吃冷面包，打开聊天框，没有新消息。

字幕：`第30天。`陈屿站在新公司楼下，雨落在手机屏幕上。他收起手机。

【场景 3：办公室楼梯间 / 傍晚 / 四年前】

林晚追上陈屿。

林晚：你最近怎么了？

陈屿：没怎么。

林晚：你以前不是这样的。

陈屿：人会变。

林晚：那你至少说清楚。

陈屿靠在墙上，手指敲着手机边缘。

陈屿：说清楚了，又能怎么样？

林晚：至少我知道该不该等。

楼下有人喊他的名字。陈屿抬头。

陈屿：我先走了。

他从她身边经过。林晚没有追。

【场景 4：地铁 / 夜 / 现在】

林晚向上滑聊天记录：`到了吗？`、`伞在包里。`、`虾给你剥好了。`、`别等我，先睡。`

她在输入框打下：`那天我不是不想回你。`又打：`我只是觉得，已经没有什么好说的了。`

她看着两行字，全部删除。

【场景 5：小餐馆 / 夜 / 现在】

一盘白灼虾放在林晚面前。她自己剥虾，壳刺破手套，扎进指尖。

服务员递纸巾。

服务员：没事吧？

林晚：没事。

她按住伤口，换一只手继续剥，把虾放进自己碗里。

林晚（OS）：后来我才知道，我们不是哪一天分开的。只是有一天，他没有再发，我也没有再等。

她吃掉虾。手机屏幕熄灭。她打开聊天窗口，没有输入，退出。

切黑。字幕：`有过就好了。`

## 视听锚点

最后一条“你最近还好吗？”作为 Hook；第1、3、7、30天让沉默可见；手机不是信息展示，而是关系逐渐停止的证据；结尾回到虾，但不再插入回忆。
