# 05《已读之前》

预计时长：约 118 秒

## 核心戏剧动作

林晚回到最后一条没有回复的消息，试图找到正式的分手时刻，却只看见自己从一小时后回复、半天后回复、几天后回复，直到不再回复；陈屿等不到解释，渐渐也不再发。她没有主动挽回，也许那时她已经想分开。

## 剧本

【场景 1：地铁 / 夜 / 现在】

车厢晃动。林晚打开旧聊天窗口。最底部一条消息：`陈屿：你最近还好吗？`下面没有回复。

消息旁边没有时间，也没有后续气泡。她向上滑，拇指一次次被旧照片和语音条挡住。

地铁进站，手机屏幕被车窗反光切成两半。她的拇指停在输入框上。

【场景 2：手机与生活碎片 / 交错 / 四年前】

字幕：`男孩离职后，第1天。`

陈屿：你最近还好吗？

一小时后，林晚回复：`刚忙完。`

回复发出去，她把手机扣在键盘旁，继续敲字。屏幕右上角的时间跳过一格。

字幕：`第3天。`

陈屿：下班了吗？

半天后，林晚回复：`嗯。`

她只发出一个字，顺手把对话框的通知设成静音。

字幕：`第7天。`

陈屿：周末要不要吃饭？

几天后，林晚回复：`最近有点忙。`

消息发出后，她没有等对方回复，转身去接同事递来的文件。

陈屿的输入框里出现：`那你先忙。`

他删掉，换成：`好。`

字幕：`第15天。`

陈屿发来一张路边的虾照片：`看到这个，想起你。`

林晚看见，手机屏幕亮了很久。她把通知划掉，没有回复。

屏幕暗下去，又被会议提醒点亮。她把手机翻面，压在一摞文件下面。

字幕：`第30天。`

陈屿站在新公司楼下，打开聊天框。最后一条仍然是自己发的。他打出：`你最近还好吗？`，停住，全部删除，收起手机。

字幕：`后来，他也不再发。`

【场景 3：地铁 / 夜 / 现在】

林晚向上滑聊天记录：`到了吗？`、`伞在包里。`、`虾给你剥好了。`、`别等我，先睡。`

她在输入框打下：`那段时间，我其实已经想分开了。`又打：`只是没有说出口。`

她看着两行字，全部删除。

【场景 4：小餐馆 / 夜 / 现在】

一盘白灼虾放在林晚面前。她自己剥虾，壳刺破手套，扎进指尖。

服务员递纸巾。

服务员：没事吧？

林晚：没事。

她按住伤口，换一只手继续剥，把虾放进自己碗里。

林晚（OS）：后来我才知道，我们不是哪一天分开的。只是有一天，他没有再发，我也没有再等。

她打开聊天窗口。输入框是空的。她没有再打字，直接退出。

聊天列表里，陈屿的名字沉到最下面。她的手指掠过屏幕，没有把它置顶。

她吃掉虾。手机屏幕熄灭。

切黑。字幕：`有过就好了。`

## 视听锚点

最后一条“你最近还好吗？”作为 Hook；第1、3、7、30天让沉默可见；手机不是信息展示，而是关系逐渐停止的证据；结尾回到虾，但不再插入回忆。
