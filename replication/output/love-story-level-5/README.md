# 《她曾经这样爱过》

## 项目定位

写实现代爱情情景短片系列，与广告项目无关。五集统一为同一对男女；女孩视角为主，通过现在的生活细节触发回忆。每集 90–120 秒，严格不超过 2 分钟；可独立观看，合起来拼出一段没有正式结束的爱情。

画面质感参考现代写实、克制表演、现实与回忆交错、结尾情绪回收；不复制参考视频的具体人物、台词、镜头或情节。

## 核心主题

> 每个女孩都应该有一个刻骨铭心的爱情。爱情是奢侈品，有过就好了。

爱情没有正式分手事件。两人是同事，从熟悉到相爱；男孩离职后失去每天见面的理由。误会越来越多，失望越来越多，最后一条消息女孩没有回复，男孩也没有继续发。一旦、一周、一个月，成年人用“你不回，我也不再发”完成告别。

## 人物与关系

### 女孩

年轻时更在意当下的陪伴、及时回应和被看见。不擅长追问，也不愿显得太在乎；失望后会先收回自己，把沉默理解成答案。

### 男孩

在别人面前精明、谨慎、会计算得失；只有在女孩面前不计较。他习惯用剥虾、准备百宝箱、解决麻烦和努力赚钱表达爱，却不擅长解释脆弱，把“为以后努力”误当成了“她现在应该能够理解”。

### 共同前史

- 两人是现代城市的同事，在工作中熟悉并成为恋人。
- 男孩离职后，两人没有正式说分手。
- 关系在误会、失望和沉默里逐渐稀释。
- 最后一条消息她没有回复，他没有继续发。

## 统一叙事规则

```text
现在的生活细节
→ 物件/声音/动作触发回忆
→ 回忆中的照顾或误会
→ 回到现在
→ 女孩独自完成过去由男孩完成的动作
→ 一句克制旁白确认新的理解
```

表达比例建议：画面与动作 60%，对白 25%，旁白/屏幕文字 15%。旁白只负责时间跳跃、无法直接拍出的信息和结尾回收，不解释画面已经表达的情绪。

## 五集总纲

### 01《虾壳》

女孩不太会剥虾，手指总被扎破，后来很少吃。回忆中男孩每次替她剥，手被扎破也继续，把虾肉放进她碗里；她当时还嫌他慢、嫌他麻烦。多年后她第一次自己剥虾，手被扎破，停了一会儿，还是吃掉。

核心遗憾：她不是不喜欢虾，只是后来再也没有人替她剥。

### 02《不算》

男孩在别人面前精明，从不让自己吃亏；在女孩面前却不计算迟到、改计划、付钱和让步。一次争吵中女孩问“你是不是觉得反正我都会等你”，男孩只问“你已经这么想了？”误会没有被解释。现在她在计算器里输入旧账，最后全部删除。

核心遗憾：他把所有人的得失算得清楚，唯独没有计算过她。

### 03《你怎么又不穿外套》

男孩像一个随身百宝箱，止痛药、充电宝、雨伞、创可贴、饼干、胶带什么都有。女孩一边拿一边嫌他婆婆妈妈，最后说：“你能不能别什么都管？”他只回答：“好。”现在她淋雨、低电量、鞋跟断掉，翻遍包也找不到需要的东西；她输入“我到了”，又删除。

核心遗憾：她嫌他什么都有，后来才发现那是被照顾的形状。

### 04《现在和以后》

女孩想要当下的陪伴，男孩想先赚钱、换工作、存钱，为两个人换一个未来。他总说“等忙完这阵子”“很快了”。她问：“你说的以后，什么时候才算到？”男孩离职，女孩没有去送，只发“以后顺利”，他回复“你也是”。两人没有谁做错，只是想要的生活不在同一个时间。

核心遗憾：她要的是今天，他努力的是他们的明天；也许就是没有缘分，希望他很好。

### 05《已读之前》

从最后一条消息开始：他问“你最近还好吗？”女孩没有回复。不是不爱，而是失望太多，不知道从哪一句开始解释。他等了一天、一周、一个月，也没有继续发。多年后女孩重看聊天记录，仍没有补回那句迟到的解释；她一个人吃饭，自己剥虾，手被扎破后继续。

核心遗憾：两个人没有说过再见，但沉默本身就是结尾。

## 视觉与声音基调

- 现代城市真实空间：办公室、出租屋、餐馆、地铁、雨夜街道、旧楼和便利店。
- 自然或动机光，不使用明显梦境滤镜；以空间、服装、道具和声音区分现在与回忆。
- 中近景、手部特写和物件特写为主；镜头运动克制，只在关系发生变化时移动。
- 每集一个回收道具：虾、计算器、百宝箱、空工位/房屋资料、聊天记录。
- 现实与回忆切换保留动作、声音或构图锚点：剥虾声、雨声、手机提示音、充电宝插入声、办公室关灯声。
- 生活声优先于满铺配乐；关键停顿保留静默。

## 统一结尾原则

不使用强行哭泣、死亡反转或长篇总结。女孩在当下完成一个过去由男孩完成的动作，旁白轻轻确认：

- “后来我才知道，他不是喜欢剥虾。他只是记得我喜欢吃。”
- “我以前嫌他什么都有，后来才发现，我弄丢的是一个总能接住我的人。”
- “我想要的是现在，他给我的，是他以为我们会有的以后。”
- “我们没有说过再见。所以我用了很久，才知道那就是再见。”

## 待确认项

- 两人的姓名、年龄、城市是否明确。
- 同事到恋人的具体时长。
- 男孩离职原因：主动换工作、被裁、回家发展或创业。
- 最后一条消息的准确内容。
- 是否共享一个固定地点或声音，增强五集关联。
- 旁白保持女孩第一人称，还是进一步减少为字幕。
