# 《别嫌她唠叨》翻拍项目

## 目标

使用全新人物、服装和场景，忠实翻拍用户提供的故事与全部对白。原视频只用于内容、动作与节奏分析，不复用原演员画面。

## 已确认

- 平台：抖音
- 画幅：16:9
- 成片时长：115-120 秒
- 内容：保留全部对白
- 地域：当代中国普通城市
- 风格：写实生活电影感，表演克制自然
- 模型：MiniMax-H3
- 声音：H3 生成无可辨认对白的表演画面；剪映完成三人后期配音、字幕、环境声和混音
- 首次预算：25.75 元，不含失败重试

## 当前状态

`character_prompt_review`：剧本、人物、视觉规则和12个叙事分镜已确认；三张人物定妆图提示词已建立，等待用户确认。当前尚未生成图片或视频。
