### 文件1：顾川男声（VO_male）——用同一个男声，一次把下面 10 句连着念

```

够到的，只有空气。
到了，今天不堵。
我还在跟她说话。可副驾上，只剩下她没带走的东西。
你习惯了她在，就忘了她已经不在。
```

### 文件2：苏晓女声（VO_female）——1 句
剪映操作：新建文本 → 「文本朗读」选一个**明亮/温柔女声**（推荐：`元气少女` 或 `温柔淑女`）→ 导出。

```

```
