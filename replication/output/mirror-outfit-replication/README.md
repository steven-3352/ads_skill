## 最终结构

```text
睡醒拿手机
→ 手机选择黑色穿搭
→ 黑色卧室结果 + 户外照片
→ 手机选择白色穿搭
→ 白色卧室结果 + 户外照片
→ 手机选择深蓝穿搭
→ 深蓝卧室结果 + 户外照片
→ 拿手机和钥匙出门
```

## 最终采用的素材策略

- 主场景使用同一张无人物卧室背景母图。
- 黑、白、深蓝三套状态来自同一条 15 秒生成视频。
- 户外照片以该视频的三张稳定帧为唯一人物与服装参考。
- 视频只使用动作明确的短区间；照片用轻微推拉提高信息密度。
- 内部样片暂用原视频音轨作节奏参考，正式发布前必须更换为可商用音轨。

## 不再采用

- 镜面、镜框和反射关系。
- 分别生成三套长视频后直接顺序拼接。
- 仅靠文字要求不同任务生成“同一房间”。
- 用早期概念服装图派生最终视频状态的户外照片。
