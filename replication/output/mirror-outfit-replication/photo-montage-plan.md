# 户外穿搭照片蒙太奇

主线动作仍发生在固定卧室。户外照片是手机中的穿搭想象和换装后的效果回扣，不表示人物在卧室与户外之间连续瞬移。

## 照片组

| 文件 | 画面作用 | 建议成片时长 |
|---|---|---:|
| outdoor-black-01-full.png | 黑色机能风全身出街效果 | 0.35-0.55 秒 |
| outdoor-black-02-detail.png | 黑色面料与衣领细节 | 0.25-0.45 秒 |
| outdoor-white-01-full.png | 白色日常风明亮出街效果 | 0.35-0.55 秒 |
| outdoor-white-02-detail.png | 白衬衫袖口与轻松气质 | 0.25-0.45 秒 |
| outdoor-navy-01-full.png | 深蓝通勤风完整使用场景 | 0.4-0.6 秒 |
| outdoor-navy-02-detail.png | 最终穿搭确认与结果回扣 | 0.5-0.8 秒 |

## 剪辑方式

- 每张照片不要静止超过 0.8 秒。
- 全身图使用 103%-108% 的快速推进；细节图使用轻微横移或反向拉远。
- 黑、白两套各使用两张照片快速闪过，深蓝最终造型可以稍长。
- 照片切换落在音乐重拍，并叠加相机快门声或短促电子点击声。
- 户外照片与卧室人物镜头之间使用直接硬切、手机界面遮挡或 2-4 帧白闪，不使用长渐变。
