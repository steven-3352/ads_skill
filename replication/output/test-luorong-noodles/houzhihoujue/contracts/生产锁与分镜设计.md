## 1. 核心创意：同起点·不同选择·不同结果

这是全片的灵魂——**用具象行为把抽象金句演出来，同一个吵架起点，分岔出不同结局**：

```
        ┌── 你不哄 → 两人各自沉默僵住 ──→ 冷战
吵架起点 ┼── 你哄了·我不应 → 男伸手哄·女扭头 ──→ 较劲
        └── 你哄了·我笑了 → 男哄·女破功笑 ──→ 幸福
```

镜 1/2/3 **复用同一吵架起点的构图与机位**（重复画面），只让后续行为分岔——观众一眼看懂"就差一个哄、一个理"。

再叠双层对照：**过去是暖色双人日常，现在是黑底顶光孤身一人**——那个人已经不在了。冷暖一撞，遗憾成立。

## 2. 视觉双层

| 层 | 用途 | 光/色 |
|---|---|---|
| **过去·暖闪回** | 镜 1-6，两人居家日常演绎 | 居家顶灯明亮通透、自然暖白、真实肤质、iPhone 手持微动 |
| **现在·黑底顶光** | 镜 7 + 尾板，女主孤身独白 | 纯黑背景、头顶单束柔光、电影颗粒、浅景深 |

全片统一：**无油光无蜡感无 AI 塑料感，光染环境不染脸，人脸哑光漫射**。

## 3. 台词与 VO 核算（正常偏快 ~4.5 字/秒）

念白合计 ≈ 17.4s + 尾板定格 ≈ **成片 20-22s**。VO 一条连续铺满，无静默死尾。

## 4. 分镜（7 镜 + 尾板；边说边演）

### 镜 1 · 冷战｜暖闪回｜0–2.5s｜FL2VA
- VO：**你不哄，我不理，这就是冷战**
- 画面：居家沙发两端，女背对生闷气坐一头，男坐另一头也不看她，中间空一段距离，各自沉默
- 状态：吵架起点 → 双方都不动，僵住（首帧吵架后 / 尾帧各占一角冷掉）

### 镜 2 · 较劲｜暖闪回·复用镜1构图｜2.5–5s｜FL2VA
- VO：**你哄了，我不应，这就是较劲**
- 画面：**同场景同机位**，男这次凑过去伸手碰女肩想哄，女把肩一缩、扭头不应
- 状态变化：男主动哄（伸手）→ 女不应（缩肩扭头）

### 镜 3 · 幸福｜暖闪回·复用镜1构图｜5–7.5s｜FL2VA
- VO：**你哄了，我笑了，这就是幸福**
- 画面：**同场景**，男继续哄（做鬼脸/挠痒/递零食），女绷不住扑哧一笑，身体转回靠近男
- 状态变化：女破功笑 → 两人靠拢

### 镜 4 · 心疼｜暖闪回｜7.5–10s｜FL2VA
- VO：**我委屈，你服软，这就是心疼**
- 画面：女低头抹眼角、肩膀微塌显委屈，男心软上前轻揽入怀、让步
- 注意：委屈走低头抹眼角/男揽入怀，**不写泪光/红眼/发光眼**

### 镜 5 · 迁就｜暖闪回｜10–12.5s｜I2VA
- VO：**我唠叨，你点头，这就是迁就**
- 画面：女指着什么碎碎念叨，男耐心笑着连连点头听
- 状态：女唠叨 → 男包容点头

### 镜 6 · 以为还有以后｜暖转冷｜12.5–15s｜I2VA
- VO：**以前我以为，还有以后**
- 画面：两人依偎的暖色画面，镜头极慢，暖光开始褪色/边缘虚化，暗示这是回不去的回忆

### 镜 7 · 那个人不在了｜现在·黑底顶光｜15–19s｜I2VA
- VO：**现在懂了，可是那个人，已经不在了**
- 画面：**切现在时黑底顶光，女主独自伫立**，身旁那个位置空荡无人，低头、屏息、慢眨
- 全片冷暖对照最强点；**严禁泪眼/红眼/发光眼**，坠落走抿唇+屏息+慢眨+缓低头

### 尾板 · 后知后觉｜黑底渐暗｜19–22s
- 无 VO（留一口气）
- 字幕淡出（设计性大字，非对白轨）：**有些遗憾，后知后觉**
- 光束缓缓变暗，渐黑收尾

## 5. 人物母板需求

1. **女主身份母板**：30-35 岁东亚女性，成熟隐忍气质，一套身份 → 派生暖色居家便装 + 现在时黑底顶光两种呈现
2. **男主身份母板**：东亚男性，与女主匹配年龄，居家便装，温和
3. 先出母板认可 → 各镜 --reference 母板生关键帧（masters-before-shot-keyframes）

## 6. 关键避坑

- **发光眼**：所有情绪镜绝不写 tears/red/glowing/泪光；委屈坠落走低头/抹眼角/屏息/慢眨
- **蜡感**：文生图母板 + H3 提示词双线写真实肤质/哑光/电影颗粒，压塑料感
- **复用起点**：镜 1/2/3 首帧共用同一"吵架起点"构图机位，只改后续动作 → 强化"同起点不同果"
- **字幕**：VO 无对口型，成片不烧对白字幕；尾板大字是设计元素；H3 生成后逐镜查是否自烧字幕
- **无品牌**：居家道具无 logo，零食/物件用无标泛化外观
- **居家光**：闪回场景顶灯开、明亮通透，别单盏暖黄压暗（scene-lighting-normal-not-moody）
- **音频**：闪回镜 H3 出环境音（居家氛围），VO 独白由豆包 seed-audio 单独一条，后期铺满全片；无静默死尾

## 7. 生产流水（阶段锁）

1. **母板**：女主 + 男主身份母板（文生图）→ 认可
2. **关键帧**：镜 1-7 首/尾帧文生图（锁 768×1344 竖屏；镜1/2/3 复用起点构图）
3. **H3 提示词**：全部用 h3-prompt-writing 技能（指令行 + 三核心字段；闪回镜无对白只出环境音，状态变化动作用 FL2VA 摆落点逐动词）
4. **VO 配音**：豆包 seed-audio 生成独白一条，正常偏快、隐忍克制
5. **生视频**：金丝雀验通路 → 并行付费生成
6. **装配**：ffmpeg 拼接 + VO 铺底 + 尾板叠字 → final/ 挂公网 ads-review
7. 每步出公网 HTML 交人工看，视频效果人工确认
