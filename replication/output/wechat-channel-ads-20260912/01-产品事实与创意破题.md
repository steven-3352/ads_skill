# 第一阶段：产品事实与创意破题

## 统一策略

这批商品横跨家居、健康科普、冲调食品、身体护理、茶饮和宠物护理，不能套同一种“痛点口播”。六条广告统一采用一个原则：**先让观众看见一个问题被解决，再让商品名称和事实卖点出现。**

默认受众按视频号观看习惯处理：信息要看得懂、动作要真实、产品要出现得早；不过度追逐年轻化网络梗，也不做中老年电视购物式吆喝。

资料图片只作为产品事实与商品外观依据，不把图片里的营销话术自动视为已证实事实。本阶段未引入未经核验的网络信息。

**一句话概念：** 花洒像一辆总停错位的车，一按、一转，终于停进最顺手的“专属车位”。

**核心戏剧动作：** 手反复追着乱摆的花洒，随后把吸盘支架按上墙面；花洒卡入、转向、稳稳对准。

**15 秒结构核：** 失控 3 秒 → 安装 4 秒 → 调角度 4 秒 → 使用结果与商品落版 4 秒。

**备选方向：**

- `给爸妈调到刚刚好`：成年子女安装，父母伸手即可够到；情感更温和，但人物成本更高。
- `浴室不打孔改造`：租房浴室一秒前后对比；转化直接，但创意辨识度较弱。

### 禁用或待举证

不得擅自使用“任何墙面都能吸”“永久不掉”“超强承重”“适合所有花洒”等绝对化表述。

### 卖点优先级

1. 把难读的指标和日常选择整理成可查、可执行的信息。
2. “红绿灯食物指南”具有天然、直观的视觉记忆点。
3. 覆盖看报告、吃什么、怎么运动、识别误区等多个生活决策。

### 核心受众

- 第一受众：体检后拿到血脂报告，却不知道从哪里开始了解的人
- 第二受众：替父母筛选通俗健康科普资料的成年子女
- 补充受众：希望系统整理饮食、运动和复查问题的人

### A 线候选：把血脂知识变成看得懂的视觉规则

**一句话概念：** 把抽象的血脂知识放进观众熟悉的交通、任务或可视化系统中，让原本难理解的信息通过规则、比喻和画面变化变得直观好玩。

**内容推进：** 一个抽象问题先以难懂状态出现；书中知识启动可视规则；信息依次被分类、比较或完成任务；结尾回到真实书页和可查工具。交通灯只是候选语法，最终比喻必须与书中实际内容一致，不能把视觉隐喻冒充医学证明。

**项目案例接口：** 可参考“红灯停绿灯行”的熟悉规则压缩、“多角度记录”的信息可视化、“教程/任务验收”的知识拆解，只继承规则、观众角色和升级结构，不复制案例人物、造型、界面或音乐。

**观看奖励：** 观众不是被告知“这本书很有用”，而是在片中真正看懂一个以前模糊的知识点，同时记住这本书把复杂内容讲直观。

### B 线候选：家里常备的一本工具书

**一句话概念：** 体检报告放在桌上，家里人都想关心，却谁也说不清；一本常备工具书让他们先把问题理清，再把该问医生的话写下来。

**关系与问题：** 可以是成年子女和父母，也可以是夫妻。冲突来自“都在关心，但一个不想让人担心，一个不知道怎么问”，不是靠恐吓疾病或争吵制造戏剧。

**内容推进：** 报告出现 → 家人一句日常对话暴露信息差 → 翻书查找 → 圈出要问的问题或整理日常选择 → 书回到家中固定位置，形成“常备、随手可查”的生活角色。

**项目案例接口：** 可参考历史情感项目对物件、关系和潜台词的处理方式，继承“一个物件承载未说出口的关心”和声音缝合，不复制原故事人物、台词、关系结局或场景。

**观看奖励：** 观众认出家庭里“不知道怎么关心才合适”的处境，并看到一个克制、可执行的问题解决过程。

### A/B 选择标准

- A 线更适合扩大停留、知识传播和品牌化表达，关键验证是比喻是否准确、首屏是否立即看懂、奇观是否与书的内容有关。
- B 线更适合视频号家庭受众、信任建立和工具书购买理由，关键验证是关系是否真实、对话是否自然、书是否真正参与解决问题。
- 两线没有预设优先级。进入 `screenwriting-master` 后分别完成概念与梗概，再结合目标受众、目标时长、生成稳定性和首次成本推荐。

### 禁用或待举证

不承诺降血脂、防治疾病或替代医生；不制造“某指标等于突发疾病”的恐慌。作者资质、粉丝量、播放量、三年创作周期在用于广告前需完成证据归档。

- 补充受众：偏爱杏仁、银耳和谷物风味的人

### 推荐破题：杯子里的早班

**一句话概念：** 清晨还没完全醒，粉、热水和勺子先在杯中“上班”，把一杯细滑早餐叫醒。

**核心戏剧动作：** 粉落下、热水冲入、旋涡形成、勺背带起稠润挂壁；画面从冷清变得温暖。

**形式：** 微距食欲镜头 + 声音放大。主角不是人物，而是粉末、热水和稠度的可见变化。

**15 秒结构核：** 清晨空杯 2 秒 → 冲调微距 7 秒 → 入口前的质感停顿 3 秒 → 包装与事实卖点 3 秒。

**备选方向：**

- `四种口感被一勺叫醒`：细、香、滑、糯依次用材质动作表现；视觉明确，但需避免模型生成文字。
- `早餐不用赶，热水会完成`：用时间压缩呈现忙碌早晨；效率卖点更强，产品气质略普通。

### 禁用或待举证

不使用美白、养颜、减脂、降血脂、代餐减肥等功效。40%、三个 0 添加、18.5 g 膳食纤维等数据必须以实际销售包装和检测材料复核后才能上片。

### 禁用或待举证

不使用治疗关节、止痛、消炎、活血、药膏、修复损伤等医疗表达。“千万瓶销量”“快速舒缓”等内容需证据。温热、清凉或刺激感必须与中文标签和实际体验一致。

### 卖点优先级

1. 加长喷嘴穿过毛发、对准目标位置，是最强的结构性演示卖点。
2. 不需要大面积处理毛发，操作过程更直观。
3. 细雾与局部喷洒可通过真实特写表现。

### 核心受众

- 第一受众：长毛猫犬或毛发较密宠物的主人
- 第二受众：希望局部护理操作更精准的养宠家庭
- 补充受众：不希望为了局部护理剃毛的主人

### 推荐破题：穿过毛发迷宫

**一句话概念：** 普通喷雾停在“毛发森林”外，加长喷嘴沿着一条路穿过去，把护理动作送到目标位置。

**形式：** 宏观宠物实拍 + 微距尺度跳跃。用喷嘴是否到达目标来证明结构，不用旁白声称治疗结果。

**15 秒结构核：** 表层喷不到 3 秒 → 长嘴穿过 5 秒 → 局部喷洒演示 4 秒 → 产品与使用提示 3 秒。
