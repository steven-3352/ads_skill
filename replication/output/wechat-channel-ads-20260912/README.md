# 视频号六商品广告项目

## 项目目标

根据 `/Users/wmzuo/Desktop/视频号广告/` 中的 28 张商品资料图，为六个商品分别开发一条视频号带货广告。

## 制作规格

- 每个商品一条独立竖屏广告
- 画幅：9:16
- 最终成片时长：最短 15 秒、最长 120 秒；单个分镜、镜头或生成单元可以更短
- 风格：视频号信息完整度 + Social-first 开场钩子
- 内容要求：六条都必须具备可拍的内容框架并经过 `screenwriting-master`；可以是人物故事、好玩规则、幽默观察、视觉奇观或感官过程，但必须有观看入口、推进和兑现，禁止纯展示、纯卖点口播和伪对话硬广
- 中文、价格、参数等事实文字统一后期确定性添加，不交给视频模型生成
- 低预算只减少镜头与生成次数，不降低创意和成片标准
