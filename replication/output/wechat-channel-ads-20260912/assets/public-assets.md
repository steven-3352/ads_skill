## L1 通用层(六商品共享)

### 0. 视觉语言 / 拍摄风格(全项目基调 · 用户 2026-09-15 锁定)
- **iPhone 17 手持拍摄质感 · vlog 形式**:自然光、轻微手持呼吸感、生活流,像家人被随手记录下来,不精致影棚感、不刻意运镜。
- **景别:中景 / 中远景为主,少用近景**。人物尽量带环境(桌、窗、居家背景)。
- 近景/凑近镜**仅在必要兑现处使用**,且以 vlog 式"手机随手怼近看一眼"的方式呈现,不做电影级微距。
- 手持感适度(轻微晃,不眩晕);对白与生活拟音是主要质感来源。

### 1. 技术规格(硬约束)
- 画幅:16:9(本项目用户锁定);gpt-image-2 的 16:9 标准档实际输出 **1280×720**(比例正确,喂 H3 不变形);请求时传 `--size 1344x768`,模型规约到 1280×720。避免非 16:9 静帧被 H3 拉伸(记忆 gpt-image-h3-aspect-mismatch-distortion)
- 生成模型:MiniMax-H3;提示词技能 h3-prompt-writing;图片走文生图(generate-image.sh,禁 img2img 肖像磁吸)
- 对白镜:中文对白直出配音 + 烧录中文字幕即达标(记忆 h3-dialogue-native-subtitle-is-standard)
- 状态变化镜:FL2VA 锁首尾帧(记忆 fl2va-for-state-change-actions)

### 2. 选角池(Cast Pool · 一个中国家庭)
> 全部 **East Asian / 中国人**,文生图提示词首要素显式锁死人种与年龄,禁欧美脸(记忆 daihuo-casting-must-be-chinese)。**每个人先出一张"人物母板"作身份锚点,后续所有镜头关键帧 `--reference` 母板锁同一个人**(记忆 keyframe-anchored-pipeline-higher-hitrate / wechat-01-two-keyframe-trees)。
- **C-OM 老先生(本片男主)**:中国男性,58 岁上下,短寸微白发,方脸,肤色偏暖,眉眼温和;家常打扮(深色棉麻立领/polo)。身份锁词:`Chinese elderly man, ~58, short greying hair, square kind face`。母板文件:`assets/masters/master-C-OM.png`(✅ 已生成 v1,五视图)
- **C-OF 老太太(本片女主)**:中国女性,55 岁上下,齐耳微卷短发略染,圆润和气,家常针织开衫。身份锁词:`Chinese elderly woman, ~55, short permed hair, gentle round face`。母板文件:`assets/masters/master-C-OF.png`(✅ 已生成 v1,五视图)
- (预留)C-YM 中年子女 / C-K 孙辈 —— 其他商品需要时再追加,不在 05 出现。

### 人物母板规格(先于任何镜头关键帧生成)
- 形式:**角色五视图设定表(character turnaround sheet)**——同一个人半身像(腰以上)按 **正面 / 左3⁄4 / 正侧 / 右3⁄4 / 背面** 五个角度横向排布在一张图内。
- 要求:**同一个人、同一套家常服装、中性平和表情、双臂自然下垂、均匀柔光、干净中性浅灰背景**(便于作纯净身份参考,不带场景污染);看清五官与发型轮廓。
- 用途:六商品共用的身份根;各镜关键帧用 `--reference master-*.png` 渲染,任意机位都锁同一个人(脸型/发型/身形/年龄一致)。
- 文件:`assets/masters/master-C-OM.png`、`assets/masters/master-C-OF.png`(不进 git,记忆 no-media-in-repo)。

### 3. 场景库(Scene Bank)
- **SCN-tea-table 家中茶桌(本片用)**:午后居家,原木小茶桌,自然侧光从窗进,背景虚化的居家暖调(木色/布艺),不豪华、有生活感。禁:品牌门店、影棚白背、包装堆头。
- (预留)SCN-kitchen 家用厨房台面 / SCN-living 客厅沙发角 —— 其他商品按需追加。

### 4. 统一调色 / 光(Grade)
- 基调:自然暖光,略暖白平衡,中低对比,肤色健康不蜡黄;高光柔、阴影通透。
- 一致性:六片同一 LUT 基调,保证跨片"同一个家、同一种光"。避免忽冷忽暖。

### 5. 音频基调(Audio Bed)
- 环境:安静居家室内底噪(极低),真实生活拟音优先(啜饮、注水、器物轻碰)。
- 音乐:极轻或留白,不抢对白与拟音;响度归一 -16-- -18 LUFS。
- 对白:H3 直出中文配音,自然口语,不念稿腔。

### 6. 通用红线(全项目)
- 不出现包装、品牌字样、礼盒/罐体特写(除非某商品单独另定)。
- 选角必须中国人;不做功效承诺;宣称守各商品 01 事实卡边界。

## L2 本片实例(05 广宝福黄金陈皮《这味儿对了》)

### 参演
- 男主 = C-OM;女主 = C-OF。老两口对坐,家常关系,潜台词"早说过"。

### 场景
- SCN-tea-table。同一张桌、同一光位贯穿 S01–S05;S01 与 S04 男主同轴正打(同侧机位)。

### 道具(Props · 本片锁定,跨镜一致)
- **PR-glass 透明玻璃杯 ×2**:直身无花纹,便于看清汤色由清黄→琥珀。
- **PR-peel 大陈皮**:大片、卷曲、沟壑纵横的干燥果皮(料好可视);S02 给纹理近景,S05 落幅同框。按事实=大片干果皮,禁写十年陈/产区/年份。
- **PR-dish 白瓷小碟**:盛放散放的几片大陈皮(无包装、无罐)。
- **PR-pot 家用茶壶**:S03 注水用。
- 汤色事实锚:清淡黄 →(注水舒展)→ 琥珀色;**禁夸成浓黑**。

### 需要生成的关键帧清单(下一步付费,先报价)
> 生成分两阶段:**① 先出人物母板(身份根)→ 认可 → ② 各镜关键帧全部 `--reference` 母板**。全部 iPhone vlog 手持质感、16:9、1344×768。景别以中景/中远景为主;仅 S03 一个凑近镜。

**阶段② 镜头关键帧(均 --reference 对应母板)**
