# 05 广宝福 10陈黄金陈皮 5A《一片展开的时间》· 拍摄脚本(逐镜 verbatim 事实源)

> 由 03-六商品详细内容脚本.md 已锁定 5A + 01-产品事实卡(索引62-66)落成。
> 形式定位:**微距·尺度奇观·感官片**。一片卷曲陈皮在水中舒展,纹理放大成"折叠地图",尺度在幻想与现实间缩放。
> 与 03《清晨开场乐》同为感官片,但武器完全不同:03=声音节拍ASMR/单一厨房/暖;05=微距尺度奇观+快慢对比+冷调忙乱→暖调茶汤的调色转变。必须拉开,绝不重复。

## 关键三要素
- **钩子**:开场是"急促"——手机连续亮起、手翻文件、杯子被推开;一旦玻璃罐打开,环境声骤然收窄,只剩干皮摩擦声。听觉上的"从吵到静"就是钩子。
- **卖点(为什么买)**:开罐→取皮→注水→舒展→出汤的完整质感链;大片果皮、琥珀汤色、玻璃罐/礼盒陈列——全部是资料图可支持的外观卖点。买点靠"一片卷皮舒展成琥珀茶汤"的可见变化兑现,不靠旁白。
- **情绪**:从急促到从容的治愈,叠加尺度奇观的惊叹。让观众跟着"慢下来"。

## 驱动四层
主引擎=尺度变化/视觉奇观(卷→展、微距放大如地图、幻想尺度缩放);动力=快慢节奏对比(忙乱快剪→微距慢镜)+冷暖调色转变;点睛=收尾字幕(全片无对白、无人声,保持纯感官);缝合=陈皮从紧卷到舒展这条形变主线+声音由吵到静。氛围服务于主引擎,不单独驱动。
