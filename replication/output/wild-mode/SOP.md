# AI 动物变商品时尚短片 SOP

## 1. 适用范围

用于制作以下结构的 10-20 秒竖屏短片：

```text
真实主体 A
→ 可辨认的机械中间态
→ 完整商品 B
→ 多个结果快速确认
→ 最终使用者/场景回扣
```

主体不一定是动物，商品也不一定是服饰。可迁移到食材变厨具、矿石变首饰、植物变香氛、交通工具变电子产品等主题。前提是 A 与 B 之间存在可解释的形态、结构、材质或动作映射。

本流程不让一个视频模型完成整条故事，而是把高风险任务拆成稳定单元，再由剪辑重建速度、音乐、因果和完整感。

## 2. 三条成功原则

### 2.1 一条生成任务只解决一个困难

- 图片任务只锁定一个状态：自然态或商品态。
- 视频任务只完成一次连续变形。
- 人物使用、结果证明、卡点和收尾由独立素材或后期完成。
- 不要求模型同时维护人物脸、手部接触、五件商品、复杂运镜和空间连续性。

### 2.2 用锚点链传递一致性

```text
空间母图
→ 自然态首帧 A
→ 在 A 上局部替换得到商品态尾帧 C
→ A+C 生成变形视频
→ 从已通过状态派生人物结果图和剪辑素材
```

不要分别凭文字独立生成 A 和 C。即使提示词相同，独立生成也会改变桌面、机位、光线、主体位置和透视。

### 2.3 AI 负责奇观，后期负责广告

- AI 擅长：材质重组、折叠、展开、机械结构、局部运动、短时奇观。
- AI 不稳定：长连续剧情、多人关系、真人身份、手部穿戴、反射、精确文字、跨镜头商品一致性。
- 后期负责：删等待帧、卡音乐、速度递进、结果特写、统一调色、音效、扫描效果和结尾句号。

## 3. 前期创意拆解

### 3.1 建立映射表

每个变形必须先填写：

| 字段 | 要求 |
|---|---|
| 起点主体 | 一个清楚、熟悉、可一眼识别的对象 |
| 目标商品 | 外形完整、可使用、可商业化的商品 |
| 形态映射 | 至少 2 个能直接看见的轮廓对应 |
| 结构映射 | 至少 2 个可以折叠、旋转、滑动或锁定的部件对应 |
| 材质映射 | 起点颜色/纹理如何转成商品材料 |
| 数量逻辑 | 一个变一个，或两个变一双，不能中途增殖 |
| 观众奖励 | 最终商品为什么意外但合理 |

本案的主要映射：

| 起点 | 商品 | 主要映射 |
|---|---|---|
| 两只黑豹幼兽 | 一双鞋 | 四肢→鞋面支撑，脊柱→鞋底，尾部→导轨 |
| 甲虫 | 手表 | 背甲→表圈，核心→表盘，足部→表带链节 |
| 蜻蜓 | 墨镜 | 复眼→镜片，翅膀→镜腿，胸部→鼻梁结构 |
| 蛇 | 皮带 | 长形身体→带身，鳞片→分节，头部→带扣 |
| 隼 | 帽子 | 翅膀→帽冠面板，羽毛→叠片，身体方向→帽檐 |

如果只能解释为“它们都很酷”，映射尚未成立，不要进入制作。

### 3.2 锁定统一视觉系统

在生成任何单品前确定：

- 画幅、时段、空间、机位、焦段感和主体占比。
- 主色、点缀色、金属色和不可出现的颜色。
- 商品共同材料语言。
- 人物何时出现，以及哪些镜头禁止出现人物。
- 禁止品牌、Logo、文字、IP 特征和多余道具。

本案使用明亮晨间更衣室、暖白与石灰岩、石墨黑桌面、钴蓝点缀、香槟银结构。每条变形都发生在同一桌面上。

## 4. 关键帧生产

### 4.1 将关键帧分三级

1. **风格锚点**：最终人物造型、空场景母图，确定全片颜色与空间。
2. **设计图**：A/B/C 三阶段设计板，只用于确认映射和造型。
3. **生产帧**：单一自然态 A 和单一商品态 C，作为 Seedance 首尾帧。

设计板不能直接作为视频首帧，否则模型容易生成拼贴、分屏或同时出现多个时间状态。

### 4.2 先做自然态首帧 A

提示词依次写：资产用途、每张参考图的单一职责、主体数量、完整轮廓、位置与占比、空间与机位、自然态约束、禁止项。

```text
用途：合成。资产类型：9:16竖屏首帧生产关键帧。
图片1只提供[主体外观/颜色/姿态]，图片2只提供[固定空间、桌面和晨光]。
生成一张普通单机位照片，不是拼贴、三联画、分镜或分屏。
画面中严格只有[数量]个[主体]，完整可见，位于[位置]，朝向[方向]，
占画面[百分比]，周围保留充足空间。固定[机位]，[焦段]镜头感。
保持图片2的建筑、桌面、光向、阴影、曝光、景深与配色。
当前是完全自然状态，不出现机械结构或变形效果。
禁止[目标商品]、额外主体、人物、手、镜子、反射、发光、火花、文字、
品牌、Logo和水印。避免近距离裁切、暗黑赛博和多个时间状态。
```

### 4.3 尾帧 C 必须由 A 局部替换

这是本案最重要的成功率措施：把已通过的 A 设为不可变编辑底图，另一张图只提供商品设计，只替换中央主体。商品继承 A 的位置、方向、视觉占地和数量关系。

```text
用途：精确物体编辑。资产类型：与首帧严格匹配的9:16尾帧生产关键帧。
图片1是不可变底图和编辑目标；图片2只提供已确认的[商品]设计。
仅把图片1中央的[起点主体]替换为[数量]个完整[商品]，位置、方向、
占地和尺度与原主体一致。
保持图片1其余所有视觉属性：空间、桌面、衣柜、门洞、机位、裁切、
透视、阳光、阴影、曝光、景深和颜色不变。
[列出商品的3-5个不可改变设计特征]。
这是完成后的商品状态，不存在进行中的特效。
禁止原主体残余、额外商品、人物、手、镜子、反射、发光、火花、文字、
品牌、Logo和水印。禁止改变背景、桌面、相机、构图和照明。
```

### 4.4 首尾帧几何验收

- 分辨率和画幅完全相同。
- 桌面边缘、门框、衣柜和主阴影位置基本重合。
- 主体中心点偏差不超过画面宽度约 5%。
- 主体视觉占地接近。
- 数量守恒。
- A 不提前出现机械结构，C 不残留动物器官。
- 两帧都不是拼贴、设计板或多状态画面。

不通过时只重做关键帧，不要用视频提示词补救错误端点。

### 4.5 最终人物图最后做

先确认全部商品尾帧，再生成最终人物造型。将商品尾帧中的产品裁图作为唯一产品真值；如果人物图已经生成，则逐项做局部精确替换。

必须检查鞋、表、眼镜、皮带和帽子是否与商品尾帧一致。本案早期人物图与离场图的鞋存在差异，最后通过剪辑裁切规避；以后应在关键帧阶段消除。

## 5. Seedance 变形视频

### 5.1 请求模式

- 使用 Seedance 2.0 mini。
- 默认 5 秒、9:16、720p、生成音效、不加水印。
- 使用 `first_frame + last_frame`，不要混入参考媒体。
- 首尾帧模式不要发送 `camera_fixed`；将固定机位写进提示词。
- 本地首尾帧由通用脚本临时转换，JSON 不写死公网 URL。

```json
{
  "duration": 5,
  "ratio": "9:16",
  "generate_audio": true,
  "watermark": false,
  "resolution": "720p",
  "content": [
    {"type": "image_url", "local_path": "path/to/state-a.png", "role": "first_frame"},
    {"type": "image_url", "local_path": "path/to/state-c.png", "role": "last_frame"}
  ],
  "prompt": "..."
}
```

### 5.2 五秒分时提示词模板

```text
5秒，9:16竖屏，[风格与景别]，@图片1严格作为首帧，@图片2严格作为尾帧。
全程固定机位，[空间、桌面、光线、阴影、景深和构图]完全不动，
只允许中央主体变化。

0-0.7秒：[自然主体]安静保持原位，只允许一次呼吸、眨眼或触角动作。

0.7-3.9秒：完成清晰、连续、无痛的三阶段机械变形。
[外层材质]沿结构分片开启，露出[内部机械材料]；原主体轮廓短暂保持可辨认；
[部件1]折叠为[商品部件1]，[部件2]旋转/展开为[商品部件2]，
[部件3]滑动/收束为[商品部件3]。所有零件只做精密开启、折叠、旋转、
滑动、对齐和锁定，不融化、不液化。

3.9-4.6秒：完成最后一次对位，锁定为@图片2中的完整商品。
4.6-5秒：商品静止，光线扫过关键材质，保持清楚可用的商品外观。

声音：[自然态轻声]；变形阶段使用齿轮、伺服、滑轨和金属链节声；
完成瞬间使用一次干净锁定声；无人声、无夸张音乐。

必须保证主体安全、无痛、无伤口，变形是工程结构重组。
不要切镜、推拉摇移、镜头抖动、改变背景、增加人物或手。
禁止数量变化、肉体压缩、血肉、骨骼、断裂、液体融化、烟雾遮挡、
爆炸、能量光圈、魔法粒子、文字、品牌、Logo和水印。
```

### 5.3 提高成功率的提示词写法

- 使用可执行机械动词：开启、折叠、旋转、滑动、伸展、收束、对齐、锁定。
- 明确 3-5 个部件映射，不只写“变成商品”。
- 先保持原轮廓，再逐步重组，避免直接跳变。
- 给最终商品预留约 0.4 秒静止展示。
- 固定背景时列出不可变对象，不只写“背景不变”。
- 用“只允许中央主体变化”建立唯一变化区域。
- 同时写正向动作和反向禁止，防止模型用融化、烟雾、粒子逃避结构变化。
- 不要求变形过程中出现人物接触；穿戴关系由结果图证明。

## 6. 自动生成与验收

### 6.1 生成命令

```bash
replication/tools/generate-video.sh \
  --prompt path/to/video-prompt.json \
  --output-dir path/to/videos \
  --output-name item-task.json \
  --wait \
  --download
```

先生成一个简单单体和一个数量复杂的样本。本案先验证甲虫→手表与双黑豹→双鞋；规则稳定后，再批量提交其余单元。

### 6.2 自动验收标准

1. 首帧主体数量、姿态和环境正确。
2. 0.7 秒前没有提前变形。
3. 中间至少有一段能同时认出原主体和机械结构。
4. 变化主要是折叠/旋转/滑动，不是融化或烟雾遮挡。
5. 背景、桌面边缘、机位和主光方向稳定。
6. 尾帧商品数量正确、结构完整、可使用。
7. 没有额外人物、手、动物、商品、文字或 Logo。
8. 没有伤口、身体恐怖、明显穿模和断肢观感。
9. 生成音效存在，完成点有可用的锁定声。

抽取 0、0.7、1.5、2.5、3.5、4.3、4.9 秒帧制作接触表。

必须重做：数量错误、目标商品错误、背景/相机明显跳变、没有机械中间态、出现不安全画面、商品不完整。

可以后期修正：短暂轻微蓝光、一两帧纹理漂移、节奏偏慢、音效过响。不要因可剪掉的小问题反复生成。

## 7. 剪辑与后期

### 7.1 不按生成时长剪

5 秒是生成稳定性容器，不是成片必须使用 5 秒。先删除等待帧，再按信息变化剪辑。

```text
空间建立 0.5-0.7秒
→ 第一条变形 2.2-2.4秒，教会观众规则
→ 后续变形每条 1.8-1.9秒，逐步加速
→ 配饰结果闪切 0.2-0.3秒/张
→ 完整人物 0.8-1.3秒
→ 离场 1.0-1.5秒
→ 视觉闭合与黑场 0.5-0.9秒
```

### 7.2 声音层级

- 以有权使用的背景音乐为主轴，先检测 BPM 和重拍。
- 将变形原声高通到约 250-300 Hz，音量降到 0.18-0.24。
- 在商品锁定点保留磁吸、卡扣或伺服声。
- 最后一拍增加独立低频锁定声。
- 使用限制器控制峰值，避免音效盖住音乐。

### 7.3 视觉包装和结尾

- 统一对比度、饱和度和冷暖关系，修正不同生成任务的色差。
- 只使用轻微颗粒、暗角和锐化，不用重滤镜掩盖素材问题。
- 结果闪切使用 1-2 帧白闪；过长会像空白帧。
- 扫描线和定位框只在“系统完成”阶段出现。
- 无品牌片不强加文字标签。
- 结尾必须完成“商品确认→完整状态→主题回扣→离场→音画停止”。

本案 V2 使用机械扫描、近景背影离场、孔径闭合、金属锁定音和 0.13 秒黑场形成句号。

## 8. 无人干预运行规则

创意母题、商品清单、画幅、时长、禁用项、模型和费用范围明确后，代理可连续执行：

- 自动选择首尾帧模式。
- 对失败关键帧局部重做，不推翻已通过素材。
- 生成接触表并依据统一标准验收。
- 将慢素材加速剪辑，不因成片慢而重做视频。
- 使用已有结果图补人物特写和最终证明。
- 保留上一版，输出递增版本号。

只有以下情况中断：商品真值缺失或冲突；真人认证、隐私或版权阻止生成；费用将明显越界；创意改变为新故事、新商品或新受众。

## 9. 常见失败与修正

| 失败 | 根因 | 修正 |
|---|---|---|
| 首尾帧空间不同 | 两帧独立生成 | 在首帧上局部替换得到尾帧 |
| 视频出现拼贴 | 把三联设计图当生产输入 | 拆成单一 A/C 生产帧 |
| 中间直接闪成商品 | 没有部件映射 | 写出3-5个部件对应及动作顺序 |
| 出现烟雾、粒子或融化 | 模型逃避结构变化 | 限定机械动词并列反向禁止 |
| 数量增殖 | 首尾数量逻辑含糊 | 三处重复准确数量 |
| 人物或手变形 | 同时要求复杂穿戴 | 变形无人化，结果图证明穿戴 |
| Seedance 返回400 | 首尾帧和参考媒体混用 | 两种模式二选一 |
| mini 拒绝参数 | 首尾帧模式发送 `camera_fixed` | 删除字段，提示词写固定机位 |
| 成片节奏慢 | 直接使用5秒素材 | 删除等待帧并加速到1.8-2.4秒 |
| 结尾不完整 | 只有离场 | 增加完整状态、锁定、声音和短黑场 |

- 图片工具：`replication/tools/generate-image.sh`

- 关键帧与提示词：`replication/output/wild-mode/keyframes/`、`prompts/`

复用时保留方法和检查规则，替换主题、主体、商品、映射、空间与视觉系统，不复制本案动物、服装或具体设计。
