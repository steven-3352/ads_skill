# 源片分析｜镜前选择器换妆视频

## 文件信息

- 本地文件：`source-reference.mp4`
- 时长：23.797 秒
- 画幅：720 × 1440，竖屏 1:2
- 视频：H.264，约 60fps
- 音频：AAC，44.1kHz，双声道
- 分析目的：保留源片的观看机制，改造成无品牌男生服装换装版

## 一句话机制

手机中的选择动作控制镜子里的现实人物。手机负责提出选择，点击负责触发，镜子负责给出结果，爱心/白闪/遮挡负责掩盖跳切。

## 视觉规则

### 必须保留

- 竖屏构图和固定镜面空间
- 镜面画面与手机画面交替
- 手机选择先于服装变化
- 点击动作和变化结果之间的因果关系
- 每次变化都使用短促反馈，而不是慢速溶解
- 最终造型展示时间最长

### 本项目明确删除

- 源片平台 Logo、账号名、抖音水印
- 搜索框、平台片尾和任何可识别品牌界面
- 真实美妆应用名称
- 商品价格、购买按钮、品牌文案

## 镜头与构图

- 镜面段：固定正面中景，镜子位于中央，人物约占镜面高度 55%–70%。
- 手机段：手机竖直，屏幕占画面主体，手指从侧下方进入；可用实拍录屏或后期合成。
- 最终展示段：仍保持镜面正面关系，只允许轻微侧转和小幅推进，不做夸张运镜。
- 背景：浅色方格墙面/浴室或卧室，冷白晨光；所有镜面段必须使用同一背景参考图。

## 剪辑机制

源片的核心剪辑不是特效数量，而是“动作闭环”：

```text
浏览 → 点击 → 点击音 → 白闪/爱心/手机遮挡 → 镜中换装 → 短暂停留
```

男生版每次换装建议拆成两个视频片段，在剪映中完成硬切：

```text
遮挡前片段 → 0.05–0.12 秒白闪或遮挡 → 遮挡后片段
```

不要依赖 AI 生成连续换装，以免脸、手和衣服细节漂移。

## 声音规则

- BGM：轻快、时尚、鼓点清晰的电子节拍。
- 滑动：短 whoosh，音量低于点击音。
- 点击：每一次选择必须有明确 click/pop。
- 换装：白闪可配短促上扬音或轻 hit。
- 最终拍摄：camera shutter + 极短闪光音。
- 不使用源片中可识别的品牌音频或平台提示音。

## 复刻验收

- 前 2 秒看懂“男生刚起床、准备选择穿搭”。
- 第一次点击后 0.3 秒内看到新服装。
- 每次点击只触发一次服装变化。
- 镜子、人物站位、发型和脸部不跳变。
- 最后一套服装至少保留 3.5 秒。
- 全片没有品牌、Logo、账号名、平台水印、价格和购买引导。
